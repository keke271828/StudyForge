## 电脑与手机：先存放，再决定读什么

上传、拖入文件或保存网址，只把资料放入当前项目，标为「待选择范围」。不解析正文，不转录视频，不下载网址的视频，也不调用 AI。勾选引用同样不会自动通读。

资料快选旁的「范围」及资料库中的「选择解析范围」提供：

| 选择 | 实际读取 | 使用方式 |
| --- | --- | --- |
| 指定 PDF 页码 | 只提取、渲染或 OCR 所选页 | 输入 `3`、`3-5,8`；一次最多 60 页 |
| 选中文字 | 只保存并交给导师所选原文 | 预览一页，选中一段，点「只使用我选中的文字」；也可手动粘贴 |
| 全文解析 | 用户明确选择的完整原资料 | 用于通读整本书、网页或视频；运行期间可以处理其他资料 |

页码指 PDF 文件的页次，从 1 开始，可能与书上印刷的页码不同。预览只在点击「只查看这一页」时读取该页，不先扫描整本书。扫描页需用按页解析识别；文字预览不会为整本书启动 OCR。

选段是本项目中的独立资料，保留原文件名称及页码或自填位置。当前对话改为引用这份选段，原文件继续留在资料库。导师和成果生成读取完整的选段原文，不使用界面的概括预览，也不自动扩展到原书其余部分。手动粘贴、尚未核对的原文会注明来源核对限制。

在对话中明确说「只解释第 3 页」，导师可以直接读取选中的 PDF 的这一页；原文件依旧保持待解析，不会变为已通读。只说「第 3 页第二段」或某章、某节时，由于 PDF 文本块不可靠地对应逻辑段落，导师先请你选取或粘贴确切原文，不会用整页、整章或全文代替。

目前指定页码适用于 PDF；DOCX、PPTX、代码、思维导图等可先存放，再选择全文解析或粘贴原文选段。Word 页码依赖排版，因此本版没有伪造稳定的 Word 按页读取功能。

## 安卓连接电脑

1. 退出托盘中的旧版，双击「验收最新版.vbs」打开最新源码。
2. 手机和电脑接入可互通的同一局域网。点击电脑顶部「连接手机」，选择正确的 Wi-Fi/有线地址并启用连接。
3. 首次连接：点「导出连接证书」，把 `.cer` 文件传到手机，在安卓系统设置中找到「安装证书 → CA 证书」。各品牌菜单位置不同。面板提供证书指纹供核对。不要传输电脑上的私钥。
4. 扫码或在手机浏览器输入面板中的 HTTPS 地址，填写 8 位配对码及设备名，再在电脑面板批准这台手机。
5. 首次连接默认接着电脑当前项目和对话；此后手机记住自己的上次位置。浏览器菜单可在支持的设备上安装或添加到主屏幕。

这是由电脑提供后台的手机网页客户端，没有生成 StudyForge APK。电脑必须开机，软件需继续运行；隐藏到托盘可以继续使用，彻底退出或电脑睡眠后手机无法调用模型。默认不开启网络入口，可选择下次打开软件时自动启用。Wi-Fi 直连地址随电脑 IP 变化；使用 Tailscale 固定入口可以避开这种变化，已配对的同一浏览器无需每次扫码。首次改用不同地址需重新配对一次。Windows 防火墙需允许程序在相应网络接收连接；本次没有修改系统防火墙规则。

证书的作用是让手机信任自己电脑的 HTTPS 服务；安卓首次安装 CA 会要求系统确认。不希望安装证书时，可以继续在电脑端使用。当前没有不安全的 HTTP 降级或公网转发模式。

## 手机端已经接入的功能

- 项目与独立对话；各对话自己的资料范围，项目成果不会混入其他项目。
- 从输入区上传多个手机文件，或使用系统相机入口添加图片；每次上传上限 512 MB。
- 文件和网址先入库，再明确选择解析范围。
- 分类资料快选、搜索、选择整类，以及直接引用生成的成果。
- 与电脑相同的 AI 服务、模型、学习模式、讲解风格和语言；Codex 可选择目录支持的推理强度。
- Markdown、代码、表格、引用和本地 KaTeX 数学公式显示。
- 讲解、只出题和同步习题生成，五档概括性和审查强度；配套习题默认单独 DOCX。
- 查看电脑任务的进度，暂停/继续原本支持这些操作的生成任务。
- 下载带可读名称的成果；生成后可直接引用，不必下载再导入。
- 作业提交、提交后即时解析、独立批改报告、错因问卷与草稿恢复，以及费曼讲解；编程题按题单语言提交。详见《手机作业提交与补讲验收》。
- 回复由电脑后台保存，刷新手机页面后恢复；重试使用原发送编号，避免同一消息重复执行。
- 文件操作审批在手机内等待决定；撤销设备后不能继续访问受保护的电脑文件。手机不会继承电脑的完全访问权限，只读限制仍生效。
- 浅色/深色/跟随系统；专注模式隐藏顶部和工具导航，只留下对话区和输入区。

手机端保留简洁学习流程；桌面的完整画像编辑、回收站和更新管理本版没有搬到手机。作业提交现已接入手机，相关电脑功能继续保留。

## 实现和验证

- 桌面 API 继续绑定回环地址。新增独立 HTTPS 网关，使用路由白名单、短效配对码、电脑确认、加密连接和可撤销设备会话。
- 会话密钥只保存在 Secure/HttpOnly Cookie，数据库保存其哈希；不放进二维码、URL 或脚本存储。手机不接触模型密钥、桌面所有者令牌或全局文件权限设置。
- Service Worker 只缓存公开的界面文件，不缓存资料、画像或认证 API 响应。手机本地保存界面偏好、未发送草稿和发送状态，以支持恢复。
- 文件工具会检查未解析资料和当前范围，避免绕过选择去读完整原文件。选段解析保留独立的范围记录；外部上传不能冒充软件内部的选段文件。
- 相关自动化测试覆盖暂存、不下载网址、单页读取、精确选段验证、拒绝扩大范围、恢复时不自动读全文、项目隔离、配对与撤销、权限限制、原有审批等待和 DeepSeek 独立运行。
- `scripts/check_mobile.ps1` 使用独立数据和模拟 AI 响应，通过实际 HTTPS 服务及真实 Electron 界面完成配对、手机/电脑上传、单页预览、原文选段、导师输入范围核验、回复中刷新页面、公式排版、专注模式、320 像素宽度、DOCX 生成和浏览器下载，并重新打开下载文档。
- 两轮相关回归分别 84 项和 74 项通过，范围包含项目与对话、原文生成、学习模式、权限与审批；计数有重叠。最后的界面流程另行实测，未把测试数量当作任意资料都能准确讲解的保证。

真实安卓硬件、各厂商证书安装菜单、手机系统键盘、系统下载目录和实际家庭 Wi-Fi/防火墙仍需用户设备验收。Electron 手机尺寸测试证明了流程和布局，没有被表述为真实安卓设备测试。模型替身只验证流程；不代表重新评估了实际模型的讲解质量。
