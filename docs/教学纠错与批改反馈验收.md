# 教学纠错与批改反馈验收

日期：2026-10-16。继续按真实教学表现改进；本轮为源码更新，未打包。

## 改进目的

学生的思路常常部分正确。若导师连合法步骤一起否定，学生容易丢掉已有理解，也无法看清到底该改哪里。上一轮的高斯定律回答出现过这种风险：匀强场常数可以提出积分，错误是把剩下的有向面积和当作总面积。

本轮对数学、物理、化学、演示用反馈模型、哲学与编程进行8组真实对照，再实际检查批改与错因补讲。采用一处小范围教学规则，并修复真实评分响应暴露的格式故障。没有增加固定审核轮次，也没有降低用户选择的模型或推理强度。

## 已实施

### 保留有效步骤，再定位分岔

共同教学规则将原先“先把结论和理由核对正确”细化为：保留学生推理中有效的步骤，指出哪一步不成立或缺少条件，在原情境中接上正确推导，不能为纠错否定合法操作。规则增加45个输入字符，没有加入任何学科题目的特定答案，也没有要求输出固定栏目。

导师与讲解、修订沿原有共享规则生效。教学版本为 `2026-10-16-preserve-valid-reasoning`；已有公开聊天保留，下一轮私有工具上下文按教学签名更新。风格、模式、语言、来源与本次要求保持各自作用。学生原本正确时仍应确认，不制造错误。

### 单题多个评分点不再导致整次批改失败

真实测试中，一道题有多个评分点，模型分别在 `feedback` 数组中写出多个评语。分数和内容合理，但原校验要求每道题恰好一条反馈；格式修复后模型仍按评分点拆开，最终RuntimeError，教学反馈无法交付。

- 只对**一道题**、反馈为多个非空字符串的情况，在本机完整合并为一条分段反馈，并保存 `feedback_normalization` 记录。
- 不改分、不删点评、不改错因、不将格式整理当成新的独立评分。原分数、评分依据和全部评语保留。
- 多道题的分组不明确时不猜归属；仍通过一次有界格式修复，明确告知题数、当前条数及每题全部评分点应合在一个字符串。
- 空白、非字符串和非数组反馈不静默丢弃或填造。非有限分数、分数数量和其他原有校验仍有效。
- 原来的两次独立评分、必要分歧裁决、79／80分边界、疑点暂不定分和提交前答案隔离保持。
- 同一道题的全部反馈能进入实际批改DOCX，随后照常提供错因分析与针对性讲解；评分点不被误当作额外题号。

同一 DeepSeek Flash／high，服务返回 `deepseek-flash`；关闭工具与联网。8题在采样前固定，后4题未用于再改规则；每臂一次，无重复或盲评。导师组从实际聊天入口捕获公开背景、当前问题与完整所选文件，文档组使用实际讲解函数。两臂只改共同规则中的一句，其他提示保持。

本次5组更快、3组更慢，6组较短、2组更长。若干问题本身明确要求保留正确步骤，会帮助两臂。采用这项一般纠错标准，不能声称已经证明总体质量或速度普遍提高。原版多数主问题本来就能回答；长复述、规范前提与认识论措辞仍有待改善。

全部16份最终回答、实际公开输入、用量、指纹及逐份评语在对照页。没有润色模型回答，也没有保存私有推理正文。

## 真实批改与补讲

第一轮两道题均在结构校验阶段失败，保存4条完整模型响应，包括两次格式修复后的结果。它们给出的分数分别为100与40，但反馈按评分点拆分。将这4条原始响应在本机重放，经无歧义合并后全部通过，分数与文字不变，零新增模型请求。

第二轮重新使用实际批改和补讲函数，取得6条模型响应：

- **等价正确证明：100分。** 两次独立批改均认可证明与等号条件，没有因定义了一个未使用符号扣正确性分。第二次响应多了一个右方括号，由现有一次格式修复恢复，共3条响应。
- **高斯定律部分正确推导：40分。** 两次独立评分均保留写出有向积分／合法提出常数的40分，按明示评分标准判定另外两点未满足，共2条响应。
- **错因补讲：1条响应。** 从本次原话“剩下的面积积分是六个面的面积和6A”定位错误，保留提出常数的正确步骤；说明法向、逐面正负通量与错误除法链。历史上不理解电通量的记录只作线索，没有单凭画像断定当前错因。模型使用implementation分类，分类并非唯一合理选择，不据此认证长期能力。

第一轮记录完成响应数，没有测量非流式HTTP尝试数；第二轮另核对6次实际HTTP返回。不能把两次同分当作客观正确性证明，本轮分数另由明确评分点人工核对。所有试题、作答和画像均为合成测试，不涉及用户真实学习记录。

实际评分和补讲经原有报告与Word输出器生成DOCX和Markdown，未改写。Word容器、正文和原生公式检查通过，未在Microsoft Word进行视觉验收。
