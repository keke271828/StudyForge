本次按用户最新指令直接打包当前已完成的源码。阅读区手动拖动、讲解格式手动收起，以及新报告的习题独立解题失败没有继续修改，尚未验证的临时布局改动已撤回。

## 打开方式

1. 在 Windows 右下角托盘右键 StudyForge，选择“退出 StudyForge”。如果运行的是源码验收版，也先完全退出。
2. 运行 `dist/StudyForge-Setup-0.3.5.exe`，沿用原安装目录。
3. 安装完成后从桌面或开始菜单启动 StudyForge，无需打开 CMD。

也可直接启动 `dist/win-unpacked/StudyForge.exe`；需要保留其整个文件夹。安装版与该入口共用默认的 `%LOCALAPPDATA%\StudyForge` 本地数据，避免同时运行。

本版本包含已经完成的作业提交、即时解析、错因问卷与独立批改文档，以及对话放大和原生全屏。显示模式操作见 [对话放大与全屏验收](对话放大与全屏验收.md)。
