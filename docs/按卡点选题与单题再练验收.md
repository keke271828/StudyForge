# 按卡点选题与单题再练验收

2026-10-22，源码更新，未打包EXE。

## 实现

- 修复练习支持显式选择原失分题号；默认全选，可从按题回看仅预选当前题。查看与勾选零模型请求，确认后才生成。
- 每个所选卡点各出一道同参考难度新题，提交前隐藏答案；旧的整套接口与费曼／问卷／评分待核实边界保留。
- 不同范围依照提交与上下文签名独立查找缓存，不被最后一个生成结果覆盖；缺少目标标记的缓存不复用。
- 后台入队及恢复保留RepairIn选择与依据；同题单入队前二次检查占用，避免并发重复创建。
- 选题窗口绑定当前项目和对话，迟到响应不回写新位置。指南、手机壳v68与静态资源白名单同步。
