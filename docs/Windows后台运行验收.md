# Windows 后台运行验收

本项修改源码，没有重新打包。后续自动更新、界面美化和全面审计仍待逐项验收。

## 打开并验收

1. 先退出旧版，再双击项目根目录的 `验收最新版.vbs`。标题应带「源码验收版」。
2. 在工作台输入一段尚未发送的草稿，关闭窗口或按 Alt+F4。右下角通知区会保留 StudyForge 图标；可能在「^」展开区内。
3. 单击图标重新打开，检查原草稿、当前聊天和项目仍在；重复双击入口也应恢复同一窗口。
4. 发起讲解后关闭窗口，稍后从托盘菜单「查看生成进度」打开成果页。隐藏不会主动暂停任务，模型速度及网络仍影响完成时间。
5. 右键托盘选择「退出 StudyForge」，或进入「设置与联动 → 运行环境」点击「完全退出」。任务状态保存后，后台和它启动的子进程停止。
6. 若退出时有未完成讲解，重开后进入成果页，该任务应显示「已暂停」，点击「继续生成」。保留原任务要求并复用已保存步骤，已导出的讲解只保留一份；同步习题仍单独默认 DOCX。

设置页同时提供「隐藏到托盘」按钮。第一次隐藏会尝试显示 Windows 提醒；系统可能屏蔽通知，不影响托盘本身。托盘创建失败时，关闭窗口会完全退出，不留下无法打开的隐藏窗口。

## 改动及原因

- 原版窗口关闭事件直接退出 Electron 并杀死后台。现在关闭事件隐藏同一窗口，进程、对话画面和未发送草稿保留到本次实际退出。
- 显式退出先让前端结束录音并等待已发起的模型/学习模式保存，再通知后台暂停生成、停止学习记忆工作器、保存中断状态，随后终止后台；退出等待有上限，服务异常时仍能退出。
- 原来重启只处理部分知识整理和问卷状态，生成任务可能永远显示「运行中」。现在启动会将排队、运行、正在暂停的生成恢复为「已暂停」。用户主动继续才重新开始，不自动增加模型调用。
- 生成保留原始参数及冻结的对话要求，并利用既有步骤缓存与成果编号继续。后台状态接口不调用模型，托盘定时读取当前任务计数。
- 桌面状态及退出接口要求父进程生成的临时令牌，令牌不交给网页；隐藏／退出 IPC 只接受本机主窗口的主框架，外部网页和其他窗口不能调用。
- 保留原有 Windows Job Object 和父进程监测：后台退出时停止由它启动的子进程；重复启动复用现有主进程。

关闭事件、托盘与退出事件采用 Electron 的公开接口：[BrowserWindow close](https://www.electronjs.org/docs/latest/api/browser-window#event-close)、[Tray](https://www.electronjs.org/docs/latest/api/tray)、[App before-quit](https://www.electronjs.org/docs/latest/api/app#event-before-quit)。

## 可恢复范围

隐藏窗口保留当前运行；电脑休眠、关机或网络断开不会让模型任务自动完成。完全退出前已成功保存的回复和成果可以复用，服务端尚未返回的请求不能保证保存，继续时可能重发。不把“可以继续任务”表述为“所有在途推理无损恢复”。

Windows 关机等情形未必触发 Electron 的常规退出事件，所以保留下次启动的中断恢复路径；此路径已验证，但没有自动执行真实系统关机。强制终止也依靠已写入数据库的步骤和重启恢复。原资料缺失或变更时仍拒绝使用旧缓存生成。

导入、通读、知识整理等任务本次不做细粒度续作，中断后显示失败并提示重试，原文件和已生成成果保留。问卷补讲失败状态可重试。学习记忆继续使用原有开关、间隔和每日限额；本项不新增开机自启或模型调用，不更改旧安装包。
