# 作业提交、即时解析与错因补讲

更新日期：2026-10-04。本轮修改源码，未重新打包安装程序。

## 打开最新版

从 Windows 右下角托盘完全退出旧 StudyForge，再双击项目根目录的 `验收最新版.vbs`。窗口标题应带“源码验收版”，无需保留 CMD 窗口。学习工作台输入栏旁应出现 **✓ 提交作业**。

源码验收版继续使用本机 StudyForge 数据库和模型配置。旧安装版 `.exe` 不会因这次源码修改自动替换；`start_studyforge.cmd` 可能优先启动旧打包程序，不用于验收本次改动。

## 用户流程

1. 在当前学习对话点击“提交作业”，从本项目选择软件已生成的题单或编程作业。
2. 普通题逐题作答，也可上传 PDF、DOCX、文本或图片，让所选模型提取到答题框。识别结果必须先核对，不自动视为完成提交。
3. 编程题按题单语言粘贴代码或读取文件，支持现有判题器的 Python、JavaScript、TypeScript、C++、MATLAB 和 Wolfram Language。不会统一要求 Python。代码文件预览使用与导入器一致的编码识别，保留 UTF-8、UTF-16 和 GB18030/GBK 中文；读取到代码框不调用模型、不自动提交。
4. 所有题目均需有明确作答。不会的题可以填写“不会”及卡点，不必编造答案。确认完成后提交，提交前不给参考解析。
5. 完整作答保存到本机后，直接将题单中已有的参考解导出为 **原题与答案解析.docx**。这一步是本地导出，不等待批改模型。
6. 同时启动独立的后台批改任务，仍可关闭作业窗口继续与导师讨论。评分核查后，为每道失分题定位原因并准备对应补讲。
7. 证据不足时，在原对话显示错因问卷；**批改文档尚不交付**。问卷可多选概念/术语、前置知识、构造动机、方法选择、论证、计算/实现，另有“仍不确定”和补充框。
8. 回答后自动恢复同一任务，复用原评分，导出 **批改与错题讲解.docx**。若另一题的错因仍需确认，先为那一题补充问卷，已填答案继续保留。作业记录、对话通知与项目成果区均提供两份文档链接，并标注来源对话。

## 两份独立文档

| 文档 | 交付时间 | 内容 |
| --- | --- | --- |
| 原题与答案解析 | 完整提交后，本地导出完成即交付 | 原题、题单中已有的参考解析和易读的评分标准 |
| 批改与错题讲解 | 评分、错因定位及必要问卷完成后 | 原题、我的作答、逐题评分依据、每道失分题的错因及证据边界、针对性讲解、下次核对方法、参考解析与本次总结 |

原题和学生作答采用引用样式，导师讲解使用正文样式。失分按逐题未达100分判断；不把总分达到80分误当成“所有题都没有错误”。低分的费曼或修复流程继续遵循已有设置。

## 错因与画像的证据标准

- 明确问过“高斯定律是什么”等定义问题，会立即留下不计分的暂定疑问记录（后台学习已开启时），不必等一次额外模型调用。软件操作、报错、闲聊不会因此进入画像。
- 批改使用提交时冻结的相关学习画像、当前模型及讲解偏好。与题目无关的其他聊天原文不作为错因证据。
- 历史疑问是线索，不能证明学生现在仍不懂。只依据旧画像，或只有错误最终数字/选项而没有推理步骤，不能发布“已确定”的错因；先询问。
- 错因依据的引句必须确实出现在对应的本次作答、画像或问卷中；一道题的问卷不能冒充另一道题的自述证据，引句中的引号按原文字面核对。学生自报标明尚未独立验证。
- 补讲必须实际解释本题的概念、变量、条件、推导动机或错误步骤，不能只写“复习一下”。系统检查每道失分题的覆盖和必要字段；不完整或过短的输出修复一次，仍不合格则保留解析与已完成评分，暂不发布批改文档。
- 自评与作答诊断分别保存，均不再增加一次分数或掌握度。无关补充不沉淀为学习画像。
- 学生填写“仍不确定”后若原因依然无法确定，文档诚实标明边界并给定位指导，不虚构原因，也不无限循环问卷。

## 恢复、重试与隔离

- 作答、两份成果、待填写的问卷与问卷草稿保存到本机。草稿短暂防抖自动保存，完全退出前等待保存；重开可恢复。
- 同一题单的相同提交返回既有记录，不重复评分。失败重试复用完成的评分阶段，失败的模型原始响应重新请求，避免永久重放坏 JSON。
- 解析导出失败时仍保留完整作答，可重试；批改失败时保留已交付解析。失败保留实际进度，不伪装完成100%。
- 题目或评分标准在暂停期间改变，阻止混用旧步骤；取消或删除任务后，不能通过旧问卷恢复交付。
- 不同题单可遵循并行设置分别运行；同一题单评分及依赖评分的进阶继续顺序处理。
- 问卷只出现在原对话，项目成果仍按项目文件夹隔离。切换对话不丢未提交的问卷输入；切换项目清空前一项目的通知。
- 通过新提交流程提交、但尚未关联对话的作业，会在所属项目创建独立的“作业反馈”对话，默认不选资料，避免问卷没有填写入口。
