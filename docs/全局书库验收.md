## 一、打开当前版本

2026-10-10 的后续还完成了阅读时段、每日 token 软预算与真实请求计量/等待续接，见 [书库后台阅读安排验收](书库后台阅读安排验收.md)；长回复渲染、图片准备、慢响应轮询与取消处理另见 [流畅度与内存优化验收](流畅度与内存优化验收.md)。再后续优化了 [大型书库查询与导师回查](大型书库查询与导师回查优化验收.md)，目录批量读取、笔记逐条检索、工具按已读页和片段回查。均为源码交付，安装版尚未更新。

1. 从 Windows 右下角托盘完全退出旧版 StudyForge。仅关闭窗口会继续运行旧程序。
2. 双击根目录的 [验收最新版.vbs](../验收最新版.vbs)。无需保留 CMD 窗口。
3. 电脑侧边栏打开“全局书库”。手机连接这个源码版电脑服务后，从输入区“选项”进入全局书库。
4. 软件内“使用指南”或 F1 已加入“全局书库：先建目录，只读选中的章与节”，无需模型调用即可查阅。

## 二、完整使用流程

### 先放书，再建立目录

- “＋ 放入 PDF 教材”只保存书籍副本，不自动扫描或让模型通读正文。相同文件内容复用同一本书。
- 有内置书签时，直接形成候选目录；扫描 PDF 需填写目录所在的 PDF 页码，例如 `3-5`。一次最多识别 12 页，不能把未提供的正文当作已读。
- 可以预览单页原图。纸面页码与 PDF 页码分别保存；确认纸面第 1 页对应 PDF 第 6 页后，填写对应关系生成候选定位。
- OCR 目录保留原始行、页码栏核对和来源位置。标题与公式符号可能识别错，漏项可以手动补充。

### 选章、节和页内范围

1. 点节点旁“范围与原页”。
2. 核对标题、起止 PDF 页码。相邻小节位于同一页时，用起点和终点百分比限定选区；也可点击原图设置位置。
3. 勾选“我已确认”并保存，再选中需要的节点。
4. 选择串行或并行，点“阅读所选节点”。选中父章节时不会再重复处理已选的子节。

串行按目录顺序处理；并行由独立节点工作器处理不同范围，不把尚未完成的兄弟节点当作先修证据。后台最多两个工作器，实际请求数仍受全软件并行开关和模型请求上限限制；不能并行时，任务卡显示原因。只选一个节点时两种方式都只有一个工作器。

### 后台阅读与恢复

- 使用当前对话选择的 AI 服务、模型和推理强度；后台阅读不带入项目聊天记录。
- 页面按最多四页一批加载，保留原页 OCR、图像核对记录和来源。每批整理后保存进度，长章节不需要等整章完成才更新进度条。
- 每批一次精简索引请求；长节点再一次汇总。没有反复让代理相互赞同，也不把整理当成永久训练模型。
- 前台优先：已有背景步骤保存后让位，新步骤等到空闲才启动。正在执行的请求不能承诺即时抢占。
- 任务卡支持暂停、继续和取消。手动暂停的任务重启后仍暂停；退出时被中断的任务下次恢复，并复用已保存步骤。
- 同版本、同范围、同模型的已完成阅读可以复用；范围变化使旧阅读失效。部分失败保留已经完成的节点。

### 引用到任意项目

书架搜索支持书名、章节与已读原页术语，结果注明匹配来源和 PDF 页；点击只定位，不启动阅读。本书目录另有标题/状态筛选、章节折叠和清空勾选。筛选隐藏的已有勾选仍会阅读，启动前请看已选数量提示。

1. 已读节点点“引用到当前对话”，回到学习工作台。
2. 在“书库参考”中选用途：**参考背景**辅助当前资料；**重点讲解对象**将节点本身作为生成对象，可以不添加项目附件直接生成。
3. 每个对话独立保存自动、手动或关闭的选择，其他项目不会继承本对话的引用或聊天。
4. 自动模式从相关已读节点回查原页摘录；长页围绕问题取连续片段，并保留附近的定义和证明上下文。笔记只用于导航，省略与未解决疑点会注明。未读的相关节点只显示提示，由用户安排阅读。
5. 主动选作生成对象的节点使用全部已选范围，不以检索返回的少量页代替整份讲解输入。

原书版本、范围和原页缓存会在引用与导出复核中校验。书库可作参考，导师仍可依据当前允许的其他资料和联网设置回答。要求只使用指定材料时，不额外扩展自动书库范围。

### 数据归属

书籍、节点、原页缓存和阅读任务不依附某个学习项目。删除或彻底清除项目不删除全局书库。删除全局书籍会移除软件内副本、目录和缓存，所有对话中的相应引用失效，用户原来的 PDF 保留。

“AI 已整理”不等于“学生已掌握”。书库任务不创建掌握评分，学习画像仍使用知识疑问、自身解释、作答、费曼讲解和自评的证据。

## 四、实现与边界

目录的同级顺序、章／节归属及撤销在后续轮次完成，见 [书库目录整理验收](书库目录整理验收.md)。结构移动保留原范围及引用；已经提交的后台任务不随新目录改变节点或顺序。

代码主要位于 `studyforge/library.py`、`library_worker.py`、`library_routes.py` 和 `web/library.js`。独立书籍、节点、阅读、原文分块、步骤缓存和对话引用表在 `studyforge/db.py`。生成、导师工具、调度、手机与通知接入各自已有接口。

目前支持 PDF；关键词检索可使用，可主动启用后续完成的本地语义增强。目录整理支持同级排序、改变层级与撤销；后台也已接入阅读时段、每日 token 软预算和服务用量／估算的区分记录，详见各后续验收。尚未按所配置服务的价格折算费用，软预算不是精确账单上限。并行工作器不提供跨节点统一证明正确性的保证。OCR、视觉模型和生成模型都可能犯错；目录和正文范围需确认，复杂推导应回查原图。

本轮没有完成十本 300–400 页扫描教材的全部阅读、内存峰值长期测量或逐一定理的理解准确率评估。这一版可用于逐节点建立书库；不能把所有书上传后就视为模型已经高质量掌握全部内容。
