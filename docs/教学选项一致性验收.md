# 清晰讲解与教学选项一致性验收

2026-10-04。本项源码已完成，未重新打包。范围包括共同清晰标准，以及用户追加的讲解风格、学习模式、讲解语言和审查强度核查。

## 核查结果与修复

| 选项 | 原先问题 | 现在行为 |
|---|---|---|
| 风格 | 生成器只有简短风格要求，聊天不接收选择；不能据此保证术语解释、推理衔接与直接表达 | 三种风格采用明确的不同规则，聊天、生成、必要修订、补讲、总结和格式整理采用同一选择；所有风格保留准确性与必要说明 |
| 学习模式 | 已有实际目标规则，但问卷补讲可能用原讲解模式而界面仍显示当前模式 | 补讲恢复原讲解的模式、风格与语言；生成使用启动时的快照，任务不受后来选择改变 |
| 语言 | 聊天不接收讲解语言；修订等路径缺少统一规则；来源告警、代码标题及注释指令未完全跟随；双语总结标题识别不完整 | 统一中文、按段落或小节中英对应、英语正文；引用、代码标识符与来源位置原样保留；固定核对说明及交付代码标题支持英语和双语 |
| 审查强度 | 执行流程已有区别，但没有按对话保存；“三轮复核”标签模糊 | 每对话保存，提示每章真实调用范围；三项审查、有问题才修订并复核；聊天在同一次回答内自检 |

新增对话绑定当前教学默认值。已有对话分别保存自己的风格、语言、模式与审查选择；重开恢复，旧记录兼容迁移。修改选项不清除阅读缓存，不创建新的学习对话，不调用模型重新读资料。

共同清晰标准要求：直接说明当前对象和结论；术语解释落到实际含义；必要前置在用到处补足；公式交代符号与条件；重要推理交代本步依据与作用；方法理由能回应真正障碍。需要例子时讲完实例，类比有真实帮助才使用，并说明边界。不会把每次回答扩成全套证明、历史和跨学科教材。

风格控制表达方式，模式控制学习目的，概括性档位控制目的下的详略，语言控制说明语言，审查强度控制额外核查。学生本次明确的篇幅、来源、格式和不出题要求优先。风格与语言修改自身不会追加模型调用；同一资料可重新生成不同版本。

## 审查范围

| 档位 | 每章首次额外审查请求 | 发现实质问题时 |
|---|---|---|
| 极速 | 0 | 生成时自检，没有独立报告证明通过 |
| 快速 | 1 次综合核查 | 标注疑点，保留原稿 |
| 平衡 | 1 次综合核查 | 再修订一次，修订稿不再独立复核 |
| 严谨 | 覆盖、事实与推导、成品三项 | 再修订一次，并做三项复核；仍有问题列出待核实 |

不含首次讲解、补总结、代码实现、卡片/代码包整理以及单独习题流程。长文章节各自执行；因此严格档位不是整篇固定三次调用。代码和模型输出有结构与静态核查，不能据此声称已经实际执行、数值正确或经同样三项语义审查。

## 打开与人工验收

先从托盘退出旧窗口，然后双击项目根目录 `验收最新版.vbs`，确认标题带“源码验收版”。该入口使用最新源码；原有安装包未更新。

1. 在学习工作台打开“更多设置”里的讲解选项，分别修改风格、语言和文档审查；学习模式在对话顶部。选项旁显示说明。
2. 用两个对话设置不同选项。切换及完全退出重开，检查各自恢复，阅读笔记与资料选择保留。
3. 选同一资料分别用通俗、专业风格，要求“简短说明关键条件，不出题”。检查表达有区别但没有丢失条件或增加未要求作业。
4. 分别用概览、精学、研究，检查主线梳理、方法动机与复现、证据边界这些目标真正不同；不以字数变化作为唯一判断。
5. 分别试中文、双语、英语，并要求补讲一个术语；检查正文、总结、代码说明与语言相符，引用仍保持原话。
6. 无模型审查的极速档只显示生成时自检；比较更高档位的审查阶段。生成后通过理解问卷指出具体困难，再看补讲是否处理卡点。

### 教学质量人工标准

以学生能指出依据、条件及方法线索为验收方向，不只判断文章顺口。下面六类缺口对应原理解问卷，可用于真实模型抽样评审：

| 缺口 | 检查讲解是否做到 |
|---|---|
| 不懂术语 | 定义具体含义，保留原术语，能辨认它指什么 |
| 缺少前置 | 在首次需要处补足最小必要背景，避免继续使用未解释概念 |
| 看懂计算但不懂构造动机 | 把目标、障碍及这个构造带来的帮助接起来 |
| 会套方法却不知何时用 | 说明触发线索、前提和一个失效边界 |
| 能复述但无法论证 | 明确前提、关键理由和结论间的关系 |
| 推理正确但计算/实现错 | 对应关键算步、系数、条件或边界输入，具体定位错误 |

可使用 `scripts/lesson_quality_eval.py` 已有哲学、社会科学、数学、物理、编程、生物资料进行真实模型与人工抽样；其离线默认模式仅检查流程。本次未执行付费抽样。实际共享提示词见 [AI导师提示词](AI导师提示词.md)，可用 `python -m scripts.export_teaching_policy` 从源码重新导出。
