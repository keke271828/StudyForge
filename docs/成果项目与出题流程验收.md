# 成果项目与出题流程验收

2026-10-04。本次为源码修改；安装包未更新，未进行打包。

## 打开与操作

先从 Windows 托盘退出旧版，再双击项目根目录的 `验收最新版.vbs`。窗口标题应包含“源码验收版”。启动入口已检查存在，并采用现有 Electron 运行时。

1. 在学习工作台选资料或填写题目范围，输入框下「生成内容」选择「只生成习题」，按钮会变成「生成习题」。讲解格式此时禁用；更多设置中的习题格式默认 DOCX。
2. 只出题不生成讲解、讲解审查文档、讲解总结或讲解理解问卷。习题仍先求解、核查，再只导出学生题单。
3. 普通导师聊天中明确提出出题，进入同一流程。完整提交全部作答并成功批改后，才开放题目解析。尚未完成时可以看方向提示；将题单成果选入另一个学习对话也不能提前索取答案。
4. 在「成果文档」内点击项目文件夹，查看该项目的成果与任务。文件夹可搜索，数量随生成与删除更新。切换项目不会混入其他项目的文件。
5. 成果上「来源对话」可点击返回该对话；对话改名后来源更新。已删的对话显示“已删除”；未记录来源的旧成果和导入成果明确显示未记录，不推测来源。
6. 任务卡片的「取消并删除任务」二次点击确认，停止后续工作并移除列表记录；完成的成果保留。「显示已结束任务」显示最近任务，可删除完成或失败记录，完成的任务不再显示暂停按钮。
7. 学习工作台「删除对话」二次确认，删除聊天、草稿、私有协议与关联任务的消息上下文，停止该对话生成任务。资料、成果、题单和学习画像保留。为成果出处保留最小对话标识和标题；导师正在流式回复时先结束回复再删除。

## 修复的实际路径

- 同步出题：首次结构化输出无效时，保留原请求与字段约束，最多发起一次格式修复。仍无效时不发布题单，显示明确错误，已经生成的讲解不丢失。不会无限重试。
- 私有解题、批改：参考答案和评分标准不保存到公开聊天协议。Codex 私有任务使用独立服务连接；取消会关闭本应用拥有的会话服务和工具请求，下一次导师回复从本地消息恢复上下文。
- 任务取消：注册 API 发起的后台任务；取消协程并解除暂停等待，禁止已取消或已移除任务再更新成运行或完成。重新启动软件不会恢复已取消的任务。
- 生成发布：读取和模型步骤有取消检查，导出后在入库前再次检查。已取消的任务不能因为延迟结果再次新增成果。
- 项目切换：成果请求检查项目、切换版本和排序，丢弃旧响应，避免 A→B→A 后旧列表覆盖当前成果。

## 验收边界

模拟响应证明程序路由、隔离与文件生成可用，不能证明真实模型题目准确、语言自然或对每种自然语言出题表达均识别正确。常见明确出题请求走确定流程；普通教学仍依赖提示词遵守题单保护规则，不能将提示词称为数学意义上的内容保证。

取消异步任务会停止后续步骤和交付；已经在线程内执行的文件解析、转录或导出不能安全地强行中断，可能完成当前底层操作。此前已完成并保存的资料与成果保留，不把取消等同于全部撤销。

未记录对话来源的历史成果显示未记录，不能凭文件内容可靠补出过去的来源。全部任务的通用暂停/恢复、自定义背景以及并行调度仍在后续清单，当前取消功能不表示这些项目已经完成。
