## 打开方式

1. 从 Windows 右下角托盘右键退出已经运行的旧 StudyForge。
2. 双击工程根目录 `验收最新版.vbs`，窗口标题包含「源码验收版」。无需保持 CMD。
3. 点击右上角「外观」，或进入「设置与联动 → 外观与操作」。
4. 外观内分为「背景」「界面分区」「字体与文字」「基本设置」。

## 独立调整的区域

| 区域 | 实际控制范围 |
|---|---|
| 主界面底色 | 背景图上方、其他区域后面的主工作区底色 |
| 侧边栏 | 项目与对话树、工作区导航的背景 |
| 阅读面板 | 聊天正文阅读区域及阅读预览 |
| 资料快选栏 | 资料分类、选择与导入区域 |
| 输入栏 | 问题输入、附加资料和生成选项所在区域 |
| 顶部栏 | 项目标题、专注与外观入口 |
| 对话选项栏 | 模型、模式、通读状态与各工作区标题 |
| 按钮与表单控件 | 常用操作按钮、文本框、下拉菜单等控件底色 |
| 消息气泡 | 用户、导师消息的局部底色，与整个阅读面板独立 |
| 设置区域 | 设置卡片、类别导航与外观子标签 |
| 弹窗与菜单 | 笔记、知识结构、确认弹窗和管理菜单 |
| 成果与资料卡片 | 成果、资料、任务、练习、画像卡片及导入卡片 |

每个区域都支持：

- **不透明度 0%–100%**。0% 完全透出背后的画面，100% 实色遮挡。后端也接受 0%，不再有 88% 的隐藏下限。
- **背景模糊 0–40 px**。0 关闭，仅模糊区域背后的画面；不对文字或整个组件应用模糊滤镜。
- 文字使用主题颜色、黑、白或自定义颜色。
- 描边 0–2 px；自动选择与文字明暗相反的颜色，也可选主题、黑、白或自定义。0 关闭。
- 本区恢复默认，以及将本区样式应用到全部区域。

文字不随底色滑杆变透明。代码与公式保留原有字体；代码、公式、图标不继承文字描边。原文引用继续保留区别于讲解的衬线字体与引用样式；选中状态、引用、代码等具有语义的局部样式仍可见。

移除了原来叠在阅读面板、资料标题、分类和输入正文下面的固定实色层。若其他区域（例如主界面底色或消息气泡）设置为实色，透明区域会显示那层底色，这符合实际层叠关系。0% 透出软件的背景，并非使 Windows 窗口透明。

## 更快地设置

- 四种预设：「纸面专注」「玻璃夜读」「轻透留白」「完全透底」。它们修改实际区域参数，当前完整匹配的预设会显示选中状态；手动修改后可成为自定义组合。
- 保留用户自己的背景图；玻璃/轻透预设同时调整明暗主题与背景显示强度，没有图片时提供内置渐变。
- 右侧即时预览包括顶部、侧栏、选项、阅读、资料和输入区域，以及真实 KaTeX 公式。
- 「快速定位区域」直接滚动至该卡片并聚焦不透明度滑杆。窄窗口使用单列，外观子标签滚动时保持可见；切换外观子标签回到内容开头。
- 压缩设置页重复标题，文字和描边折叠收纳，保留键盘焦点与减少动画设置。

## 自定义字体

「字体与文字」支持系统、微软雅黑、宋体、楷体和上传字体。上传 TTF、OTF、WOFF、WOFF2，最多 50 MB。本机解析并保存可用字体副本；代码、公式与原文引用保留各自字体。

字体不会作为学习资料导入，不发给模型，也不产生画像证据。替换清理旧副本，删除副本恢复系统字体，原文件保留；无效字体或保存失败保留原偏好。浏览器加载失败时显示提示并使用系统字体。格式依赖已加入安装配置，未来打包配置包含字体表与 WOFF2 解码模块。

背景恢复默认、界面恢复默认与字体删除分别处理，只恢复各自范围，不重置模型、学习模式、所选资料或聊天。修改立即预览，合并连续滑杆操作并按变化项保存；过期读取不覆盖新偏好，保存失败恢复已确认的值，退出前保存待处理修改。

## 手动验收

1. 选择图片或内置背景，点击「界面分区 → 完全透底」。阅读区、侧栏、资料、输入与顶部均应透底，文字仍显示。
2. 分别把阅读面板、侧边栏和输入栏从 0% 拉到 100%，其他区域参数不应被改动。
3. 将阅读面板保持低不透明度，模糊从 0 拉到 20；背后的图片在阅读范围内变柔和，侧边栏不随之模糊。
4. 使用「快速定位区域 → 顶部栏」；卡片滚动到面前，滑杆可用键盘调节。
5. 打开文字与描边，选白色文字和自动描边，观察正文，再检查代码、公式和图标。
6. 上传自己的字体，完全退出托盘并重开，检查字体与参数恢复；删除字体副本后检查原文件。
7. 分别尝试恢复本区、全部界面及背景默认；模型和学习任务不应被更改。
