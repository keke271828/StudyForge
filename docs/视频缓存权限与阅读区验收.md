# 视频记录、Agent 权限与阅读区调整

源码验收日期：2026-10-07。此次没有重新构建安装包，已有 0.3.5 安装版不包含本页修改。

## 打开最新源码

1. 从 Windows 右下角托盘完全退出已有的 StudyForge，避免两个版本同时使用本机数据。
2. 双击项目根目录的 `验收最新版.vbs`。它启动 Electron 窗口，后台隐藏运行，不需要打开 CMD。
3. 已有项目、聊天记录和设置使用原本的数据目录。测试均使用单独目录，不改动用户的学习资料。

## 本次功能

### 视频与识别记录

- 字幕按严格编码解码；字幕、转录和 OCR 中的替换字符、非法控制字符及孤立代理项标为 `[无法辨认]`。
- 保留来源位置、异常数量、原字符位置和识别文本校验值；导师不能从上下文补造未辨认的公式。
- 网址视频完成识别、原文档导出及记录校验后，保存 `.sfvideo` 识别记录和必要关键画面，清理本次下载的视频、副本、音频和重复画面缓存。
- 记录包括完整可得字幕／转录、时间戳、来源网址、关键画面与校验值；生成讲解或新一轮工具调用可以重新读取记录，复用既有对话中的网址识别结果。
- 网址读取工具支持显式重新读取，缓存被删除时也会重新获取。已清理的视频若需要原来未采样的视觉细节，需要重新临时获取，不能从现有画面推测不存在的细节。
- 网址导入失败时也清理本次闲置下载。用户本地原视频不在网址下载清理范围内。
- 删除资料库中的视频识别记录会同时清理其所属的画面目录。
- 设置与联动 → 工具与联动 → AI 工具与权限，新增“网址视频读取方式”。

| 方式 | 获取内容 | 下载与清理 |
| --- | --- | --- |
| 音画分析（默认） | 字幕／语音转录与采样关键画面 | 临时下载音画；完成后清理视频，保存识别记录 |
| 字幕优先 | 可用的带时间戳字幕；明确标注未分析板书、图表 | 有满足时间范围检查的字幕时不下载音画；否则回退音画分析 |

关键画面是采样，不等于逐帧观看；平台登录、版权及链接访问限制仍需通过已有浏览器导入方式处理。此次测试没有使用用户的 B 站账户验证具体外网视频。

### Agent 文件权限

输入框底部新增权限选择；两种 AI 服务通过相同的后端工具执行。

| 模式 | Agent 文件操作 |
| --- | --- |
| 只读 | 可读取所选资料、软件代码和授权目录；禁止主动写入、修改、删除、复制输出、导出及绘图落盘 |
| 需要审批（默认） | 当前工作目录和明确授权目录内可操作；其他文件操作显示单次审批卡片，批准后执行 |
| 完全访问 | 可操作当前 Windows 账户能访问的文件；仍遵守单独的联网、网页视频、绘图和文件修改开关 |

审批显示实际路径和有界修改预览；仅授权本次操作。拒绝、取消任务、删除对话、文件在审批期间变化或重启软件都会阻止对应操作或使审批失效。审批卡片位于对话滚动区，小窗口仍可操作。

新增删除、复制与恢复工具。删除文件保留备份，返回恢复路径；非空目录不递归删除。完全访问提供显式文件访问能力，不自动把其他项目或对话的聊天记录注入当前上下文。核查题目、答案和评分的私有上下文保持只读。

用户点击软件的生成按钮仍可生成内容并由软件导出；只读模式限制 Agent 主动操作文件。

### 阅读区

- 在输入区上沿拖动分隔线：向下扩大阅读区，向上扩大输入区。
- 双击分隔线尽量扩大阅读区并收起生成选项；方向键可微调。
- “收起／展开生成选项”统一控制格式、详略、讲解内部并行等选项的显隐，保留生成按钮和已选设置。
- 比例和显隐偏好保存在本机，重开恢复。上下限根据窗口与必要控件尺寸计算。
- 保留原聊天 DOM、草稿、资料与生成设置，并与既有放大、全屏和滚动位置维护协同。

### 习题 RuntimeError

原流程把独立求解阶段的每条评论直接计为失败，因此“可以换一种证明”等建议也会导致“独立解题未通过”。现在让两项后续核查逐项判定疑点是否影响题意、解答或公平评分，并保存确认／驳回依据。建议性意见可以驳回；实质问题必须修订复核，不因文件格式是 DOCX 就降低正确性要求。

新增实际 DOCX 导出与读取检查，确认学生版没有参考解。结构缺失、遗漏疑点判定、重复索引或确实存在实质缺陷仍不能当成通过。
