# 侧边栏项目与对话管理验收

2026-10-04，最新源码。按用户要求未重新打包。

## 打开方式

1. 先从 Windows 右下角托盘右键选择「退出 StudyForge」，完全退出已有旧进程。
2. 双击工程根目录 `验收最新版.vbs`。窗口标题应包含「源码验收版」，无需打开或保持 CMD。
3. 学习资料仍使用原来的本机数据目录。这次数据库只新增导航顺序、置顶、折叠偏好和项目回收站记录。

不要用旧安装包或优先打开安装包的 `start_studyforge.cmd` 验收尚未打包的改动。

## 界面与操作

项目与对话整合成文件夹树。六个工作区入口改为两列紧凑导航，给项目列表留出更多空间。

| 操作 | 结果 |
|---|---|
| 点项目名称 | 打开项目，恢复该项目最近使用的对话 |
| 点项目左侧箭头 | 只展开或收起文件夹，保留当前聊天 |
| 右键项目，或点行尾 `⋯` | 打开、新建对话、行内重命名、置顶、查看项目成果、查看项目资料、移入回收站 |
| 右键对话，或点行尾 `⋯` | 打开、行内重命名、置顶、查看所属项目成果、删除对话 |
| 管理未选中项 | 无需先切换到待管理对话；右键未选中的项可直接修改它 |
| 行内名称输入框 | Enter 保存；Esc 取消；离开输入框提交非空名称；自动刷新保留输入、焦点和光标选区 |
| 拖动项目或对话 | 保存固定顺序；对话在所属项目内、相同置顶分组内排序 |
| 搜索 | 按项目名、对话标题或最近消息筛选；不会改变正在看的聊天；搜索期间禁用拖动 |
| 排序 | 固定顺序、最近消息、名称；置顶项优先。最近消息以内容更新时间为依据，打开、改名和草稿不改变它 |
| Ctrl+P | 搜索项目与对话；在专注模式下自动显示侧边栏 |
| Ctrl+N / Ctrl+Shift+N | 新建对话 / 新建项目 |
| F2 / Delete / Shift+F10 | 对侧边栏焦点项重命名 / 打开删除确认 / 打开菜单 |
| 上下方向键、左右方向键 | 移动侧边栏焦点、展开项目、收起项目或回到父项目 |

不支持把对话拖入另一个项目。避免无意改变聊天的资料范围、成果归属和隔离边界。

## 删除的具体影响

- **项目移入回收站**：确认窗口显示对话、资料、成果和未完成任务数量。关联生成任务停止；项目从工作台、成果文件夹和 MCP 可访问列表移除，旧资源链接不可直接读取。原文件、成果、聊天保留。侧边栏回收站入口可恢复项目，停止的任务不会自动重新执行。
- **删除对话**：确认窗口显示消息数量及未完成任务。聊天、草稿和私有会话删除，关联任务停止并移除任务历史；项目原资料、已生成成果及有效跨项目画像保留。这项操作不能撤销。
- 删除最后一个对话后，项目保持为空，提供新建对话入口，不自动制造替代聊天。
- 导师正在回复的项目或对话暂不能删除，接口明确解释原因。

回收站没有永久销毁文件的入口。已完成的学习画像仍按原来的跨项目记忆规则使用；待整理的回收项目证据不会继续自动送给模型，进行中的后台输出也不能在项目移除后提交。

## 同时修正的常见操作阻力

1. **选中即自动置顶**：后端以前按最近打开时间排序，现改为独立保存的固定顺序；选择不会重排。
2. **刷新打断操作**：项目和对话节点复用，保留列表滚动位置；行内编辑不会被定时刷新重建。
3. **切换等待无关加载**：先恢复聊天、草稿和所选资料，模型目录、成果列表和作业列表后台更新。模型目录迟到的结果不能改写新对话的设置。
4. **点击当前项重复初始化**：再次点击当前项目不会清空聊天、资料选择和草稿。
5. **切换反复通读**：有效通读记录照常恢复；单纯打开一个已有聊天不自动创建新的 AI 通读任务。主动选新资料、发送依赖资料的问题或点击通读仍使用原来的阅读流程。
6. **查看材料后丢位置**：勾选资料保留快选列表滚动和键盘焦点，已打开的内容预览保持打开。聊天切换在本次运行内记住各对话的阅读位置。
7. **关闭重开丢导航偏好**：名称、置顶、固定顺序、排序和折叠存在数据库中，不依赖每次变化的本地端口。当前项目也可保持用户选择的折叠状态。

全任务并行调度仍在后续清单中，以上导航加载优化不代表模型任务已经统一支持并行。

## 手动验收建议

1. 在同一项目新建三段对话，分别改名；在三个对话之间来回切换，确认位置不变。
2. 在对话 A 写下未发送的草稿，右键对话 B 改名，确认当前仍在 A，草稿不变。
3. 改名时等待超过五秒，确认输入框仍然存在；Enter 保存，另一次用 Esc 取消。
4. 置顶一个对话，拖动另外两个；完全退出并重开，核对顺序、名称和草稿。
5. 将当前项目折叠，完全退出并重开，确认聊天恢复且文件夹仍然折叠。
6. 用临时项目测试移入回收站和恢复；在成果区核对它的文件夹随之隐藏和恢复。
7. 用临时对话测试删除；若是项目的最后一个对话，应显示空项目，不自动新建。
