# StudyForge 0.4.4：新手指南与安装包

这轮把帮助从按功能堆叠的长文，改成按用户想完成的任务查步骤。指南保存在软件内，查看不调用模型；仍需先配置一个可用的 AI 服务，才能聊天或生成讲解。

## 从哪里开始

- 电脑：左侧“使用指南 · 零基础上手”，或按 **F1**。
- 手机：首次配对页与“学习选项”里的使用指南。
- 上传资料、生成成果、交作业、画像和全局书库附近增加了就近说明按钮，直接打开相关主题。

新版首页提供六个入口：第一次使用、读资料、下载讲解、练习与交作业、整本教材、遇到问题。19个主题覆盖连接模型、项目和对话、解析范围、提问与公式追问、模式、成果、作业、画像、书库、权限、手机、后台和常见故障。

## 改了哪些容易误导的提示

1. 不再把“通读”写成每次提问前必须完成的步骤。可以直接问问题，也可以解析、勾选资料后直接讨论。
2. 明确“上传只保存”“解析才提取内容”“通读整理笔记”“生成导出文件”的区别。
3. 不再承诺上传就自动选用，提示用户检查当前对话引用。
4. 明确 PDF 文件页码与书页印刷页码不同；网址、图片不走部分解析。
5. 将模型接入、第一次提问、PDF单页学习、作业提交写成操作步骤，并写出完成后的现象。
6. 进阶说明折叠；搜索会展开命中的说明，清空搜索恢复原展开状态。例子复制被禁用时保留手动复制方法。
7. 指南保留核查、画像、评分和来源的边界，不把一次高分等同长期掌握。

## 安装与数据

安装包：`dist/StudyForge-Setup-0.4.4.exe`。先从 Windows 右下角托盘完全退出旧版，再运行安装包，选择原安装位置。安装程序按原策略保留本机学习数据；本轮测试不操作真实学习数据库。

也可运行 `dist/win-unpacked/StudyForge.exe` 验收，但必须保留整个 `win-unpacked` 文件夹。无需通过 CMD 启动。手机界面由电脑提供，更新电脑后刷新手机页面；保留原数据与浏览器站点数据时，已有配对无需因界面更新而重新建立。

目前没有正式更新发布源和发布者签名配置，本次不安装到用户环境、不在线发布，不声称在线自动更新已接通。
