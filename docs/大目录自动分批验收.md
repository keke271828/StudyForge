# 大目录自动分批验收

2026-10-11。延续全局书库改进，处理超过 200 个节点的教材无法全选启动定位／阅读的问题。本次更新源码，未重新打包。

## 使用变化

- 可一次选择最多 2000 个节点；316 个节点的书可直接全选。界面、阅读接口、定位接口、集中核对接口采用一致的上限。
- 实际待处理节点超过 200 个时，一个任务内部按每批最多 100 个依次执行。原先不超过 200 个的任务沿用原流程。
- 阅读先对整个选择集按目录顺序去重，只有已确认的祖先范围完全覆盖子节点才合并；不会把同一章和它覆盖的小节分到不同批次重复阅读。
- 任务卡显示总批数、保存批数、处理节点数及整体进度。所有批次保留同一任务的模型、推理强度、前台／后台和串行／并行设置。
- 串行按启动时目录顺序处理；并行只在当前批次启用最多两个独立节点工作器，并继续服从全软件并发开关和模型请求上限。批次本身不同时执行。
- 定位任务完成全部选定批次后，一次安排可用节点阅读；不逐批建立相互重叠的整章／小节阅读任务。不能可靠定位的节点仍等待核对，不把猜测标为已确认。
- 同一定位任务的 AI 辅助维持最多六个不同标题疑点的预算，包含所有批次；重试同一疑点复用已保存模型步骤，不为每一批另开六个配额。
- 集中核对允许一次确认最多 2000 个已核对建议，仍先检查每个原页版本，再在一个数据库事务中提交。任一版本冲突时整次不确认，没有自动代替用户批准。

## 恢复与资源边界

- 每个阅读批次完成后保存检查点；批次内部原页提取、图像核对和模型步骤继续复用原来的检查点。
- 每个定位批次把范围、证据、结果和提交后的目录版本同时写入。崩溃后可判断该批确已提交，不重复应用、不丢掉后续批次。
- 暂停后等待正在执行的步骤保存，停止启动新步骤；重启后手动暂停保持暂停。继续时跳过已完成批次；取消不再启动后续节点，已完成笔记保留。
- 任务所选页范围、原文件或目录发生冲突时停止，要求重新选择；不会刷新版本后把用户手动修改当成当前任务的旧授权。
- 当前批次才建立工作队列和页面几何缓存。页面缓存保存在磁盘并在批次之间复用，每批的定位器和模型客户端执行完释放。
- 进度接口只携带当前／最后一批的详细结果及全局计数；所有节点笔记和边界依据仍在节点记录与检查点内。既不删掉已完成记录，也不在每次轮询传输全部批次的结果列表。

## 打开验收

1. 从 Windows 通知区托盘完全退出旧版 StudyForge。
2. 双击工作区根目录的 `验收最新版.vbs`。
3. 进入“全局书库”，选择目录超过 200 个节点的书。
4. 点“全选本书目录”，选择前台／后台及串行／并行，再安排定位或阅读。
5. 查看任务卡的实际批次变化，尝试暂停、继续，并在节点内查看已保存笔记与定位依据。

手机刷新电脑提供的工作台后使用相同功能，服务工作缓存更新为 v19。源码验收入口启动当前代码；旧安装版不会仅因源码修改自动升级。
