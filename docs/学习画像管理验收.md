# 学习画像管理验收

本项完善用户对跨对话画像的控制与证据区分；按约定未打包，也未推进复习、托盘、更新或模型目录等下一项。

## 打开和验收

退出旧版窗口，双击项目根目录 **验收最新版.vbs**。窗口标题带“源码验收版”，使用原有本机资料与设置；首次启动自动添加控制表，不重写原聊天或答卷。

在左侧打开 **学习画像**：

1. 搜索知识点、判断或原话，选择作答、自评、聊天、接触范围、偏好等来源。每页30条，可查看超过旧版最近100条限制的记录。
2. 点击 **查看依据 / 纠正**。原始判断、引用原话、学生发言或原记录并排显示；能区分资料通读、学生自述、聊天观察与作答。
3. 填写新的判断并保存。界面注明 **用户纠正（未验证）**；原话及原评估不被改写。自动刷新不覆盖未保存的填写内容，也可恢复原判断。
4. 点击 **移出画像** 并确认：这条判断与对应评估分数停止参与后续教学。切到 **已移出画像** 可查看并恢复。
5. 用同一知识点继续问导师或新建讲解任务，检查是否采用你的纠正，是否停止依据已移出的记录评估你。移出某次高分后，评估参考按剩余有效记录重算；新作答仍可以建立新证据。

管理操作不调用模型，也不生成额外文档。原始对话、试卷成绩和资料文件保留；“移出”是停止参与画像，**不是彻底清除本机历史或删除资料**。

## 分数与证据边界

| 来源 | 用于画像的含义 | 是否算作答评分 |
| --- | --- | --- |
| 导入 / 通读 | 资料涉及哪些知识，不说明学生读完或学会 | 否 |
| 聊天观察 | 有学生原话的暂定理解、困难、偏好或建议 | 否 |
| 自评 / 理解问卷 | 学生认为自己掌握什么、哪里困难 | 否 |
| 用户纠正 | 学生对原判断的当前补充，尚未验证 | 不改变原成绩 |
| 做题 / 费曼讲解 / 运行判题 | 已保存的评估记录，仍受题目、评分和条件限制 | 有分数时参与参考 |
| 仅静态代码审查 | 运行成绩尚未确认 | 否 |
| 早期汇总 | 缺少对应逐条证据的旧数值 | 明确标记局限，可移出 / 恢复 |

自评不提高或降低**作答参考分**。2026-10-07 新增**综合学习参考分**，默认按作答参考分80%与最近有效数字自评20%计算，可在画像中调整自评权重0–50%。两项分数同时显示，实际试卷成绩和80分过关条件依据作答。只有自评时显示**自评参考 · 未测验**，不会把内部兼容存储的0显示成能力0分。理解困难问卷的文字意见不自动伪造数字分数。详见 [回收站彻底删除与自评综合分验收](回收站彻底删除与自评综合分验收.md)。

可追溯记录分别平滑汇总做题/编程与费曼评分，再按0.6与0.25的相对权重合成参考分。这只是便于教学适配的统计，不是经校准的能力尺度或长期掌握概率。一次79或80分仍不能证明稳定能力；原习题的评分和费曼流程未在本项改变。

存在可追溯明细的知识点只采用有效明细，不把无法拆分的旧汇总混回。因此当前参考分可能与旧版不同。没有明细的旧知识点显示 **早期汇总 · 缺少逐条证据**，可单独移出、恢复；新的明细优先于早期汇总。

提示使用、是否独立完成、延迟保持和跨情境迁移尚未自动可靠测量。你可以在纠正中注明“借助提示完成”等事实，导师会按自述处理，但本项不假装已经建立完整的能力测量系统。

## 生效与失败处理

- 导师、讲解、习题、编程作业和 MCP 读取采用有效画像。检索按当前知识点和标签跨项目进行，不把物理记录强加到哲学或其他材料。
- 用户纠正优先于同条旧判断，不能作为原资料事实或客观掌握证据；当前具体任务要求仍优先。
- 已移出记录给导师附加简短的排除说明，避免从历史对话重新采用旧判断；不重新发送移出的判断正文或分数。
- 用户控制过的事件停止后台重试；在途后台结果不能根据相同事件改名后重新建立判断。其他已有判断可单独管理，新聊天/新作答可产生新证据。
- 使用版本号处理同时修改：旧页面保存返回冲突，当前填写内容保留，不静默覆盖新版本。关闭后重新打开核对。
- 新生成任务采用有效画像；重启恢复生成任务时检查画像版本，后续章节及出题也重新核对。已经发给模型的请求和已经完成的讲解不会被这次操作自动撤回或重写。
- 依据接口只返回原记录、学生发言和已记录的反馈，不返回事件任意附带的私有答案、评分标准或工具历史。较长学生发言只在窗口展示前24000字符，并显式标记截断。
