# 手机作业提交与针对性补讲

2026-10-09 源码更新，尚未重新打包。手机与电脑使用同一套题单、提交、评分和成果记录。

## 打开和进入

从 Windows 托盘彻底退出旧版，双击项目根目录的「验收最新版.vbs」。首次连接手机按《手机连接与按范围解析验收》安装连接证书、配对并在电脑确认。

手机顶部新增「作业」。专注模式仍只保留对话与输入区，可以从输入区的「⋯」进入「提交作业 / 查看错因补讲」。

## 一条完整的学习流程

1. 在当前项目打开一份题单，逐题写出答案及思路。不会的题可以明确写出卡点；空白不能算作完整提交。
2. 也可以选择已经完成的答题文件，再点击「识别到答题框 · 不提交」。选择文件本身不触发识别；识别不会补全答案或自动提交。填入识别结果后，需要重新勾选完整作答确认。
3. 普通知识题可说明是否查阅笔记，默认「未说明」，不会擅自当成已经独立完成。编程题按照题单语言读取和提交代码，不要求统一使用 Python。
4. 确认提交后，电脑保存完整作答并本地导出第一份 **原题与答案解析.docx**。不等待批改模型完成，解析链接立即出现在作业窗口。
5. 导师在电脑后台批改、核查评分并定位失分原因。可以关闭作业窗口，继续聊天或者处理其他资料。
6. 证据不足的失分题进入错因问卷；**第二份批改文档暂停交付**。原对话的输入区显示入口，后台任务区同样提供「填写错因问卷」，不会用通用「继续」按钮跳过问卷。
7. 问卷可多选概念/术语、前置知识、动机、方法选择、独立论证、计算/实现，也可以选「仍不确定」并写补充。草稿立即保存在手机，短暂防抖后同步到电脑。刷新后重新打开题单可恢复。
8. 问卷提交后，恢复同一批改任务，复用已完成的评分，随后提供独立的 **批改与错题讲解.docx**。每道失分题包含错因、依据和相应补讲。
9. 原有严格低分流程需要费曼讲解时，可以直接在手机提交。未通过后保留再次讲解入口和具体反馈；通过后由原有流程安排进阶题。可选修复流程也能在手机发起修复练习。

## 编程作业

按现有判题器支持 Python、JavaScript、TypeScript、C++、MATLAB 和 Wolfram Language。文件后缀根据题单改变；点击读取代码仅预览，不执行、不提交。

代码文件沿用电脑端的编码识别，保留 UTF-8、UTF-16、GB18030/GBK 中文。单个代码文件上限 2 MB，普通作答识别文件上限 100 MB；手机网关为文件上传保留 multipart 封装空间，不把大作答文件误判成超过 2 MB 的普通文字请求。

Docker 未运行时仍可获得静态代码反馈，但界面明确显示尚未完成运行验证、没有最终分数。不能把模型看过代码当成程序已经运行正确。

## 恢复与隔离

- 作答草稿按项目和题单保存在手机；换题单或刷新不会把草稿带到另一份题单。手机草稿尚未提交时，不代表已同步成电脑端完整作答。
- 错因问卷由电脑保存，手机另有本地草稿备份。问卷提醒只显示在原提交对话；手动打开项目里的题单，可以查看其来源对话和反馈。
- 项目切换清空旧项目的作业列表和提醒。提交时冻结题单、对话及模型，晚到的识别结果不会替换另一题单或已经提交的作答。
- 同一题单的相同完整提交复用既有记录，不增加一次评分。失败重试沿用电脑端恢复流程；已交付的解析继续保留。
- 完整提交前不显示参考答案。下载、问卷和编程接口仍需要有效手机配对；新增接口不开放桌面设置、文件权限或项目删除。
