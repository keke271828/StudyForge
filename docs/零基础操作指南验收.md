# 零基础操作指南验收

## 交付目标

把中文指南直接放在 StudyForge 中，用户不需要找工程文件、懂 API 或阅读开发文档。先完成一次学习流程，再按需求查阅详细操作。

## 入口与内容

- 电脑左侧下方「使用指南 · 零基础上手」，以及 F1；运行环境设置中提供第二入口。
- 手机配对页「第一次连接？查看操作指南」，已配对后的「学习选项」中也可打开。
- 17 章：首次使用、界面与入库/解析/通读、AI 配置、项目与对话、按范围读取、导师交流、教学选项、成果、理解反馈、作业、画像、学习路线、权限与联动、安卓连接、后台与更新、外观与快捷键、常见问题。
- 目录跳转、正文关键字搜索、无结果提示、三份可复制示例与问题反馈模板、电脑和手机各自可用的功能跳转。
- 手机阅读正文后可一键返回目录与搜索。支持浅色、深色和大字设置；正文使用独立底板，避免自定义背景干扰。

## 实现边界

内容位于 `web/help/guide.html`，由电脑和手机共用。`web/user_guide.js` 只管理帮助窗口和明确点击的导航，未添加聊天消息、重新解析、自动生成、模型调用或自动修改学习资料。

手机仅增加五个固定帮助资源入口；指南 HTML 允许同源嵌入，其他页面维持禁止嵌入。未配对手机可以读连接说明，但不能使用需要登录的学习功能快捷入口。原有 API 登录验证及静态文件范围保持有效。

手机服务工作线程更新公共资源缓存；学习内容与认证响应不进入缓存。公共指南可随已缓存页面离线查看，资料处理仍要求电脑在线。


打包资源的五份指南文件与源码逐个核对哈希一致。实际运行验证：

## 限制

这次验证针对指南及其接入，没有使用真实外部模型重新评价全部教学成果，也没有替用户在真实安卓手机上重装证书或执行安装向导。更新发布地址仍需正式接入；指南已明确说明。
