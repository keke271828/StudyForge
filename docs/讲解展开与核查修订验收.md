## 已采用：快速核查修订的格式定位修复

### 复现的问题

先前真实核查中，原句写“A 与 B”，模型返回的定位句写“$A$ 与 $B$”。内容基本逐字相同，仅单个字母的数学排版不同；旧代码无法定位。同一问题的多处修订必须整组应用，因此其中一处失败后整项未写入，仍保留待核实警告。

### 现在的行为

1. 逐字匹配仍优先；多次逐字出现时不猜测位置。
2. 长中文普通句子里，最多8处 `$A$` 一类单个ASCII字母标签允许识别缺少美元定界符的写法。句子必须在唯一普通段落位置，且有明确句首边界、完整句尾。
3. 不归一化文字、空白、数字、公式内容、符号大小写、上下标、导数符号、多字母、LaTeX宏或其他公式写法。不对代码、标题、列表、表格、原文引用、来源位置和网址使用这种别名。
4. 同一问题仍整组应用或整组保留。定位失败、冲突、结构受损、只改排版而不修实质问题，均不记为解决。
5. 成功修订保存 `local_correction_anchors`：匹配方式、原稿Unicode位置、模型定位句与实际原句的SHA-256。格式别名与逐字匹配明确区分，不在该记录另存私有原句全文。
6. 应用建议不代表观点正确。原始核查的 `passed=false` 保留，成品仍注明修订后尚未再次独立复核。

修复作用于之后新生成并选用**快速**核查的成果；不自动改写既有文档。无新增模型核查、全文重写或后台任务。“极速”仍不额外核查，平衡和严谨仍按原有流程。
