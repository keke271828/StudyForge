# 首次讲解对照与数学核验工具验收

完成日期：2026-10-16。接续首次讲解、审查输入和教学质量改进。当前源码可验收，本轮未打包，没有改动已安装版本。

## 实施判断

没有采用新的证明讲解模板。相同资料、当前要求和模型条件下，4组8次真实请求未显示稳定优势，其中柯西追问的候选明确写错“B>0意味着向量同向”。正点积对非零实向量只约束夹角在 `[0°,90°)`，包括同向0°，不能推出同向。

这轮改为增加实际数学核验能力，而非继续叠加固定讲解或审查模板。现有教学规则版本保持；共同 Agent 规则只加入按需使用本机工具及其边界的简短说明，没有新增固定审核步骤。

## 可使用的能力

`sf_check_math` 注册于共同 Agent 工具表，原生 DeepSeek／兼容服务和 Codex 的工具接口均可见。导师、讲解与私有习题／批改分支可用。私有工具值继续只返回当前模型，不发布到公开记录；后台画像整理维持原有无工具路径。

- 精确有理数：十进制、分数、加减乘除、括号与 -32 至32 的整数幂；幂写作 `**`。每批1–16项。
- 实有理向量：同维1–32维，精确点积、模平方、Gram差、线性相关、同向／反向；夹角与余弦为近似值。
- 单独区分零角、锐角、直角、钝角、平角；零向量方向与夹角未定义，不能仅凭零点积强行给几何角度。代数正交应遵循教材定义。
- 近似角因浮点精度显示为0°、90°或180°但精确分类不在该端点时，明确返回精度提示；不得据舍入结果改写精确方向。
- 解析受限 AST，不使用 `eval`、符号表达式执行器或任意代码执行；拒绝变量、函数、无理数、超限算式、零除等。输入字符、节点、维度、整数幂、结果大小均有限制。
- 在工作线程执行，避免在主服务事件循环同步完成较复杂的数值计算。工具无文件读写或网络请求，只读可用；关闭总工具开关时不可用。
- 公开工具活动只保存操作类型、状态和范围，不保存核验输入或数值结果；私有作业的格式错误不复制包含输入值的校验细节。工具关闭／权限原因不被统一错误提示遮住。

模型按需选择调用；可明确要求核算。工具只验证给定数例，不证明一般定理、不确认题意，也不保证模型准确转述。调用后的模型续答会带来额外耗时；每项算式不必单独发起模型请求，没有工具调用就没有这项额外往返。

## 真实模型实验

服务实际返回 `deepseek-flash`，推理强度 high，关闭联网。没有代替用户操作网页端。

### 首次讲解规则对照

4组8次真实请求，每臂1次；仅替换共同证明讲解规则，使用同资料与同要求，工具关闭。三题使用实际文档讲解提示构造，一题为导师追问组件，不是整本扫描书或视频的完整任务。

| 题目 | 现有规则 | 候选规则 | 人工判断 |
|---|---:|---:|---|
| 极限唯一性、取一半与最大门槛 | 42.73秒 | 36.62秒 | 现有版实际数列演算和来源位置更完整；候选无稳定优势 |
| 柯西不等式、固定 t=1 的缺口 | 33.78秒 | 32.65秒 | 候选将正点积当同向，明确不采用 |
| 高斯定律与净通量 | 23.87秒 | 27.80秒 | 两者基本反例均可读，通量单位交代仍可改进 |
| 大样本、显著与因果 | 29.93秒 | 25.23秒 | 主线均有帮助，统计与证据条件措辞仍有过强之处 |

保持原样输出、要求、输入和请求指标。人工评阅不构成经过校准的教学评分；本组不是盲评、未重复，不能据此推算普遍提速或准确率。

### 实际 Agent 核验

4份回答，每份先调用本机工具再续答，共8次真实模型请求、10次本机工具调用。导师路径使用原生Agent，文档路径使用实际讲解函数和Agent循环；都明确要求使用工具。两种角色输入有差异，不将它们当同输入质量排名。

| 场景 | 角色 | 总耗时 | 模型请求／工具调用 |
|---|---|---:|---:|
| 反例与精确分数 | 导师 | 14.05秒 | 2／2 |
| 反例与精确分数 | 文档 | 17.44秒 | 2／2 |
| 0°、180°、零向量 | 导师 | 12.66秒 | 2／3 |
| 0°、180°、零向量 | 文档 | 11.63秒 | 2／3 |

算式与具体方向结果正确。初接入回答仍忽略0°端点，工具分类和返回提示随后完善。边界复测主要数值与结论正确，但文档仍出现半开区间称为闭区间、论证衔接和“否证反例”等措辞问题。没有润色原回答冒充模型已修正，也没有把这次工具成功说成整篇质量保证。有限实例不能承担来源核查、因果识别或完整证明审查。

## 打开与验收

1. 完全退出旧源码版，双击项目根目录的 `验收最新版.vbs`。
2. 设置中开启AI工具，选择现有模型与推理强度；只读权限可用。
3. 对导师说：“请用数学核验工具检查0.1+0.2和1/3+1/6，再核验向量(1,0)与(1,1)是否同向。解释数例能说明什么，不出题。”
4. 需要文档时，可将核验要求加入本次生成要求，保留所选审查强度。
