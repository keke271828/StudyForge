# StudyForge 0.4.3：学习完善与打包验收

2026-10-14，Windows x64。用户追加“做完打包”后，已生成最终安装包并完成打包程序、手机网关、导出与 GPU 加载复验。

## 打开新版

1. 从 Windows 右下角托盘完全退出旧 StudyForge；只关窗口会继续后台运行。
2. 双击 [StudyForge-Setup-0.4.3.exe](../dist/StudyForge-Setup-0.4.3.exe)，安装到原来的位置，再从桌面或开始菜单打开。
3. 也可直接运行 [StudyForge.exe](../dist/win-unpacked/StudyForge.exe)，但必须保留整个 `win-unpacked` 文件夹，不能只复制单个 EXE。
4. 学习资料、项目、聊天、画像、证书与配对设备继续使用原来的 `%LOCALAPPDATA%\StudyForge`。安装配置保留用户数据；本轮没有替用户运行安装向导，也没有改动真实学习数据库。
5. 手机页面由电脑提供，电脑升级后刷新手机页面取得界面更新。保留原数据目录时沿用已保存的证书与信任设备；本轮验证了网关重启后的会话恢复，没有代替用户实际复测安卓移动网络。

程序本身包含 Python 后台、OCR、FFmpeg 与解析依赖，不需要 CMD、Python 或 Node 才能打开。模型服务仍需要原有配置；Codex 模式使用本机 Codex 环境。手机跨网连接仍需要电脑运行及原来的 Tailscale 连接条件。

## 这版纳入哪些改动

本安装包包含0.4.2之后至本轮结束的源码，包括学习理解检查、错因补讲与定向再练、讲解要求与审查修订衔接、书库引用来源记录、长对话分页及界面／资料准备与画面复用优化。各项的实际验收和限制仍以对应记录为准，并非本轮重新完成了全部历史需求。

本轮新增“设置与联动 → 模型与语音 → AI 服务 → API 连接方式”：默认沿用环境配置，可主动切换直接连接并保留证书验证，选择立即保存；API目录、普通和流式请求使用同一后端选择，配对手机的任务也使用电脑后端。Codex与Gemini账号入口继续使用各自网络配置。已有连接不中途换线路。

本机实际目录探测出现环境代理超时、直连成功，因此提供这个选择；这不是整体模型生成时间或内存已改善30%的证明。修复连接诊断结束后的客户端清理、设置恢复及较早响应覆盖问题，软件内指南同步说明使用方法。

## 七种教学模型的实测

实际测试七种服务组合，保留32份完整回答，覆盖证明构造、哲学概览、净通量误解、因果推断和编程概念纠错。另有5次真实调用未取得完整正文、9条发出模型请求前的测试记录器错误，单独保留，不当模型教学能力分数。

- 重点证明与深入讲解：本批任务中优先考虑 GPT-6 Astra／GPT-6.1 Sol；解释较完整，也更慢。
- 日常概览、简短纠错与效率：GPT-6 Sol 较紧凑，但证明开头也有需修正的措辞。
- 不经Codex的重点讲解：DeepSeek V4 Pro 是本轮较好的候选，因果不确定性等仍需核对。
- V4.1 Flash 有可用的证明与物理讲解，概览仍偏长；缩短提示词的试验产生逻辑问题，已经撤回。
- Luna 出现公式闭合标记损坏，Kimi一份物理回答有实质概念错误；不据此认定这些模型所有任务都差。Gemini本轮未实测。

没有改用户的默认服务、模型或推理强度。比较的是实际服务组合：Codex含原生代理规则，Kimi使用默认推理，其他用high，预算不等价；每题仅少量采样，不能作稳定总冠军、长视频／整书质量、批改能力或学生长期学习效果认证。

打开 [多模型实际对照](../build/model-teaching-20261014/多模型教学质量实际对照.html) 可隐藏模型名称独立判断，再查看评语、耗时、冻结输入，下载每份原始回答。页面可离线打开，不调用模型。详细方法与缺陷见 [多模型教学实测](多模型教学实测与API连接方式验收.md)。

## 打包去重与GPU保留

首次候选包包含重复CUDA运行库，安装包1,933,542,463字节。最终打包只移除**4个字节完全相同的嵌套DLL副本**，共976,797,920字节；保留加载目录的一份，其他运行库、三份许可证与清单保留。逐文件比较大小和SHA-256，不按名称盲删；内容不同、没有明确保留副本或目标不明确时不去重。

最终安装包1,367,871,383字节，约1.37GB，相比本轮首次候选包减少565,671,080字节，约29.3%。GPU组件使它比旧0.4.2包更大；这是安装和磁盘占用的优化，不代表运行时RAM下降29.3%。

去重前后，打包后台均使用本机同一份已缓存small模型执行真实CUDA短静音识别，均成功；清除外部CUDA目录、系统Python/Node路径，不下载模型。只证明实际GPU加载与该短任务可执行，不是长视频耗时或转录质量测量。去重前后桌面和后台EXE字节相同，改变的是重复库文件布局。
