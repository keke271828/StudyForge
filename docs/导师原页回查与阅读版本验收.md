# 导师原页回查与阅读版本验收

2026-10-21。继续知识库优化。本轮修复导师按页回查的历史依据，保留实际阅读版本、返回页和字符范围，同时改善手机上的多层滚动。属于源码交付，未重新打包。

## 一、问题复现

原先 `sf_read_library_node` 已能根据任务快照选择旧阅读版本，并按窗口返回文字；但保存检索导航时仅传递节点ID和请求页码，存在三个缺口：

1. 没保存实际阅读版本、模型和片段字符范围；请求页码也不等于真正返回了该页正文。
2. 保存时会从当前目录补填标题和范围。若读取后节点改名或范围改变，历史记录可能指向不同的目录状态。
3. 仅取到来源标题或偏移越过末尾，仍可能显示“已回查”，给人已核对原文的印象。

修复前8项针对性检查得到 **7项失败、1项通过**。失败记录位于 `build/library-tool-receipt-20261021/baseline.xml`。这验证来源记录的程序行为，不能理解为对模型理解能力的评分。

## 二、实施

### 同一次读取记录实际范围

`studyforge/library.py::read_text_window` 保留现有Unicode窗口和逐页SQLite读取方式，额外计算：

- 真正返回了文字的页；仅标题、空返回不列入正文页。
- 每页原文提取／OCR和保存的AI图像记录各自的字符起止、总长度与节选状态。
- 含来源标题的完整拼接流长度及本次继续位置。

全局偏移包含标题和分隔文字；每页的原文／AI层坐标分别计算，不能把二者混同。窗口仍是原有字符分页，可能截在句子或公式中间，需要时应继续读取上下文。

### 保存当时版本，不按当前状态补认

`studyforge/library_evidence.py::for_read_window` 使用这次读取时捕获的书籍、节点、阅读版本和真实输出，生成小型来源记录。记录复用现有版本 `library-reference-receipt-v1`，只对原页工具读取增加 `input_kind`、白名单读取窗口和另行图像复核标记。普通检索／成果记录的既有结构保持。

`studyforge/agent_tools.py` 将这份已准备记录交给原有检索历史保存。节点后来被重命名、调整范围或删除，不会改写历史读取的身份。原文和长AI笔记不复制到历史，只保留位置、版本和实际工具正文的SHA-256指纹。

原有隔离边界保留：无对话归属、私有批改、文档任务或不公开的分支，不写入学生可见检索历史。查看历史不将资料内容变成用户画像，也不计作已掌握或新的答题成绩。

### 两端显示

`web/source_evidence.js` 在“原页回查记录”中显示实际模型、版本、整理深度、精读问题、范围、原页／AI层字符位置和后续读取位置。AI图像记录不称作教材引语；另行图像复核输出也不并入原文指纹。

`web/library.js` 为旧回查记录明确提示：未保存实际阅读版本和字符范围，不能用当前书库补填。空正文记录显示“本次未提供”，不会显示成已回查原文。

实际手机截图发现书库区域有多层嵌套滚动条，挤占横向空间。`web/library.css` 调整手机学习选项：由外层选项页滚动，减少书库／历史的嵌套滚动，长来源详情继续单独滚动；窄屏内边距适当减小。电脑书库和现有按钮仍保留。

软件内指南同步更新；公共手机壳升为 **v63**。

### 原生工具与实际界面

独立数据夹具导入3页实际PDF，提取已授权的两页，建立旧版和一个较新的有效阅读版本。通过真正的 `AgentRuntime.execute` 分派4次原生工具调用：

| 场景 | 实际结果 |
| --- | --- |
| 第二页局部100字符 | 只记录该页原文第6–105字符，版本仍为旧版 |
| 仅保存的AI图像记录 | 原页OCR本次未提供；AI层为第1–66字符 |
| 偏移越过末尾 | 空字符串，不标成已读正文 |
| 完整返回这个缓存节点 | 实际两页原文与保存的AI层分别记录 |

每次保存的输入指纹都与真实工具返回正文一致。读取后将目录标题改为含HTML外观的字符串、末页50%改为60%，历史保持旧标题和50%范围，界面没有执行HTML。旧版模型与短版本号未被后来阅读版本替换。

最终实际Electron电脑页面及经过设备审批的HTTPS手机页面完成 **10项操作检查**：展开、真实滚轮、项目切换、返回、整页刷新、手机配对恢复、390／320像素无横向溢出等。手机学习选项真正打开后检查可见性和阅读宽度，未用隐藏DOM代替显示验收。

最终操作记录、截图和原生工具返回：`build/library-tool-receipt-ui-20261021-3/`。控制台错误0项，外部模型请求0次，学习事件／画像分数／文档任务／习题写入均为0。

这使用真实浏览器引擎和HTTPS配对，不是实体安卓触控、跨网稳定性或真实云模型自主工具选择验收。

## 四、速度、内存与限制

- 不新增固定模型审查轮次，不新增默认图像复核，不重新OCR或通读未选章节。
- 沿用逐页读取，仅记录实际返回页及坐标，不将整章和长笔记复制到检索历史。
- 新来源元数据会让工具响应略长；本轮没有测量其token开销或完整任务提速比例。
- 记录能说明软件给了什么，不能证明模型读懂、回答无误或学生已掌握。
- 本轮没有新增真实云端教学回答，不声称全软件内存、长视频速度、全库检索准确率或全部教学质量已解决。

## 五、打开验收

1. 在系统托盘彻底退出旧StudyForge，再双击根目录 `验收最新版.vbs`。
2. 在工作台引用一个已读书库节点，请导师回查指定页；在资料快选的“书库检索记录”展开“原页回查记录”。
3. 核对阅读模型、版本、页内范围、原文／AI层字符位置；切换对话后返回，记录应保留。
4. 手机连接同一源码实例并刷新，从右上角“⋯ → 学习选项 → 书库检索记录”查看。手机壳为v63。
