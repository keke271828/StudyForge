# 通读进度恢复与对话隔离

日期：2026-10-26。工作区源码更新，未重新制作安装器。

## 实际问题与修改

- 原来切换学习对话时只查询完成的阅读笔记，运行、排队、暂停、失败的任务没有恢复到阅读栏。现在按项目、对话、所选资料集合、AI 服务、模型、推理强度寻找最新的未结束阅读任务，恢复原任务 ID、进度及控制按钮。
- 恢复进度只读取小字段，不启动模型、不解析文件、不自动继续暂停任务。完成的笔记仍走现有原资料指纹与内容清单核对。最新任务已取消或完成时，不倒退显示更早的暂停任务。已删除任务不恢复。
- 桌面回到对话后重新跟踪正在运行的原任务；已暂停、失败的任务等待用户操作。阅读栏已排队时也禁止再次点击“通读资料”。
- 后台任务完成后，自动展开题单和刷新聊天记录要同时匹配项目与来源对话。等待列表刷新期间切换项目，会再次校验范围。本项目其他对话的任务通知会说明来源不同。
- 前端 taskUI.jobs 只缓存按钮、进度及状态所需字段；不保留讲解全文、完整聊天、答案或图像。已结束历史缓存保留最多 128 条，当前阅读/知识结构及活动任务不因这个上限被清除。完整历史仍在服务端数据库，通过成果区加载。
- 使用指南增加“通读时，可以切换对话或关闭窗口吗？”说明。

## 使用与限制

先从 Windows 托盘退出旧版软件，再打开根目录的 `验收最新版.vbs`。验收页面：`build/reading-restore-acceptance-20261026/通读进度恢复与对话隔离验收.html`。

本轮实际测了桌面界面重载，没有重新测试完整退出后重启服务、安卓实机、大视频/扫描书并发内存峰值或真实外部模型教学质量。缓存修复消除了一处不必要的全文常驻，不表示所有性能问题均已解决。退出软件或关机会停止后台执行，隐藏到托盘则可继续。原资料变更后的继续/重试仍沿用原有版本核对。
