# 网址与图片独立解析修复

日期：2026-10-09。修改已进入源码版；此前的 0.4.1 安装包未重新构建。

## 操作规则

| 资料 | 入库之后 | 部分解析 |
| --- | --- | --- |
| 网页、视频网址及由网址下载的资料 | 点“解析网址”；电脑也可直接点“浏览器读取” | 不进入范围窗口 |
| 已支持的 PNG、JPG、JPEG、WebP、BMP、TIF、TIFF 图片 | 点“解析图片”，识别整张图片 | 不进入范围窗口 |
| 本地 PDF | 点“范围”，选择文件页码、准确选文或全文 | 保留 |
| 其他文档 | 点“范围”，选择原文选段或全文 | 保留 |

电脑与手机仍先保存资料；上传或添加网址本身不启动解析。解析成功后引用原资料，图片保留原图及识别结果的位置。选段文档仍作为独立资料，原文档保留。

## 修复内容

1. URL 和图片的直接解析动作不打开部分解析窗口。资料快选、资料库、手机资料面板及提示文字按资料类型显示。
2. 后台拒绝对网址或图片创建页码、选段资料；网址下载成 HTML 或 PDF 后仍保留其网址来源分类。
3. 增加持久的 `origin_url`。旧记录优先从原始 URL 路径或导入任务记录恢复原网址。没有可追溯记录时不能凭空恢复网址。
4. URL 解析失败重试重新获取原网址，不读取已清理的临时路径。仅清理由这次导入器创建的无用副本，不删除用户原文件。
5. 电脑的“浏览器读取”在网址待解析时就可使用。浏览器关闭、导入失败或任务取消时旧资料条目保留；新资料解析成功后才移除旧条目。
6. 网络超时、HTTPS 连接失败及需要登录／验证的提示区分原因，提供重试或浏览器读取入口。保存链接不等于读到了正文。
7. 导师工具收到解析类型；已解析图片和网址不因问题里出现“第几段”而要求粘贴选段。由网址下载的 PDF 也不重新套用本地 PDF 页码选择流程。
8. 手机页面缓存版本更新到 `studyforge-mobile-shell-v6`，内置操作指南同步更新。

## 验证证据

- 59 项相关回归测试通过，覆盖原有 PDF 选页／选段、网址导入、失败重试、403、浏览器导入、视频导入与临时文件处理。
- 后续 24 项专项复查通过，包括新增的“PDF 网址在导师对话中保持网址类型”；最终 3 项存储与提示复查通过。上述测试有重叠，不累计为独立测试总数。
- 真实 Electron 电脑页面和 HTTPS 手机页面走通直接解析、失败重试、浏览器恢复及 PDF 选页；真实 OCR 识别图片文字，保留原图引用。界面检查不调用付费模型。
- 本机实测：先前的知乎链接拒绝后台读取；部分其他站点的后台 HTTPS 连接超时。桌面 Chromium 能正常打开同一个菜鸟教程页面并读取正文，表明本机存在“浏览器可访问而后台直连失败”的情况。网站登录或验证仍需由用户完成，不能保证所有网址均可自动读取。

## 如何打开本轮版本

1. 在 Windows 通知区域中对旧版 StudyForge 执行彻底退出，避免旧窗口和旧手机后台继续运行。
2. 到源码目录双击 `验收最新版.vbs`，打开本轮代码对应的桌面版，无需在命令提示符中保持窗口。
3. 添加一个网址，应显示“解析网址”和“浏览器读取”。上传图片，应显示“解析图片”，点击后不出现范围选择窗口。
4. 若后台读取超时或网站要求登录，在电脑点击“浏览器读取”，完成登录／验证并显示正文后点击浏览器导入按钮。
5. 用本地 PDF 选第 3 页，确认仍可单页解析。手机连接当前电脑版本后刷新页面，也应显示按资料类型区分的入口。

本轮修复未写入旧安装包；运行旧安装版时，手机也仍由旧后台提供页面。
