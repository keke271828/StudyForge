# StudyForge 0.4.6

Windows x64 本地 AI 学习工作台。

在0.4.5的任务恢复、阅读进度和新手指南基础上，本版增加：

- 知识结构任务按项目、对话、资料范围和模型配置接续，防止旧结果覆盖当前选择。
- 知识点原文、关系理由和边界说明支持公式排版，并保留原始文字供核对。
- 按论证支持、前置知识、概念对比、知识类比准备不同的导师追问；保留原草稿，不自动发送，同一问题不重复插入。
- 导师和文档共同保留给定数据的时间、状态与样本范围；补充条件先说明是假设，已有审查同步核对，不增加固定审查轮次。

安装方法：先从Windows右下角托盘退出旧版StudyForge，运行`StudyForge-Setup-0.4.6.exe`并安装到原位置。无需卸载或清理学习数据。手机页面由电脑提供，电脑更新后刷新或重新打开手机网页。

首次打开时可在软件内查看零基础操作指南。AI服务仍需自行配置账号或密钥。本版尚未配置正式自动更新源，未在线上传或发布。

下载使用`.exe`安装器；源码ZIP供开发使用。附带SHA-256文件可核对下载完整性。安装器未做商业代码签名，Windows可能显示未知发布者。

程序验收与真实模型样例分开记录。本次发布不表示所有教学回答无误，也不证明所有模型、长视频或扫描书都已提速。测试没有覆盖用户原安装的实际覆盖升级或安卓实机。
