# 知识联系定向追问

源码更新，未重新打包。0.4.5 安装器及其源码 zip 仍是上次发布的快照。

知识结构每条关系新增“请导师讲清这条联系”。论证支持侧重证明目标、构造动机和推理条件；前置建议说明具体在哪一步有用，不预先判定学生基础不足；概念对比解释判别方法和易混淆处；类比核对共同结构与不能类比的条件。关系边界标题随类型变化，对比和类比显示双向比较箭头，不再统一暗示推导方向。

选中联系或知识点后，把请求及至多两条去重的原文位置、完整短引补入当前聊天草稿。保留原草稿的空格和换行；重复选择同一问题不重复堆入。草稿触发原有保存事件，切换对话后可分别恢复。过期图谱、关闭的面板或已切换的资料不能写入当前草稿。

参考用可读文字显示，避免在操作中暴露内部节点编号和 JSON 参数。图谱理由明确标为待核对，以引用代码块隔开，原有画像过滤器不会把这部分当成学生自己的理解陈述。引用中含反引号时，自动使用更长的围栏，避免嵌套文本破坏引用边界。点击只准备草稿，点击聊天“发送”才调用原导师，不自动出题或评分。
