# 带来源的知识结构验收

本项实现资料知识组织，未打包。现有安装包仍是旧版。

## 打开与操作

1. 退出旧版，双击项目根目录 **验收最新版.vbs**；窗口标题应带“源码验收版”。
2. 加入或选用资料，等待通读完成，点击通读栏的 **知识结构**。
3. 第一次点击 **整理知识结构** 才调用当前选择的服务、模型和推理强度；打开面板本身不调用模型。
4. 搜索知识点或所属领域，点击节点查看解释、引用、人物归属及相关关系。
5. 点击来源按钮直接读取原文件对应位置；引用用灰色衬线字体，解释和教学建议用正文样式。长位置的显示窗口最多展示24000字符并明确标注截取，整理与生成仍读取完整原文。
6. 点击 **带回原导师继续讲解**，把要求追加到原输入框，保留之前的要求、资料、通读和对话；由你选择是否发送。

## 关系与证据

| 内容 | 含义与限制 |
| --- | --- |
| 原文知识点 | 由原文整理并附可匹配引文；引文匹配不证明 AI 的概念解释正确。 |
| 教学建议 | 从原资料提出的组织方式，明确标记，不冒充原文明说。 |
| 建议前置 A → B | 先理解 A 有助于理解 B，不是唯一顺序，也不能据此判定你缺少基础。循环关系不当作学习顺序。 |
| 论证支持 A → B | 某个论据、方法或概念如何支持结论，需要写出理由，不能把顺序相邻当作逻辑支持。 |
| 概念区别 | 说明为什么需要区分，避免仅因同名就合并。 |
| 结构联系 | 需要实质对应、原文锚点与明确差异；没有边界的类比不进入结构。不能以同构或负反馈标签断言因果机制相同。 |
| 人物与角色 | 区分讨论、提出、发展、普及。人物或角色没有在可匹配引文中出现时标为待核实；即使文字匹配，仍需核对归属语境，不能用它宣称发现史已验证。 |

每个节点和关系必须附本次所选资料 ID、实际位置与短引文。未知资料、伪造位置和无法匹配的引文被舍弃，面板列出需核对问题。阅读笔记、AI 画面分析和自己的讲解不能作为原文引文。

图像解析可辅助理解，原文锚点仍需来自原图标注、OCR 或字幕等资料文本；OCR、自动转录和采样画面仍有识别限制。没有可匹配引文时不能强行保存节点。

## 与导师、生成和画像的关系

- 这是资料结构，不是另一套导师对话。返回讨论继续原对话；聊天及讲解接收相同结构线索。
- 结构只辅助组织，后续生成仍读取完整原资料，遵循概览/精学/研究、概括性、学生当前要求与独立出题选项。
- 开始生成时，任务保存结构 ID 与具体上下文，后来重新整理不能改写已开始任务的输入；成果记录所用结构 ID。
- 结构整理不创建掌握分数、不判断学生已经学会、不自动出题或安排费曼考核。
- 结构整理仅用所选原资料，不自主联网、修改其他文件或发布额外成果。导师在后续讨论中的原有工具权限不受此影响。

## 缓存、失败和范围

- 资料未改变、模型及推理强度相同时复用结构；查看节点和原文不调用 AI。
- 更换模型后的整理使用新模型；**重新整理**会重新检查原文件，复用未改变的通读缓存，再发起新的整理。
- 同一资料与模型的并发请求合并到现有整理任务。失败可重试；重启将中断任务标记为可重新整理，不自动重复消耗模型请求。
- 重新整理前后核对资料哈希；变更或删除后，旧结构不能继续显示成当前原文的结构，也不会传给新原文的导师。
- 长资料按完整原文分部分整理，每部分最多12个知识点、18条关系，总览最多120个知识点；处理全文不等于结构穷尽全部知识。不同部分的同名概念不自动合并，跨部分关系可能未收录。
- 当前没有大规模概念自动合并、人工编辑或领域专家对关系的事实验证。提示词、JSON 校验和原文匹配不能保证完整、正确的知识图谱。

真实 Electron 实际点击检查：打开而不自动整理、整理、搜索、查看原文、人物归属、关系边界、带回同一导师、保留输入要求、聊天与生成的结构传递、成果记录和缓存复用。滚动原文后标题和关闭按钮保持可用，没有横向溢出或浏览器错误。

测试使用隔离数据与模拟云端，不修改真实资料、不消耗实际模型额度。测试验证功能和边界，真实教学内容仍需要用实际多学科资料验收。
