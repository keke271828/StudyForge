后台学习记忆 正在读取…

学习结束、空闲约 45 秒后，AI 会整理少量近期学习记录，记住疑问和学习偏好。你可以关闭它，或限制每天整理几次；整理会使用当时所选 AI 的额度。

记录自己的理解

自评掌握度描述你现在觉得自己理解到什么程度，主观难度帮助导师调整步骤与节奏。两者都供导师参考；自评掌握度还参与下方的综合分。使用与已有记录相同的知识点名称，才能合并到同一张卡片。

知识点评估

20%

作答参考分 × 80% + 最近有效自评 × 20%

综合学习参考分供导师、讲解与出题调整详略和难度；缺少一项时显示已有依据，只有自评会标为“未测验”。实际作业成绩和 80 分过关条件依据作答，不被自评改写。这个占比是可调的教学约定。

画像跨项目共享，聊天记录按对话隔离；只整理知识疑问、理解、学习困难、教学偏好、作答与自评。闲聊、软件操作和任务进度不进入画像。提示使用、独立论证与延迟记忆仍需更多证据验证。

02 / 模型与语音

AI 服务

导师与讲解共用学习对话中选择的模型和推理强度；选择会保存到本机。

选择后立即保存，适用于 DeepSeek 和 API 接入的第三方服务。直连保留证书校验；Codex 与 Gemini 账号入口沿用各自网络配置。正在传输的请求不会切换线路。

可以刷新模型列表，或填写服务商提供的模型名称。聊天和生成文档使用当前对话选中的模型。

使用你选中的模型识别完整音频。模型文件第一次需要下载；用显卡通常更快，是否可用请点上方检测。

03 / 外部工作台

Codex 与 DSH

配置一次后，就能在 Codex 或 DSH 的对话里读取本软件的资料、处理作业。下面有操作步骤和可复制的示例。

VS Code Codex
  1. 点击下方“配置 VS Code Codex”。
  2. 重新加载 VS Code 窗口或重启。
  3. 打开 Codex 对话，输入示例指令。
DSH Desktop
  1. 点击下方“配置 DSH Desktop”。
  2. 完全退出并重启 DSH Desktop。
  3. 在 DSH 对话中输入示例指令。

配置后不一定出现单独按钮。请把示例指令粘贴到 Codex 或 DSH 的对话中试用；它们需要和 StudyForge 使用同一个 Windows 用户账号。
