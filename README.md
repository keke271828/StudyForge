### 讲解方式

学习工作台上方提供 **概览 / 精学 / 研究**：概览读懂主线，精学理解方法动机和论证，研究辨析证据与适用边界。默认精学，导师与文档共用所选模式；模式独立于概括性、模型、审查和同步出题。切换保留当前对话与通读记录，下次发送或生成生效；已开始的任务保持原模式。成果记录模式，问卷补讲恢复该讲解的模式。具体验收见 [学习模式验收](docs/学习模式验收.md)。

通读后可点击 **知识结构**，按需整理知识点、建议前置、论证支持、概念区别与有边界的结构联系。点击引用可查看原文件对应位置，选中知识点可带回同一导师讨论；整理结果也会帮助后续文档组织。查看不调用 AI，相同资料与模型复用整理结果；资料变更或删除后旧结构失效。引文匹配不代表关系已获事实验证，不作为掌握分数。详见 [知识结构验收](docs/知识结构验收.md)。

聊天与文档生成使用同一个学习对话。Codex 继续相同的远端会话；DeepSeek 保存完整对话及内部工具结果。旧 Codex 对话首次启用学习工具时，会恢复已保存的聊天到支持工具的新会话，此后导师与生成共用该会话。生成直接接续学生的要求与讨论，不再调用导师交接；最终讲解保存回原对话，继续追问时可直接使用。点击生成时保存本次要求，学生原话和原资料仍是依据，不能把导师自己的回答当成学生已掌握的证据。

「成果文档」的任务卡片提供「暂停任务／继续任务」，覆盖讲解、普通习题、通读、知识结构、编程出题、习题批改、编程判题、费曼评审及修复/进阶练习。工作台通读栏、知识结构窗口及习题页面也有对应按钮。暂停会等待已发出的模型请求、容器测试或导出步骤完成并保存结果，再停止后续步骤；界面区分“正在暂停”与“已暂停”。继续复用模型结果、容器结果和已提交评分，不重复出题或评分。任务保留原项目与来源对话，资料、题目或评分依据发生变化时阻止复用旧步骤。

完全退出或重启后，上述支持恢复的任务显示「已暂停」，由你点击继续才重新执行；已保存的步骤复用，尚未完成或尚未持久化的请求可能需要重发。启动时清理已中断任务自己的批改锁，避免恢复被旧锁阻挡。隐藏窗口仍继续后台任务。文件上传、导入解析和普通导师流式回复沿用原流程，未添加任务暂停；旧版本缺少必要参数的任务只能重新发起。详见 [全部成果任务暂停与继续验收](docs/全部成果任务暂停与继续验收.md)。

资料加入学习对话只保存引用选择，不自动通读。上传文件和保存网址后先点击资料旁「范围」，选择全文、指定 PDF 页码或原文选段；只用一段时无需等待整本书解析。选定范围可直接向导师提问，也可主动点击「通读资料」整理阅读笔记，再提出讲解要求并生成。生成读取本次选择的完整原文范围，不使用截断预览，不自动扩到其余原书。未变更范围可复用原阅读记录，切换项目或对话恢复各自聊天、选材和阅读记录。长范围对话需要主动通读或进一步缩小选材；不是必须先读完整原书。

导师提示词针对前提、概念、论证与推导检查、直观解释、反例、边界和学习技巧作出具体要求；对话中适时主动确认理解，正式习题仍由用户选择。完整规则可阅读 [AI 导师提示词](docs/AI导师提示词.md)，对应 `studyforge/teaching.py` 实际使用的规则。对话支持 Markdown 标题、表格、列表、引用与代码块；LaTeX 行内 `$...$`、`\(...\)` 和独立 `$$...$$`、`\[...\]` 公式使用随安装包提供的本地 KaTeX 渲染，不依赖 CDN。代码中的公式字符串保持原样；无法排版的表达式保留供核对。

AI 导师面向哲学、社会科学、数学、物理、生物、化学和编程等领域，按原文的学科语境讲解。术语首次出现时解释概念、背景与例子；哲学及社会科学概念还说明主要提出者或发展者，归属不明时标记待核实。相关延伸应说明具体联系、共同结构与适用边界；补充背景和延伸单独标注，不把类比说成原文的结论。全文最后提供系统性总结。

涉及定理、证明、解题或算法时，对话与生成讲解共用一份思路教学规则：交代目标和假设，解释为什么选择方法、关键构造怎样帮助解决难点，展开可核对的推导，并说明背后思想与迁移条件。教学性的思路重建与有史料支持的发现过程分开；有错误的原证明会在保留原文及来源后明确纠正。关键依据不确定时，在允许联网的条件下检索并读取可靠来源，读取失败或仍无法确认时标明待核实。「概括性强弱」控制展开深度，不增加固定审查轮次；用户的简短、只用原资料等要求仍然有效。结尾“小结／全文小结”直接复用为系统性总结，避免重复生成。实施、实际纠错样例与局限见 [证明与解题思路教学验收](docs/证明与解题思路教学验收.md)。

讲解文档本身不留待答习题；未勾选“同步出题”时不会生成习题。勾选时单独输出习题文件，仍默认 DOCX。引用原文使用灰色宋体与引用底色，AI 讲解使用蓝色无衬线字体；Word、PDF、PPTX、思维导图、Anki 和 Notebook 采用各自支持的字体和颜色。纯代码与模型脚本保持可运行文本格式。只输出所选讲解格式及明确勾选的习题文件，审查和原文件读取记录保存在内部元数据中，不再额外生成 Markdown、JSON 审查或读取记录文件。

下载文件自动命名为「主题_文档用途_生成日期时间.扩展名」，例如「规训权力_AI讲解_2026-10-02_15-00-00.docx」。讲解优先使用文档主标题，习题、视频原文档和解析使用对应资料主题；旧成果下载时也使用可读名称，无需重新生成。日期时间使用本机时区，原有内部存储编号不会成为下载文件名。

「成果文档」支持按生成时间、名称和格式排序，排序偏好在本机保存。每个成果可重命名，列表与实际下载文件名同步更新，文件格式保持不变；删除需在按钮上再次确认，删除对应成果文件与记录，原学习资料、作业与作答记录保留。

1. 点击「新建学习项目」填写名称。在「资料库」创建按学科、课程或专题组织的分类，然后导入文件或公开网页、文档、视频网址。也可在学习对话中直接添加文件或网址；默认在导入完成后自动加入当前对话，这项行为可在设置中关闭。旧资料自动归入“未分类”，可在资料卡片中移动或删除。视频全文解析完成后可在「成果文档」下载带时间戳、转录文字及关键画面附录的 Word 原文档。
   明确选择网页全文解析后，知乎等需要登录或验证的网页可通过隔离的浏览器窗口读取；确认正文完整显示后点击窗口顶部「导入当前页面」。其他网址遇到 401/403/429 时也可使用「浏览器导入」，失败资料卡片提供重新导入入口。网页仍无法打开时，可保存为 PDF/HTML 后上传；软件不能保证网站允许访问。浏览器导入保存当前页面正文与来源网址，未识别的图像会标明需核对。
   视频网址自动识别 B 站 BV/av、b23.tv 短链接、所选分 P、常见视频网站及网页中的主要视频/播放器。只导入视频字幕（可获取时优先使用）、完整语音转录和抽取画面，不导入页面简介、评论、推荐、导航或弹幕；解析失败时也不会用网页文字替代视频。分离音轨与画面通过内置 FFmpeg 合并。需要登录或验证时，在软件打开的浏览器中确认视频可播放，然后点「导入视频内容」。只临时使用当前视频站点的登录状态进行读取，不将 Cookie 存入项目或发给 AI。一个链接导入当前分 P；没有指定时导入第 1 P。直播、受保护或站点拒绝读取的视频会提示上传本地文件，不保证所有网站都能下载。
2. 在「学习对话」右侧的“资料快选”中搜索资料、勾选单份资料，或一键选用整个分类，无需先前往资料库。可把本地文件拖到学习对话任意位置或右侧虚线框，直接导入当前项目资料库；导入分类使用右侧“新资料存入”的选择。已选资料按对话保存，新对话默认不选资料；项目中的其他对话仍可选择同一资料。生成文件出现在“本项目成果”分类，可手动选择并直接询问。在输入框底部选讲解格式、五档「概括性强弱」和是否同步生成习题。勾选习题时，其文件默认单独输出 DOCX；只有在「习题格式（特别指定）」中选择其他格式才改变。
3. 「成果文档」会自动更新生成阶段、进度及已用时间。每次生成重新打开本次选择的完整原文（完整文件或独立选段），不把选段扩为整本书，不使用「查看内容」的截断预览，也不先让模型概括原资料。超过单次处理大小的原文逐部分生成并按原顺序拼接，各部分独立按所选模式审查。Word 原生公式、表格与正文顺序、幻灯片备注和笔记本输出参与读取；PDF/图像使用原页与视觉识别，视频使用完整转录和抽取帧。成果卡片显示实际模型和读取字符数，并附原文件哈希与读取记录；自动识别缺失处会显式标记。Word 使用原生公式和中文字体，PDF 使用中文字体与排版后的公式。默认「极速」模式在生成时自检，不额外调用独立审查；可选择「快速」「平衡」或「严谨」。习题仍有独立的解题与审查流程。Word、PDF、PPTX、FreeMind 思维导图、Anki、代码、Jupyter、MATLAB、Wolfram Language 和 ZIP 均有输出器。MATLAB 与 Mathematica 文件未在相应商业软件中自动运行验证。
4. 在「习题与作业」填写全部答案或上传作答文件识别后核对。可领取三层思考方向提示，在「作答条件与低分处理」选择自主诊断修复或原有费曼进阶。完整提交后显示评分和解析；自主修复低于80分不自动加难度，可请原导师定位、做同难度新题或选题加入跨项目复习。画像区分作答、自评、提示支持和复习条件；分数与自报条件不等于稳定掌握。旧题默认保留严格费曼方式，复习及修复题默认自主修复。详见 [按需练习与复习验收](docs/按需练习与复习验收.md)。
5. 需要编程作业时，选择资料，在「习题与作业」选择 Python、JavaScript、TypeScript、C++、MATLAB 或 Wolfram Language，再点击「布置编程作业」。Python、JavaScript、TypeScript、C++ 提供无网络、限制内存及只读文件系统的 Docker 测试；先启动 Docker 并准备相应镜像。环境未就绪、旧作业无私有测试或选择 MATLAB/Wolfram 时只保留静态审查，不记最终成绩。严格费曼进阶保留原编程语言，生成失败后可继续且复用结果。
   出题会重新读取原资料。核查区分影响正确判题的实质错误与非阻断建议；性能说明、可选优化和合法输入范围外的处理建议不会直接拒绝发布。题意歧义、参考代码或测试错误会自动修订整份作业，最多两次，并重新独立解题和核查。仍无法确认时不发布并保存审查摘要。学生可见的审查摘要不包含独立算法、参考代码或隐藏测试。

## 资料格式

自动转录、OCR 和 AI 审查可能出错。应用保留来源定位、审查记录与「待核实」标记，供你对照原资料复核。

## Codex 与 DeepSeek Harness

设置页有「配置 VS Code Codex」和「配置 DSH Desktop」按钮，也有逐步操作指南及可复制的示例指令。连接 Codex 后，重新加载 VS Code 窗口，在 Codex 扩展对话中输入「请使用 studyforge MCP 的 list_projects 列出我的学习项目，再用 list_sources 查看资料」，即可检查工具是否可用。之后可让 Codex 使用 `read_source` 阅读资料，使用 `read_assignment` 读取作业，使用 `submit_code_file` 提交代码文件。作业卡片也能复制带作业编号的指令。Codex App Server 为软件内的流式对话、讲解和批改提供服务，需已安装并登录 Codex CLI。

DeepSeek Harness 连接按钮把 MCP 客户端配置写入本机 desktop 和 web profile，同时备份原配置；连接后完全退出并重启 DSH Desktop。在 DSH 对话中输入「请调用 mcp__studyforge__list_projects 列出 StudyForge 学习项目」，再用 `mcp__studyforge__list_sources` 和 `mcp__studyforge__read_source` 阅读资料。也可参照 `integrations/dsh-mcp.patch.yml` 手动配置。连接按钮位于 StudyForge，VS Code 和 DSH Desktop 不会自动出现同名按钮；MCP 工具通常显示在各客户端的工具列表内。安装版的连接配置直接调用自带的 `StudyForgeBackend.exe --mcp`；开发版使用 Python 绝对路径。换用安装版后，可在设置页重新点击对应连接按钮更新配置。

## 开发自检

运行 `python -m pytest -q`。端到端样例在 `scripts/` 下：`smoke_video.py`、`smoke_voice.py`、`smoke_generate.py`、`smoke_coding.py`、`smoke_codex_generation.py`、`smoke_codex_models.py`、`smoke_mcp.py`、`smoke_ui.js`。编程出题实测可运行 `python -m scripts.smoke_coding --model=你的模型ID`，使用隔离资料和数据目录。生成任务会调用模型并产生实际 API 用量。DeepSeek 出现连接错误时，可在设置页点「检测 DeepSeek 连接」查看原因，再选择 Codex 生成。

## AI 工具与权限（源码更新，尚未重新打包）

当前导师可调用文件读取、精确编辑、联网搜索、公开网页读取、图片与视频画面分析、绘图和文档导出工具。学习对话下方的「是否允许 AI 读取网页视频」即时保存，同时约束聊天与生成；默认关闭自主网页视频读取，主动导入视频不受此开关影响。视频使用字幕／转录及抽取画面，不会把简介或评论当视频内容。

Codex 接真实 App Server：每个学习对话使用独立临时会话。导师与讲解采用当前学习对话的同一模型、教学规则和公共消息；并行生成复制启动时的消息快照，独立工作目录、连接与工具协议避免互相覆盖，成果回到原对话。临时会话不写入 Codex 的历史列表，软件自己的完整聊天保存到本机并在重启后恢复。DeepSeek 使用本软件的工具执行循环，无需启动 Codex 或 DSH；两种服务共用工具权限。当前接入不等于复制某个 Agent 客户端的全部功能或保证不同模型具有相同能力。

「设置与联动 → AI 工具与权限」可关闭联网、文件修改、绘图或全部工具，也可设置读取和修改目录与调用次数。默认可读取当前所选原资料，只可修改项目工作目录；覆盖文件保留备份。联网优先知乎等学习平台，再核对原始来源，遇到登录或访问限制会提示浏览器导入。工具执行情况显示在导师回复旁，操作记录保存在本机。

图片生成需要单独填写绘图 API 密钥，Codex 登录不会自动提供绘图 API 额度。聊天中生成的 PNG 保存在成果列表并可在对话中显示、继续核对。生成讲解时，图片可嵌入 DOCX、PDF 和 PPTX，不另添 PNG 成果。普通文档生成仍只导出所选格式；聊天工具仅在用户明确要求时额外导出文件。

文档插图可按位置读取，视频抽帧保留时间；后续对话可以继续查看先前读过的图片。同名原资料不共用图片缓存。网页视频开关撤销后，缓存文件和抽取画面也不可继续自主读取；下载期间撤销会在转录前停止。习题题源检索也使用同一套联网设置。最新验收记录见 [学习 Agent 独立会话验收](docs/学习Agent独立会话验收.md)。

### 后台学习记忆（源码已更新，未重新打包）

「学习画像」现在保存跨对话、跨项目的学习证据：资料涉及范围、学生原话中的暂定理解与薄弱点、教学偏好，以及做题/费曼/编程/自评反馈。接触资料和聊天不会自动增加掌握分数；每条记录能展开查看依据，导师与文档生成会按当前知识点检索相关记忆。

默认空闲 45 秒后合并整理，最短间隔 15 分钟，每天最多 6 次，可在画像页调整或关闭。全局并行开启时低优先级整理可与前台共存；关闭时沿用前台优先的中断策略。重启恢复队列，使用原事件的服务和模型，无额外工具权限，不反复自我对话。费用并非精确硬预算，Codex 推理开销取决于所选模型和强度。详见 [后台学习记忆与画像验收](docs/后台学习记忆与画像验收.md) 和 [并行任务调度验收](docs/并行任务调度验收.md)。
