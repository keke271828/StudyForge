# 教学聚焦对照与导师回答保存验收

日期：2026-10-16。继续改进学习质量和成果交付；本轮为源码验收，未打包。

## 这轮的判断

用户希望回答能抓住自己的具体疑问，并在满意之后保留下来。继续叠加教学要求，或把已经满意的回答重新生成一次，都可能增加等待和内容变化。本轮先实测更紧凑的共同教学规则；候选未显示稳定优势，因此不替换生产规则。新增直接保存已完成导师回答的入口，减少不必要的重新生成。

## 真实讲解对照

同一 DeepSeek Flash／high，服务返回 `deepseek-flash`，6组12次真实请求，每臂1次；关闭工具和联网。导师组从实际聊天入口捕获公开背景、问题和当前所选资料，文档组使用实际讲解函数构造输入。两臂仅替换共同教学规则，保留其他模式、风格、语言、来源与学生要求。测试材料及已有对话背景均为合成内容，不使用用户真实聊天。

候选每组减少324个输入字符，4组更慢、2组更快，正文没有稳定变短。没有重复或盲评，不能将耗时差异单独归因于提示词，也不能认定整体教学质量提高。候选只保留在开发试验脚本，没有被生产代码导入。现有回答的缺陷也原样保留，未润色成“修好后的模型回答”。

原样输入、公开用量、回答指纹与最终回答在 `build/compact-teaching-real-20261016-1`；不保存私有推理正文。可打开的对照页包含全部12份回答和逐份批评。

## 新功能：保存为成果

- 电脑端和手机端，已完成且保存到聊天历史的导师回答底部出现“保存为成果”。用户发言、空白回答、已停止的半成品没有此入口。
- 可以填写名称并选择 DOCX、PDF、PPTX、FreeMind、Markdown、纯文本。这里只排版已有讲解；不生成新的卡片、代码、交互内容或新解释。
- 按回答ID、原项目、原对话和正文指纹固定版本，不使用保存时后来切换的模型或资料来重建回答。已进入队列的快照独立于之后的聊天编辑和删除；新请求仍须有可访问的原回答。
- 复用已有本机排版任务，支持暂停、继续、重启恢复、取消和换格式；重复点击及重复请求不创建相同的进行中任务。
- 文件归原项目，标明原对话，并进入该项目的资料快选，供手动引用；不会把文件放入另一个项目。
- 保存不重新调用模型、不重新读取资料、不重写或再次核查内容、不追加习题／问卷，不重复插入聊天，也不作为新的掌握证据。
- 老消息没有单独记录原模型和当时完整资料范围时，显示“原回答模型未记录”和当前保存的实际依据；不拿当前设置补填。仍可按原消息、原时间和正文指纹追溯。
- 手机使用现有配对及权限边界，只开放已公开消息的保存路由；跨项目、跨对话、已删除对话或正文版本变化会在创建任务前拒绝。

保存某条回答不能证明它正确。需要核查或改写时，先在对话中得到新的完整回答，再保存相应版本。PDF、PPT等视觉转换受现有输出器支持范围限制，原样Markdown最适合核对文本内容。

## 检验结果

- **113项最终相关去重回归通过**，记录为 `build/message-export-final-regression-20261016.xml`。覆盖六种真实格式、内容指纹、原项目／对话、版本变化、重复请求、原成果再次换格式、暂停／继续／重启、手机路由和既有对话恢复。
- 实际 Electron 桌面及配对 HTTPS 手机页面 **5项交互检查通过**，记录为 `build/message-exports-ui-20261016-2/ui-report.json`。手机采用320像素暗色视口，不是真实安卓设备验收。
- 将本轮真实浅复制回答的2045字符保存为Word，再通过手机页面保存Markdown；Word从入队到完成约1.77秒，Markdown约0.60秒。两次均零新增模型请求。这是保存现成回答的时间，不代表首次讲解、视频或扫描书任务提速。
- Markdown下载字节指纹与原回答一致；Word容器和正文中两次修改后的列表结果核对通过。未在Microsoft Word进行视觉验收。
- 保存后原对话仍为3条测试消息，没有新增理解问卷、题单或画像证据；切换项目、刷新恢复及原项目资料快选核对通过。
- 离线对照页逐组渲染12份回答，公式无解析错误、链接有效、电脑与手机宽度无页面横向溢出，不发送网络请求。两端保存窗口截图已查看。

这些检查不代表所有教学内容正确，也没有重新验收全软件总内存、完整长视频或长期学习效果。
