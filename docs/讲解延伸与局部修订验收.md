# 讲解延伸与局部修订验收

日期：2026-10-15。本轮源码新增，未重新打包；0.4.3 安装包不包含本项。

## 本轮决定

为了改善“广泛理解、重点学透”的教学质量，分别做了教师规则对照、现有文档审查对照及最终程序回放。

1. **保留现有教师规则。** 较简短规则、现有规则及增加延伸限制的候选，在四份材料上得到12份实际DeepSeek回答。候选没有稳定优势，未进入应用。
2. **扩充现有文档审查的检查范围。** 快速、平衡和严谨的已有审查请求核对新增结论的依据、例子是否仍解释同一对象、假设示意与事实证据的区别。请求轮次保持原选择。
3. **修复已经找到问题却因引号排版无法局部修订的断点。** 仅长的完整普通中文段落允许双引号直弯样式等价；其他内容仍须精确匹配。回放实际审查返回后，两处因果错误的原有修正可以应用。

这不是对所有教学角色、资料或模型的质量认证。日常导师与生成器的共同教师规则没有采用本次失败候选；本轮主要改动文档审查及修正交付，批改分数和学生能力判断没有因此重新计算。

## 具体教学问题

### 新增结论缺少依据

上一轮真实补讲在正确区分随机提醒与实际记笔记之后，又说不遵从“通常会把实际记笔记的效应往小里压”。题干没有排除提醒对成绩的其他路径，也未明确行为效应参数及必要假设，不能仅以“通常”替代依据。

研究背景参考 [Angrist、Imbens与Rubin（1996），第4.1节](https://users.nber.org/~rdehejia/%21%40%24AEM/Topic%2004%20IV/readings/angrist_imbens_rubin_JASA_1996.pdf)：随机分配与排除直接影响是不同的假设。本轮另外构造 `Y(z,d)=2d+γz`、一半依从者的合成模型：分配效应随γ可为1、4或−2，行为在固定分配下的效应保持2。因此缺少限制时，不能确定分配效应相对行为效应的大小或方向。这是本机核对的反例，不是现实实验数据。

### 例子改变了待解释问题

社会科学候选讲解用“为什么迟到”作为事件，但制度规则主要解释“为什么在意迟到、采取补救”。相关反应不自动成为该事件的解释。候选后来承认这种差别，却没有以同一结果展示多种解释。

两臂实际快速审查都没有指出这个不足。新增规则包含此标准，也不能据此称它已经稳定解决。该漏检连同原回答保留在对照页。

### 找到了问题但替换锚点不一致

扩充检查的实际审查识别了两处因果问题，并提出连续原段的替换。`before`把原文的ASCII双引号改成中文弯双引号，旧守卫未应用替换，保留了可见疑点。没有直接丢弃问题或谎称修正成功。

最终守卫在严格范围内识别这种样式差异。8份历史审查响应均通过最终程序回放；扩充因果审查中的两处修正完整应用，实际DOCX内容也核对通过，没有新增模型调用。

## 审查行为

- 核查“通常、往往、倾向”等表述是否有已知条件或证据支持；缓和措辞不能自行证明方向、大小或因果归属。
- 检查例子与主问题是否仍在解释同一对象，不以相关现象的解释替代原问题。
- 明确是假设的示意按其假设核对，不要求虚构例子有真实调查数据；例子也不能冒充现实证据。
- 疑点只限制相应断言，保留其他成立结论；信息不足与已被证伪分别表述。
- 保留原任务的学科、范围、详略、语言与风格；不能把未要求的扩展当实质遗漏。
- 快速仍为1次综合审查；平衡、严谨沿用原有修订与复核流程。极速仍无独立审查，不伪造新检查记录。
- 实际请求的审查保存规则版本与SHA-256，只代表请求过这些检查，不代表内容正确性得到认证。已完成／缓存的旧审查不补填新记录。

## 双引号等价锚点的范围

优先使用唯一逐字锚点。只有逐字匹配失败，且满足以下全部条件时，才考虑样式等价：

- 至少40字符、至少12个中文字符的完整单行普通段落，以中文句末标点结束。
- 仅ASCII双引号与中文左右弯双引号可对应；文字、数字、空白、单引号、导数符号及其他标点不归一化。
- 全文中样式等价候选只能出现一次，且必须对应解析器认定的普通段落。
- 公式、代码、反斜线表达式、HTML、来源定位、网址、表格、标题、Markdown列表和原文引用不能走此分支。
- 同一问题仍整组应用；锚点失败、含糊、多处重叠或仅改引号样式而没有实质修正时保留疑点。
- 整篇来源位置、引用与标题保护，以及代码／公式结构检查继续生效。应用成功仍明确标注“尚未再次独立复核”。

该处理不是模糊改写，没有新增模型调用。普通精确锚点沿用原匹配路径；没有据此宣称全应用内存或速度改善。

均使用`deepseek-flash / high`，合成材料、工具关闭；每格一次、未盲评，不是网页端或整个应用的重放。这里统计的是组件调用，不据此推定HTTP重试次数、完整长任务耗时或模型能力排名。

| 对照 | 实际结果与限制 |
|---|---|
| 教师三臂 | 候选在编程上较紧凑，但数学中把明确不可能的向量数据写成“不一定”，社会科学例子改变了解释对象且更长。较短教师规则也未稳定生成更短回答，因此不采用候选。 |
| 已知因果错误 | 现有快速审查未检出两处问题；扩充检查在1次审查中检出并提出修正。样式等价处理使两处修正可交付；单次差异不能证明稳定检出率提高。 |
| 例子换了问题 | 两臂均未检出，保留为未解决的教学质量问题。 |
| 原模态对照 | 现有审查把“可能影响”改成原文的“会影响”；新审查未改。模态解释有空间，不能将此组当成干净的误报率试验。 |
| 清楚的向量范围对照 | 两臂均保留7到17、两个端点取向及未给概率分布的结论，没有改动。 |

最终因果修正仍保留“两件事会同时松动随机化的比较”这一可能引起误会的引导语；两处段落应用成功不等于整篇已经重新复核。原文、问题与人工评语完整保留。

耗时逐项展示。扩充因果审查约84秒，原审查约38秒；另一原稿则约32秒与76秒。请求轮次未增加，不代表每次等待相同或普遍提速。
