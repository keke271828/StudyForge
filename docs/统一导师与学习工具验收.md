# 统一导师与学习工具验收

日期：2026-10-02。本次修改源码，未生成安装包；现有 0.3.4 安装包不含这些改动。

## 统一后的行为

- 学习对话顶部选择的模型、推理强度同时用于聊天与讲解，不再另选文档模型，也不调用导师交接。
- Codex 聊天与讲解继续同一远端对话编号。旧会话首次接入工具时恢复已保存的聊天，此后共用新的工具会话。
- DeepSeek 保留完整学习对话、内部工具结果和服务要求的推理字段；内部推理不显示给学生。
- 生成后的讲解保存回原学习对话，继续提问可使用文档全文。暂停恢复不重复添加文档或对话消息。
- 习题参考答案保存在学生对话之外，保持完整提交前不展示解析的原有规则。

## 工具与权限

共享工具支持原文件读取、目录查看、文本与代码创建、精确修改并备份、联网检索、网页读取、图片及抽取视频画面分析、绘图与文档导出。

网页视频开关同时约束聊天和生成，关闭时在下载视频之前拒绝操作；已有缓存也重新检查权限。主动导入视频沿用原流程。文件操作限于当前原资料、项目工作目录和用户授权目录；精确修改要求唯一匹配，覆盖保留备份。

检索优先常见学习平台，过滤明显无关结果。搜索摘要只作线索，导师须读取来源后核查；访问限制和无相关结果会如实返回。

## 验收证据

- 自动测试：162 项通过，包括原功能回归、同一会话的聊天与生成、长讲解上下文、暂停恢复、工具调用、文件范围、视频开关和答案隔离。
- 真实 Codex：合成因果资料 → 工具读取原文 → 创建文本文件 → 生成带概念表的 Word → 继续解释外部效度；全程同一远端会话。测试使用本机默认 `gpt-5.6-luna`，不代表建议用户固定使用该模型。
- 真实 DeepSeek：同一合成资料完成工具读取、创建文件、生成带概念表的 Word 和后续追问；使用 `deepseek-v4-pro`，共用保存的学习对话与内部工具状态。
- 真实 Chromium：统一模型选项、视频开关即时保存、工具执行状态、公式排版、受限图片与成果下载链接；未发现页面运行错误。
- 实际联网检索：中文测试词未取得相关结果，已过滤无关返回；准确英文概念取得相关来源。没有把空结果标为查证成功。
