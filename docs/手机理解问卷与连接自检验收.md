# 手机理解问卷与连接自检

2026-10-09 源码更新，未打包。根目录「验收最新版.vbs」启动当前代码，已安装的旧版 EXE 不会因源码修改自动更新。

## 手机讲解后的理解问卷

1. 生成讲解后，在手机「成果」中点击这份讲解的「哪里没懂 · 请导师补讲」。也可从输入区「⋯」进入「讲解理解反馈」。
2. 六类困难可多选：不懂术语；缺少前置知识；看懂计算但不懂构造动机；会套方法但不知道什么时候该用；能复述却无法独立论证；推理正确但计算或实现出错。
3. 「其他补充」填写具体公式、术语、步骤和自己的理解，便于导师定位困难。
4. 「提交并请导师补讲」先保存反馈，再由原对话的导师补讲；「仅保存反馈」只登记学习证据；「暂时跳过」不会调用模型或增加薄弱点判断。

问卷是可选的理解反馈，不是新的强制测验。只打开、填写草稿不会调用模型。提交是自报学习困难，不直接降低作答分数，也不自动追加作业。

问卷显示原讲解、原对话、原资料范围和原生成的教学选项。补讲使用原讲解范围和原生成模式/风格/语言，同时使用原对话当前选择的 AI 服务、模型与推理强度。切换到其他对话时不会注入问卷或串入补讲历史。

用户后来调整的选材和教学偏好仍保留，旧讲解的补讲不将它们重置回旧设置。手机从同项目其他对话打开反馈时，明确回到该讲解的原对话。

## 草稿、断网和重试

- 未提交草稿按问卷在手机当前浏览器保存，刷新可以恢复；其他浏览器看不到本地草稿。
- 提交内容与学习证据保存在电脑，可以从其他已配对设备查看。
- 导师补讲是电脑后台任务。刷新、切到其他对话或短暂断网后，可恢复进度；没有因为页面刷新重复调用导师。
- 失败后保存的反馈不丢失。显式重试不会重复添加同一份学生反馈或重复记入画像。
- 本次还修复电脑闲置时资料轮询写回旧选材的问题，避免它覆盖手机刚选择的原文选段。

## 连接自检和网络切换

电脑顶部「连接手机」→「连接自检」。手机 Wi-Fi IP 可选，用电脑真实网卡掩码比较网段；同网段不代表设备一定互通。

自检核对服务、端口、当前网卡地址、HTTPS 和 CA，以及可读取的 Windows 网络/防火墙状态。它只证明电脑本机访问情况，不伪称已经验证手机路径。

本次用户最初使用 `10.139.24.202`；换到个人热点后电脑变为 `10.64.60.164`，旧地址已经失效。用户确认新地址能打开工作台或配对页。页面超时与 CA 安装不同，不要求反复重装同一个证书。

当前网卡地址不在服务启动时的地址中时，面板隐藏旧二维码和配对码，提示「重新启用」。固定 Tailscale 入口可避开这种 Wi-Fi IP 变化，另见《固定私人连接与免重复扫码验收》。
