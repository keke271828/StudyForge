# 后台学习记忆与跨对话画像

本项仅实现学习记忆与后台整理，未打包，也没有推进托盘、自动更新或模型列表等下一项。

## 做了什么

- 导入资料：立即记录资料名称与来源，标记“接触记录”，不增加掌握度。
- 软件通读完成：排队整理通读笔记中的知识范围，保留阅读记录和资料 ID。笔记来自 AI，不证明学生读过或理解过。
- 学习讨论成功结束：记录学生原话、消息及对话 ID，后台提炼理解表现、具体困难、能力表现、教学偏好和教学建议。失败或空回复不触发整理。
- 做题、费曼讲解、编程作业与自评：保存已有评估的证据和反馈，不额外调用模型评分。编程测试未运行时记录“暂定”，不给运行掌握度加分。
- 同一次费曼讲解涉及重复知识点时，只更新一次该知识点分数。
- 记录存入本机 SQLite，在其他对话和项目中按知识点标签检索。标签必须出现在对应证据中；明确限定学科的偏好也按这个限定检索。
- 导师、讲解生成、普通习题和编程出题都会读取相关记忆。原资料仍须完整读取；画像和聊天不能替代原文，不能据此强行换成物理解释。
- 画像页分开显示评估记录、知识范围、理解/能力/薄弱点、教学偏好/建议，可以展开证据原话。

## 开销与前台优先

| 项目 | 当前行为 |
| --- | --- |
| 默认开关 | 开启，可在“学习画像 → 后台学习记忆”关闭 |
| 空闲等待 | 当前学习操作结束后至少 45 秒 |
| 最短间隔 | 默认 15 分钟，可设 5–120 分钟 |
| 每日额度 | 默认 6 次，可设 1–24 次，按本机自然日计数 |
| 合并 | 每批最多 6 个同服务、同模型、同推理强度的事件 |
| 输入 | 不超过 14,000 字符；阅读笔记最多 1,800 字符，长聊天保留开头和末尾片段，旧记忆最多 1,500 字符 |
| 输出 | 最多 6 条简短观察；DeepSeek 请求有 1,200 输出 token 硬上限并关闭思考模式；Codex 采用提示长度约束，保留原事件的推理强度 |
| 请求 | 一次整理，不启动循环审查或子代理自我对话；超时 90 秒 |
| 重试 | 不即时重复请求；失败等待最短间隔，同事件最多 2 次失败尝试 |
| 额度计数 | 失败、被前台打断和进程中断的尝试也计入每日额度 |
| 前台抢占 | 通读、导入、聊天、生成、批改等操作开始时中断后台整理，稍后恢复；前台不等待后台请求 |
| 重启 | 中断的事件恢复为待整理；已经完成的事件不会重新调用模型 |

这是调用次数及上下文规模限制，不是精确费用承诺。尤其 Codex 的推理 token 没有在此独立设置硬预算。每天额度耗尽时保留队列，不丢弃记录。

## 权限与判断边界

后台使用产生事件时所选的服务和模型，不改动导师/文档的学习对话。DeepSeek 直接请求 API，不依赖 Codex；Codex 使用独立的 ephemeral App Server 会话，不接入导师线程或历史记录。

后台没有 AgentRuntime、动态工具、联网搜索、执行命令、编辑文件或生成图片的能力。Codex 同时禁用原生工具及 MCP 路由，并使用只读沙箱。整理结果只写入应用自己的学习记忆表。

整理后的非接触记录必须引用对应事件的学生原话；导师的表述不能充当学生能力证据。粘贴的资料、题目或他人证明也不能证明学生理解。聊天判断统一标记“暂定”，不会覆盖做题、费曼和自评的分数。

记忆存于本机；后台整理时，会向所选 AI 服务发送受长度限制的学习片段和相关旧记忆。开关关闭后不开始新的整理，也不提交刚结束请求的结果。

记录和检索可以改进教学适配，不能训练或提升底层模型智力，也不能保证所有推断正确。片段没有覆盖到的内容不算“不会”；阅读记录不等于掌握。当前新活动会自动入队，旧评估分数保留，不自动对全部历史聊天发起昂贵重分析。

本页记录当时的后台功能验收；后续《学习画像管理验收》已替代最近100条、每组24条的界面限制，新增全历史搜索、分页、用户纠正及移出恢复，并将自评从作答参考分分离。相关教学检索仍查询全部存储的知识点，不会被大量近期无关记录挤掉。窗口关闭后的托盘持续运行属于后续项，此项只在后端运行时执行。

## 自检结果

### 自动化测试

最终完整回归：**240 个测试通过**。仅有现存 Starlette/httpx 弃用提示。

`tests/test_learning_memory.py` 覆盖：

- 重复回调去重、资料或聊天不增加掌握分数。
- 假造事件、假引文、导师原话及阅读内容被当成理解证据时拒绝入库。
- 跨项目检索、知识点标签、长标题、限定学科的偏好、较旧的相关记忆。
- 长消息末尾要求保留、多资料引用数量限制。
- 默认开关、额度参数、空闲等待、间隔、每日额度、失败退避与重试上限。
- 前台抢占、关闭开关后的提交拦截、进程恢复。
- 不混合不同模型事件；不追加评估调用、不泄露提交前习题答案。
- 实际聊天入口收到记忆；失败回复不排队。
- DeepSeek 无工具、无对话注入、无立即重试，输出与超时上限。
- Codex 独立只读临时会话、禁用工具和外部 MCP。此项为协议测试，未另花费一次真实 Codex 后台推理。

### 真实模型

运行 `scripts/smoke_learning_memory.py`，仅使用隔离的 `build/learning-memory-*` 数据。

第一次真实 DeepSeek 整理暴露了一个问题：模型把薄弱点写成长标题，用户后续只提知识点名时检索漏掉。修复为从证据中提取并验证知识点标签，再运行一次有输出上限的真实请求。

修复后的隔离验收目录：`build/learning-memory-0lc5c15i`。一次整理处理通读和聊天，产生 4 条记录。掌握度表保持为空，重复通读和聊天回调没有重复事件，模型未切换，也没有启动 Codex。其他项目提及“柯西不等式”可找回“构造二次函数动机尚不清楚”的记录；哲学讨论只收到通用教学偏好，没有数学薄弱点。

### 真实界面

运行 `scripts/smoke_learning_memory_ui.js`，通过隐藏 Electron 窗口检查：

- 画像分类与“接触记录/暂定”状态可见，原话可展开。
- 没有凭资料/聊天自动出现掌握分数。
- 后台开关能保存；轮询不会覆盖正在编辑的设置。
- 页面没有脚本错误，卡片没有水平溢出。
