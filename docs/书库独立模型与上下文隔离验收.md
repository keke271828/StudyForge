# 书库独立模型与上下文隔离验收

日期：2026-10-11。本项为源码更新，旧的 0.4.2 安装包不含这些改动。

## 打开与使用

1. 从 Windows 托盘完全退出旧 StudyForge。
2. 双击项目根目录的 `验收最新版.vbs`，打开当前源码版本。
3. 打开「全局书库」，展开上方「阅读模型」。
4. 默认「跟随学习工作台」：点击安排阅读时，复制当前服务、模型和推理强度到新任务。
5. 选择「书库独立设置」可以另选 Codex、DeepSeek 或已接入的第三方服务。模型可从服务目录选择，也可手动输入实际支持的模型 ID。
6. DeepSeek 可让扫描页核对使用默认视觉模型、阅读模型或指定的另一视觉模型。模型必须实际支持图片；选择名称不会让文字模型获得视觉能力。
7. 选择章节、阅读深度、前台/后台、并行方式并启动。任务卡显示保存的模型选择；之后更改设置只影响新任务。

手机在连接当前源码版电脑后刷新页面，使用同一书库设置。未配对设备不能修改模型配置。

## 上下文边界

工作台与书库使用同一模型，并不等于它们使用同一上下文。书库阅读只接收选中章节的原页、已完成的本节点分页记录及阅读要求，不附上工作台聊天或用户画像。跨项目共享教材和整理结果；聊天记录及各对话引用选择保持隔离。

独立配置不修改导师的模型或教学设置。导师回答时，可以通过本对话的书库引用/检索回查已读节点。讲解任务仍保留启动时的导师对话和要求快照。

目录识别、页码定位、本地 OCR 和语义检索有各自的本机处理流程；它们不会因为选择阅读模型而全部改用该模型。

旧任务未记录扫描页模型时显示“旧任务未保存画面模型”，不补填无法核实的历史值。新任务保存扫描页选择；改变视觉模型后会形成相应版本，不复用另一视觉模型的笔记来冒充本次阅读。

## 验证证据

- `build/library-models-final-tests.xml`：192 项相关回归通过，涵盖模型、书库、范围、暂停、检索、手机与指南。
- `build/library-models-client-tests.xml`：37 项 DeepSeek 独立运行、教学会话与连接进度检查通过。部分覆盖与上项重叠，不能将其相加当作独立功能数。
- `build/library-models-last-changes-tests.xml`：最后的模型注册表和指南相关检查 16 项通过。
- `build/library-models-ui-20261011-3/models-ui-report.json`：真实 Electron 桌面和已配对 HTTPS 手机 10 项交互检查通过，控制台错误为 0。
- 界面测试观察到 4 个模拟模型请求，确认独立模型、推理强度、暂停后原选择、第三方服务、手机配置及切回跟随模式确实改变实际请求。没有调用外部收费模型。

## 验证范围

这些检查验证设置、隔离和请求参数，不代表每个模型账号都已实际调用成功，也不证明更贵的模型必然提高教学质量。外部服务是否支持输入的模型 ID、推理参数及图片，以服务实际响应为准。

当前更新未重新打包；使用旧安装版不会出现本次新增选项。
