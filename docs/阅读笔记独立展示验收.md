# 阅读笔记独立展示验收

2026-10-04。本项源码完成，可通过根目录 `验收最新版.vbs` 打开，未重新打包。

## 原问题与修复

原 `showReadingNotes` 按钮直接调用 `message('assistant', ...)`，将整份笔记当作新回复插入聊天并滚到末尾。反复查看会反复插入，打断原有讨论。

现在点击按钮只打开本地的阅读笔记弹窗，展示当前对话已有的阅读结果。打开、关闭和复制都不提交聊天或生成任务。

## 可使用的功能

- 独立阅读窗口显示所属项目、对话标题和可展开的所选资料列表。
- 保留 Markdown 标题、表格、代码、引用、位置标注，并用本地 KaTeX 排版行内及独立公式。
- 正文单独滚动，底部的复制和返回按钮保持可见。
- 同一次运行中，最近 40 份阅读记录按对话/选材/模型/阅读 ID 记住滚动位置；关闭后再次打开恢复位置。
- 点击“返回对话”、右上角关闭按钮或按 Esc 关闭，焦点返回“阅读笔记”按钮。
- 切换工作区关闭阅读窗口；切换项目、对话、选材、模型或开始重新通读时，旧笔记关闭，避免显示错范围。
- 复制使用原始 Markdown 笔记，保留公式和来源标注；复制失败时在弹窗中显示原因，也可手动选中正文。
- 原有完整阅读记录继续保存在数据库；重启后恢复有效阅读记录即可查看，阅读窗口的滚动位置仅在本次运行中保存。

本项展示已有阅读笔记，不改变笔记生成提示词、讲解规则或文档格式。来源标注原样保留；显示位置不等于完成来源内容的事实核查。

## 实际自检

### 原生桌面贯穿

扩展现有项目多对话的真实 Electron 验收，在隔离数据目录进行两阶段测试，阶段之间实际停止后台，然后用新端口重新启动。

1. 在 A+B、B+C 两个对话分别打开笔记，核对其范围与当前对话选材一致。
2. 反复开关笔记，比较前后的聊天 DOM、聊天滚动位置、输入草稿、阅读 ID 和数据库消息，全部不变。
3. 对比全部模型请求数量，查看笔记不增加请求；后台重启后有效记录仍可直接查看。
4. 长笔记滚动后通过返回按钮、关闭按钮及真实键盘 Esc 关闭，重新打开恢复位置。
5. 更改资料、对话、项目及工作区时，旧笔记关闭；原有知识结构、聊天、成果引用/重命名/删除仍可使用。
6. 确认公式、表格、代码及引用节点实际完成排版，位置标注仍在正文。
7. 模拟浏览器剪贴板写入权限被拒绝，验证备用复制在当前模态窗口内选中完整笔记，并显示成功状态，不改草稿。
8. 检查普通窗口、1060×820 小窗口和 560×720 窄窗口，按钮可达、正文可滚动，无横向溢出。

## 打开与验收步骤

1. 从 Windows 右下角托盘退出旧版 StudyForge，再双击根目录 **`验收最新版.vbs`**，确认标题带“源码验收版”。
2. 打开一个已有有效通读结果的学习对话，或选择资料并完成通读。
3. 点击“阅读笔记”，确认笔记出现在独立窗口，原聊天中没有新增一条笔记回复。
4. 滚动笔记，点击“返回对话”，再次打开，确认阅读位置保留；也可按 Esc 关闭。
5. 检查原聊天、输入草稿和聊天滚动位置，尝试复制笔记。
6. 切换到另一个选材不同的对话，核对笔记范围；完全退出再打开后，查看恢复的阅读记录。
