# PDF 公式兼容性修复验收

2026-10-11。修复用户报告的 `\mathbb{Q}(\sqrt2)` 在 PDF 导出时失败的问题。

## 原因与改动

软件使用的 Matplotlib MathText 接受 `\sqrt{2}`，不接受同样合法的 TeX 简写 `\sqrt2`。原实现只对部分数字分数补花括号，导致正常公式被错误拦截。

新增按 TeX 单记号参数规则处理的兼容层：支持根号、可选根指数、分数、嵌套命令及常用数学字体/重音命令的等价花括号写法。保留未知符号与命令，交由排版器验证；不删除疑似 OCR 字符或猜测数学含义。已有花括号结构保留原意。

例如：

- `\sqrt2` 等价于 `\sqrt{2}`。
- `\sqrt[3]2` 等价于 `\sqrt[3]{2}`。
- `\frac\sqrt2\sqrt3` 等价于 `\frac{\sqrt{2}}{\sqrt{3}}`。
- `\sqrt23` 只能规范为 `\sqrt{2}3`，不能擅自改为 `\sqrt{23}`。

换用新的渲染缓存版本，正文、标题、引文和表格的 PDF 公式共同生效；PPTX 使用同一图像排版器，也获得兼容处理。Word 的原生公式转换保持原路径。

用户粘贴的报错末尾含 `V}`；当前本机失败记录中未找到该任务，无法确认它是复制时失真还是源公式实际损坏。软件不会自行删掉 `V`。验收采用完整、合法的集合表达式 `\mathbb{Q}(\sqrt2)=\{a+b\sqrt2\mid a,b\in\mathbb{Q}\}`；缺少匹配括号或未知命令的表达式仍明确报错。

24 项公式参数、嵌套导出及生成媒体相关测试通过。验证合法简写与完整花括号写法的图像尺寸、像素完全相同；错误括号和未知命令仍拒绝；集合式可在正文、标题、引用与表格导出。

实际文件：`output/pdf/PDF公式兼容性验收.pdf`。用真实 PDF 输出器生成，再通过 Poppler 渲染整页并视觉检查：根号、黑板粗体集合、集合分隔符、根指数、分数、行内和分行公式均显示，无原始 TeX 漏出或内容裁切。原文引用与讲解的颜色、字体区分保留。

这次修复不是完整 LaTeX 引擎升级，不能宣称支持全部宏包、复杂环境或损坏的公式。PDF 内数学公式仍为高分辨率图像，不是可编辑数学对象；这点没有变更。

打开最新版后，失败的旧任务需要重试导出或重新生成；原来失败记录不会自动变成成功。若还有其他公式报错，应核对完整表达式和不支持的具体结构。
