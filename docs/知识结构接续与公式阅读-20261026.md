# 知识结构接续与公式阅读

本轮源码更新，未重新打包。已交付 0.4.5 安装器及源码 zip 保留原发布快照。

## 修改

1. 恢复整理任务时同时匹配项目、对话、阅读记录、服务、模型和推理强度，不只比较 reading_id。任务列表和进度投影仅增加三个短模型字段，不加载全文或私有对话。
2. 面板查询按所选模型过滤知识结构；API 不带模型参数时保留原有读取行为。
3. 关闭、切换后返回的旧请求不覆盖新面板。创建任务的响应较迟时仍追踪原后台任务，但不把它分配给新面板；旧任务的 finally 也不能解除新任务的 busy 状态。
4. 明确重新整理只重做结构，不新建通读任务。后端仍核对原资料指纹和阅读清单。
5. 正在整理或已暂停时，通过原任务的暂停/继续控件操作，避免同屏重复发起。临时失败可以接续原任务；更新的完成任务不会倒退显示更早的失败。
6. 知识点引用、关系理由和适用边界使用现有安全 Markdown/KaTeX 渲染器。来源窗口显示公式并保留原始文字。引句保存内容不变，源材料中的指令或 HTML 不执行。
