# 书库重点精读与阅读版本验收

2026-10-11。流程、视觉显示和真实内容抽样分别验收，不把模型完成任务等同于理解正确。

## 本轮交付

- 阅读深度有“结构索引”和“重点精读”两个实际选项。索引建立导航、概念条件、来源及疑点；精读针对选中范围展开含义、证明动机、必要步骤、条件与例子。精读仍读取原页，不把旧摘要当作原文。
- 可填写精读问题。问题、深度、模型、范围在启动时保存；不同问题生成独立版本，后续修改输入不会改写已启动任务。
- 笔记窗口可以切换已完成版本；选回索引会打开索引。同范围、问题和模型复用完成笔记，不额外请求模型；“精读此节点”只准备选择和问题输入，点击阅读才启动。
- 原页、OCR 与有证据边界的画面观察可复用。扫描画面未成功读取会显示警告；失败或空观察不缓存为成功。强制重读、范围/图像/视觉服务变更会使相关缓存失效。
- 长记录保留完整正文。合并前不再每段随意截断到 1800 字；超过单次总结预算时保存完整记录并说明未完成统一核查。暂停、继续、前后台优先级和批次调度均沿用已有控制。
- 修复手机立即关闭再打开笔记时，迟到的关闭事件清空新窗口的问题。

## 真实教材抽样与发现

仅对 342 页《高等代数》第六版的 PDF 第 6–7 页指定选区调用真实 DeepSeek `deepseek-flash`、high。没有读取全书，没有以其结果推定学生掌握，也没有生成习题。

第二轮结构索引约 61 秒、精读约 98 秒。精读复用两页视觉观察，不再发视觉请求；首次索引约 95 秒，包含约 40 秒视觉请求。网络、输出长度及缓存状态不同，不能据此声称全应用、长视频已稳定提速 30%。最新导航复测约 53 秒。

逐份内容检查发现：初版把 π 的超越性误写成数域闭包验证的必要先修，且笼统断言所有定义条件都不能删。补充一般性的必要条件/可推导条件核对规则后，第二轮精读有所改善。再尝试以字数目标压缩索引时，产生了错误的共轭非零补证，**该字数目标已撤回**；索引只记录省略证明的回查位置和线索，完整补证交给精读。

最新索引仍对显式包含 0 的条件说得不准确：如果已经包含 1 并对减法封闭，则 `1−1=0` 已推出包含 0；这与删去包含 1 后可能出现退化集合是两个问题。对照页面显著标注这一残留错误，模型原始回答保留不改写。说明复杂教材内容质量仍需来源与推导核验，流程通过不代表正文无错。

实际样例与原始页面：`build/library-deep-real-20261011-1/结构索引与重点精读对照.html`。保存不同试验的原始输出和时间记录；未操作用户学习数据库。
