# StudyForge 0.4.2：三轮完善与打包验收

2026-10-11，Windows x64。三轮源码完善完成，最终安装包构建成功，并实际启动打包版验收。

## 打开新版

1. 从 Windows 右下角托盘右键退出旧 StudyForge；只关闭窗口会留在后台。
2. 双击 [StudyForge-Setup-0.4.2.exe](../dist/StudyForge-Setup-0.4.2.exe)，完成安装，从桌面或开始菜单打开。
3. 也可以直接双击 [StudyForge.exe](../dist/win-unpacked/StudyForge.exe)。直接运行需要保留整个 `win-unpacked` 文件夹及相邻资源，不能只移动一个 EXE。
4. 同一 Windows 用户继续使用 `%LOCALAPPDATA%\StudyForge` 中原有资料、聊天、画像与手机证书。安装配置不会删除用户数据；测试没有写入生产数据目录。
5. 手机页面由电脑提供。电脑更新后，保持原连接条件并刷新手机页面即可取得新界面；保留原数据目录时沿用证书和已信任设备。此轮在真实 HTTPS 网关上验证了设备会话重启恢复，没有代替用户复测安卓移动网络。

安装版包含独立后台、解析依赖、OCR 和 FFmpeg，不需要打开 CMD，也不需要系统 Python 或 Node。软件内的「使用指南」已同步更新，并包含书库精读与手机推理选项。

## 性能测量边界

实际 Chromium 对 60 条保存消息及六次追加刷新进行交替对照：六次刷新的累计渲染从约 344.95 ms 降至 3.45 ms，减少约 99%；该范围的 JavaScript／渲染器堆峰值从 49.46 MiB 降至 24.26 MiB，减少约 51%。渲染内容、公式、消息更正、选择、未提交问卷及项目隔离保持一致。

这是局部聊天显示测量，不代表整个软件内存或模型生成速度下降同样比例。全部历史仍从服务器获取，尚未采用超长对话历史分页；语音模型和大型视频任务仍可能占用较多资源。书库复用成功的原页观察能减少重复视觉请求，但首次扫描与模型推理耗时仍取决于资料、模型和服务。
