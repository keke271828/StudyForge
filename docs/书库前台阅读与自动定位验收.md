# 书库前台阅读、范围自动定位与检索记录验收

2026-10-11。完成当前源码改造，未重新打包。测试使用隔离数据；真实教材只读取原文件，没有修改用户的原始教材和学习数据库。

## 使用方式

1. 放入 PDF 教材，建立目录。扫描教材仍可指定目录页；这一步与正文通读分开。
2. 用“全选本书目录”一次选中整本目录，包含折叠和筛选隐藏的节点。也可“仅选筛选结果”或清空选择；隐藏选择数量会提示。单个任务最多 200 个目录节点。
3. 点“自动定位所选范围”：先核对纸面页码与 PDF 页码偏移，再用原页标题位置确定起止页和页内截取边界。可靠范围自动可用，不可靠的条目保持待核对。
4. 分别选择“前台 · 立即排队阅读”或“后台 · 空闲时阅读”，以及章节“串行”或“并行”，然后点“阅读所选节点”。未定位的范围先自动定位；可靠的节点先继续阅读，有疑点的节点单独等待核对，不再拖住整批。任务显示去重后的实际阅读范围数量。
5. “范围与原页”提供自动定位依据、“查看起始页”“查看终止页”、原页点击截取和手工页码。手动更改后，旧定位证据明确标成历史参考。已确认的范围不会被自动定位覆盖。

前台与后台选择改变实际调度，串行与并行改变章节处理方式，两组开关独立。前台无需等待全部聊天和成果任务结束，但仍共享软件模型请求上限；额满排队。后台前台忙时不启动新的阅读步骤，在途步骤保存后让位。前台不受后台阅读时段限制，仍受每日阅读预算限制。

书库同时最多接纳一项前台和一项后台书籍任务；每个阅读任务最多两个章节工作器，仍受全局并行开关和模型并发上限约束。暂停、继续、取消以及重启续接沿用已保存的步骤与启动快照。

## 检索记录不再随切换丢失

- 本对话最近 30 次有效书库检索持久保存，切换项目、切回对话、重开界面后恢复。
- 普通导师聊天的自动检索与公开 Agent 工具的搜索/原文回查均记录；私有文档生成、答案、评分等内部查询不写入公开聊天检索导航。
- 区分“目录候选”和“已回查”，记录书名、章节、页码及来源版本。范围改变或节点删除后明确显示状态。
- 长列表用鼠标滚轮和手机触摸可滚动，最近一次默认展开，较早记录按需展开；相同内容刷新不重建列表或重置滚动位置。
- 清空记录仅影响当前对话的检索导航，保留书、阅读笔记、手动引用和聊天。
- 保存的是有上限的导航元数据，不重复保存整份原文，不自动把旧检索注入下一次提示词或学习画像。更新前未保存的临时结果无法事后恢复。
- 配对手机已开放具体的范围定位和检索历史接口；仍保持原有鉴权和按对话、项目归属校验。

### 真实扫描教材的边界定位

报告：`build/library-ranges-real-20261011-2/report.json`。

使用用户提供的 342 页《高等代数》第六版扫描 PDF 的隔离副本。目录页 PDF 3—5 的本地 OCR 34.048 秒；为第一章与前两节定位边界 20.059 秒。检查 5 张边界页，0 次云模型请求；纸面页码与 PDF 页码偏移由两张实际页码观察校验。

| 节点 | 自动定位结果 |
|---|---|
| 第一章 多项式 | PDF 6 页约 11.66% 至 PDF 38 页底部 |
| §1 数域 | PDF 6 页约 29.85% 至 PDF 7 页约 81.09% |
| §2 一元多项式 | PDF 7 页约 81.09% 至 PDF 10 页约 68.07% |

三项可靠、零项待确认；已检查原页图像。这个时间是目录和边界定位时间，不是全书阅读、数学理解或讲解生成时间。扫描标题不清、目录页码不可靠、缺失目录与复杂排版仍可能需要人工核对；自动定位有页数和云端判读上限。

**后续全目录核验发现了局限并已修正**：前三个节点不足以证明整本书的效果。旧版对同一本书 108 个节点定位后仍留下 43 个待确认，包含固定 96 页上限导致的未检查节点。新版先覆盖预计边界，再局部复核，在当前代码复测中共有 106 个范围可用、2 个待核对，0 次云模型请求。新增集中核对、只读放大原页、范围确认版本冲突保护以及可靠节点先阅读。详情和完整证据见[书库范围自动定位优化验收](书库范围自动定位优化验收.md)。
