# 扫描教材目录自动查找验收

2026-10-11。实现目标：没有内置 PDF 书签的扫描教材，先自动找到目录页，再进入现有的章节范围定位和按需阅读，减少用户先逐本填写目录页码的操作。

## 操作与边界

1. 放入全局书库仍只保存文件及 PDF 书签；不自动解析或通读正文。
2. 未建立目录时，默认显示“自动找目录并建立”；手动填写页码折叠在校正入口内。
3. 默认查找前 32 个 PDF 文件页，用户可设为 1–64 页。只在本机检查标题、条目与页码列等目录特征；找到了目录结束位置就提前停止。查找期间可能查看少量相邻正文页以判断目录已结束，不会生成这些正文页的知识索引。
4. 原 PDF 可提取文字时保留行及页码列；扫描页采用本地 OCR，单页图像最长边限制为 1800 像素。每页查找后清理临时图像，缓存紧凑的目录判断依据。目录页本身沿用现有的高精度标题及页码列复核。
5. 目录查找支持现有前台／后台优先级、进度、暂停、继续和取消。暂停在当前本机步骤结束后停止启动新步骤；没有强行中断正在执行的 OCR。已完成步骤保存后复用。
6. 目录与任务提交检查点使用同一数据库事务；中途退出后续接不会因重复建目录丢失节点、引用或人工修正。取消后不提交目录；事务中途异常一起回滚。
7. 目录查找依据可展开查看候选条目和原页，完成后书架节点数立即更新。无变化的轮询复用任务卡，变化时保留依据面板的展开状态。
8. 查找不到可靠目录、到查找末页目录仍未结束、目录中间有未识别页面、识别结果逐页明显减少时，只给出候选与核对入口，不自动保存不完整目录。单次实际目录识别仍最多 12 页；超过上限显示限制，不静默截断。
9. 新目录的章节范围仍是候选，正文尚未阅读；之后选择章／节自动定位，只有可靠范围自动确认，剩余疑点沿用集中核对。没有用建目录冒充理解全书。

## 真实教材验证

测试原文件来自用户提供的 `C:\Users\Lenovo\Desktop\资料\STUDY\电子书`，使用《高等代数》第六版，342 页。所有运行使用 `build/library-toc-real-*` 中的隔离数据库及软件副本，没有改动用户正常使用的数据库或原书。

首轮发现真实缺陷：仅选到了第 3、5 页目录，遗漏第 4 页。查看原页后确认第 4 页有 43 个目录条目；OCR 在点线与页码列连接时使目录版式判断过于严格。修正后识别连续目录第 3–5 页；额外增加中间漏页和逐页识别减少的防护，避免以总条目数掩盖漏页。

最终结果：检查前 7 页，自动采用 PDF 第 3–5 页，分别识别 34、43、31 个条目，共 108 个节点、10 个大章节；模型请求 0 次，正文阅读记录 0 条。最终一轮与其他回归同时运行，耗时 69.487 秒；前一轮单独运行耗时 40.844 秒。没有以其中一次计时承诺固定速度。

结果及计时见 `build/library-toc-real-20261011-3/toc-real-report.json`；原页预览也保留在该验收目录。只核验建目录，不据此宣布全文理解或数学推导正确。目录中局部 OCR 字词仍可能需要后续原页核对。

## 自动及界面验证

- `tests/test_library_toc.py` 覆盖文字目录、页码列、无标题续页、罗马数字页眉、尾页单个条目、正文／索引误识别、查找上限、目录超过上限、中间漏页、逐页条目缺失、暂停恢复缓存、取消、原子回滚、临时图片释放、API 明确选择与重复任务防护、手动页码偏移兼容。
- 相关书库、范围定位、集中核对、目录移动、阅读安排、对话引用和检索记录回归同批 136 项通过（91.03 秒）；最后的短目录原文字复用与逐页条目门槛调整后，再对受影响的目录、书库和范围定位 64 项重测，通过（46.94 秒）。两批有重叠，不相加。
- `scripts/smoke_library_toc_ui.py` 与 `.js` 在真实 Electron 界面和实际配对 HTTPS 通道核验桌面暂停／继续、建目录、候选原页、手动校正、节点数刷新、手机 390／320 像素宽度、原页预览、零模型请求、未启动正文阅读。报告在 `build/library-toc-ui-20261011-2/toc-ui-report.json`。
- 界面验证使用生成的原文字 PDF；扫描 OCR 的验证由真实 342 页教材承担。窄屏 Electron 不能替代实际安卓触摸和输入法验收。

## 打开方式

先从 Windows 通知区托盘完全退出旧版 StudyForge，再双击工作区根目录的 `验收最新版.vbs`。在“全局书库”选一本尚未建立目录的扫描教材，点击“自动找目录并建立”。已经建好的目录保留，不自动重建。

本次更新源码与软件内使用指南，没有重新打包安装程序。手机刷新后使用电脑提供的新界面资源。
