# 书库参考片段与输入记录验收

2026-10-11。源码更新，未重新打包。使用隔离数据库、本机模拟模型响应和实际 Electron／配对 HTTPS 手机界面；没有改动用户学习数据库，没有调用收费外部模型。打开新版前从托盘彻底退出旧版，再双击根目录 `验收最新版.vbs`。

## 修复与新增

1. **记录真正提供的书库辅助输入。** 之前成果保存了主要原文清单，却没有记录“参考背景”实际提供的页码、字符范围和省略情况。现在讲解成果保存书名、节点、用途、起止页和页内范围、阅读模型／版本、实际摘录页、OCR 与图像核对记录的字符范围、导航笔记节选与校订，以及未提供的节点。输入长度和校验值与实际参考文字配对保存，不重复存入整份教材原文或导航笔记。
2. **修复长文分章时的隐式截断。** 原来书库参考附在项目阅读笔记后面，分章逻辑只取部分笔记的前3000字符，可能把书库参考一起截掉，甚至完全没有交给章节写作。现在项目阅读笔记与书库辅助输入分开。多部分讲解共用一份最多6000字符、带明确省略标记的固定参考；单部分讲解保留原有最多18000字符预算。重点对象的完整原文仍逐部分提供。详情显示真正送给章节的参考，而非启动时准备、却未完整发送的长字符串。
3. **暂停、重试复用固定输入。** 多部分讲解的参考准备作为独立本地步骤保存；恢复时核对原输入与记录，复用同一段文字和范围，不重复查书或使用后来重读的版本。记录与文字长度或校验值不符时，在模型调用前停止。公开生成接口在服务端重新构造记录，客户端传来的假上下文和假记录不能直接进入任务。
4. **严守节点授权范围。** 参考检索、相邻页选择、语义候选页和导师原页回查均受节点起止页限制。缓存中混入其他页时，不再因关键词更相关就选入；指定范围外页码明确拒绝。
5. **保存历史时不重写当时的来源。** 输入准备后节点可能被改名、修改范围或删除。历史保存使用当时冻结的标题、范围版本与阅读 ID，不用后来状态替换；删除后仍保留记录，恢复界面标记该节点已删除。历史按对话隔离，未提供的节点标为“本次未提供”，不会冒充“已回查”。
6. **两端可查看且滚动。** 电脑“成果文档”和手机“成果”的“资料依据”分别列出正文资料和书库参考。工作台“书库检索记录”可展开“本次书库输入”。内容按需建立，刷新与项目／对话往返保留本次页面运行期间的展开状态，长详情可滚动；用户校订作为纯文本显示。旧成果缺少的辅助范围明确提示无法追溯，不使用当前书库补填。
7. **减少重复校验。** 一次参考准备中同一原页缓存只验证一次；下一项准备重新检查。手机页面缓存更新至 v27，指南同步更新。

字符范围指保存的提取／OCR 或图像核对文字中的位置；PDF 页码是文件页码。两者与教材印刷页码、扫描图像的物理坐标不同，节点页内裁剪范围另列。

## 本地参考准备的性能对照

使用修改前保存的 `library.before.py` 与当前实现，分别在独立进程运行。沿用之前隔离的实际三页 PDF、12个节点、每节点约60万字符的合成导航笔记。先预热、四轮不带追踪器计时，再独立测量 Python 分配峰值；这次基线已经含有上一轮逐份加载笔记的优化。

| 指标 | 本轮修改前 | 本轮修改后 | 判断 |
|---|---:|---:|---|
| 参考准备平均耗时 | 476.40 ms | 476.21 ms | 没有明显变化 |
| Python 分配峰值 | 5,507,304 字节 | 5,530,375 字节 | 记录增加约23 KB临时分配 |
| 文件校验次数／准备 | 23 | 4 | 同页重复校验减少 |
| 参考正文长度 | 8691字符 | 8691字符 | 保持一致 |
| 新增参考记录大小 | 未记录 | 17,258 字节 | 保存元数据，不复制原文／笔记正文 |

旧字段投影的原文、摘录范围、候选、模式和省略列表逐项完全相同，校验值一致。新记录字段不属于旧内容投影。这项对照没有改变参考输入的原有内容，范围外缓存的修复另由专门回归覆盖。

报告：`build/library-reference-receipt-20261011/reference-before.json`、`reference-current.json`、`reference-comparison.json`；脚本：`scripts/benchmark_library_reference_receipt.py`。

这些是局部本地准备指标，不是软件总 RAM、扫描 OCR、视频解析、模型响应或真实教学质量的评估。本轮主要消除输入丢失、范围越界和溯源误导；没有据此宣称全应用提速或所有学习内容理解无误。

## 如何在软件中验收

1. 从托盘退出旧版，双击 `验收最新版.vbs`。原0.4.2安装包不包含本轮及前几轮后续源码改动。
2. 将已整理书库节点作为“参考背景”引用，向导师提问。展开工作台检索记录中的“本次书库输入”，核对实际页码、摘录范围与省略。
3. 以一份资料或某个重点节点生成讲解，在本项目“成果文档”展开“资料依据”。正文与背景分列；长资料分部分时，会说明各部分共用的参考输入及其预算。
4. 切换项目或对话后返回，原对话的检索记录仍在；别的对话没有这些历史。节点被改名、重读或删除时，已有记录仍显示当时的依据。
5. 手机“成果”与工作台显示同样的记录；长内容在框内滚动，Word 下载保留原有功能。

记录对应导师发起回答时自动注入的辅助资料，以及讲解章节实际使用的书库参考；它不是后续每一次 Agent 工具、联网来源和审查请求的完整日志。来源可追溯不证明论证正确，也不代表学生掌握。真实讲解效果仍应对照原页与实际学习反馈评估。
