# 右下角通知遮挡修复与验收

日期：2026-10-07。更新的是源码验收版。

## 原因与修复

主界面的 `.app-shell` 使用 `z-index: 1`，原通知没有指定层级，因此显示在主界面下面。原通知也位于原生 `dialog` 弹窗外，无法覆盖弹窗的浏览器顶层和背景遮罩。

新增统一通知组件。正常情况下进入浏览器顶层；存在模态弹窗时，将通知放进最后打开的模态弹窗范围，保证可见和可点击。弹窗关闭、后打开弹窗、多个弹窗叠加和浏览器全屏切换时重新安排通知位置。没有弹出层 API 时使用固定定位与高层级降级；该降级分支在当前 Electron 中通过关闭 API 的方式验证。

通知具有独立的清晰底色、关闭按钮和长文本滚动区域，不继承阅读面板的不透明度。普通通知默认 5 秒，操作错误默认 12 秒。鼠标停留或键盘焦点在通知内时暂停消失，离开后恢复；原生窗口或顶层切换漏发边界事件时，也可恢复计时。新通知替换旧通知后，旧计时不会关闭新通知。文字以纯文本显示，错误信息不会作为 HTML 执行。

## 实际窗口验收

使用真实 Electron / Chromium、隔离学习项目、持久化的测试对话和真实鼠标点击。模型调用 **0 次**，控制台错误 **0 条**。修复前，普通布局及阅读弹窗内的通知位置均被其他界面元素覆盖。

修复后的 15 个显示场景通过几何边界和 `elementFromPoint` 检查：

- 普通布局、放大对话、设置页。
- 阅读笔记、提交作业、通知出现后再打开弹窗、弹窗关闭后继续显示。
- 按与 DOM 顺序不同的顺序打开多个模态弹窗。
- 桌面原生全屏及其内部弹窗。
- 浏览器全屏兼容路径及其内部弹窗。
- 小窗口、夜读主题、长中文错误及连续英文网址；文本可滚动且无横向溢出。
- 关闭弹出层 API 后的普通布局和模态弹窗降级路径。

此外通过：真实鼠标关闭、关闭通知不关闭作业弹窗、Esc 关闭弹窗时保留原生全屏、显示通知不抢走输入焦点、不改变未发送草稿、重复通知计时、鼠标停留及离开、键盘焦点进入及离开、HTML 文本不执行。
