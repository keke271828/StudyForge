# StudyForge 开机自动启动

2026-10-09 源码更新；已纳入 0.4.0 安装包，详见《0.4.0打包与启动验收》。

## 使用与设置

在「设置与联动 → 运行与更新 → 桌面后台运行 → 开机自动启动」设置：

- **开机自动启动 StudyForge**：为当前 Windows 用户登记启动项。实际执行时间为开机后登录 Windows；不是登录前的系统服务。
- **启动后隐藏到托盘**：推荐启用。自动启动时准备后台和已有的手机连接，窗口保持隐藏；手动双击软件仍打开工作台。
- **保存启动设置**：写入后核对 Windows 的真实登记和启用状态。
- **检查实际状态**：重新读取系统状态。任务管理器中禁用启动项后，界面显示被 Windows 禁用，不在每次启动时偷偷重新开启。

若已启用手机连接的「打开软件时自动启用手机连接」，软件登录启动后会恢复手机服务。电脑和手机仍需各自保持 Tailscale 已连接；软件不能替手机开启 VPN。

从托盘右键「退出 StudyForge」只退出本次运行，不关闭下次登录自启动。关闭自启动需取消开关并保存，或在 Windows 的启动应用中禁用 StudyForge。

源码自启动登记当前项目文件夹内的 Electron 和项目路径，不需要 CMD。请保留该文件夹。未来安装版使用应用自身 EXE；已保存并启用的同名自启动项可在首次打开新版本时迁移，避免同时登记两个 StudyForge。若用户已在 Windows 禁用旧项，迁移不会自动重新开启。

## 打开最新版

从 Windows 通知区托盘完全退出旧版，再安装 `dist/StudyForge-Setup-0.4.0.exe` 或运行完整 `dist/win-unpacked` 内的 `StudyForge.exe`。已启用的源码启动项会在首次打开新版时迁移到新 EXE；Windows 中已禁用的旧项不会被自动重新开启。源码仍可通过根目录「验收最新版.vbs」打开。仅刷新旧窗口不能替换旧版桌面主进程和权限桥。
