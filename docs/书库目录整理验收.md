# 书库目录整理验收

2026-10-10，源码更新，未重新打包。正式用户数据库未用于试验；测试数据、界面截图和模型模拟响应位于 workspace/build 下的独立目录。

## 本轮完成

- 全局书库新增“整理目录”。电脑可以拖动 ⠿：上方／下方调整同级顺序，中间改变归属，底部虚线区恢复到顶层。整章移动包含全部下级节点。
- 电脑与手机均可通过“移动…”选择归属和排列位置。完整目标路径与位置另行显示，长标题被原生下拉框截短时仍可核对；窄屏的确认与取消按钮固定可见，长内容单独滚动。
- 电脑支持 Alt＋↑↓排序、Alt＋←上移一层；最近一次移动可撤销。目录被再次修改后旧撤销失效，避免覆盖另一端的修改。
- 补充目录时可以选择任意章、节作为父节点，新节点放在该父节点的子树内，不再附加到整本书的末尾。
- 多层缩进真实反映当前层级；移动保留勾选、筛选和阅读安排。整理工具在“完成整理”后收起。

## 保存和阅读边界

服务端在一次 SQLite 写事务内校验归属和插入位置，再保存全书的目录顺序。节点 ID、标题、原页范围、页内裁剪、确认状态、原始来源记录、阅读笔记和已有对话引用保留；不复制节点或改写原 PDF。章节不能移动到自身或其下级中，不能挂到另一书籍的节点下。

每次移动携带目录结构版本。电脑或手机已改变目录时，旧版本请求返回 409；移动窗口刷新当前目录后，需再确认，不能自动重试覆盖。数据库写入异常时全部回滚，不留下改了一半的目录。

目录归属是组织关系，不自动扩大父章节的阅读范围。新的任务只有在所选父节点的已确认范围完全覆盖子节点时才去重；同页裁剪或页范围不包含子节点时仍保留该子节点。等待、暂停及正在执行的既有任务使用提交时保存的有效节点 ID、顺序和范围，不能因后来移动目录漏读原先选中的章节。

移动本身不调用模型，也不使同范围的阅读结果失效。

## 打开并验收

1. 从 Windows 通知区托盘完全退出正在运行的旧版 StudyForge。
2. 双击根目录 [验收最新版.vbs](../验收最新版.vbs)，启动当前源码；电脑资料继续使用本机原数据目录。
3. 打开“全局书库”，选择教材，点击“整理目录”。尝试移动一个章、节，再打开笔记及原页，核对仍可使用；可以点击“撤销上次移动”。
4. 手机连接这次启动的电脑服务后刷新页面，打开全局书库，在“移动…”中选择位置。电脑重新打开该书即可看到保存结果。
5. 软件内 F1／“使用指南”已加入目录整理、键盘操作、范围去重和任务顺序说明。

现有 0.4.1 安装包没有随源码修改更新。本轮新增部分需要从上述源码入口使用；书库仍以 PDF 为首批范围，多书复杂证明的教学正确性继续需要原页核对和内容抽样。
