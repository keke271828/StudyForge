## 本轮修复

1. **设置同时保存丢字段**：对读取、合并、写入加锁，使用同目录临时文件及原子替换。不同设置区的请求保留彼此修改，写入失败保留上次文件。
2. **无效设置类型引发服务异常**：校验枚举、语音参数与开关类型，返回明确的输入错误。
3. **编程判题阻塞其他任务**：容器检测和测试移到工作线程，保持异步服务可响应。
4. **把运行环境故障算成学生 0 分**：镜像缺失及 Docker/运行命令启动失败保留静态审查，最终成绩为空，不更新掌握分数；不在批改中自动拉取大型镜像。
5. **测试超时可能残留容器**：使用本次独有名称，超时后只清理该容器；清理失败返回具体容器名称。
6. **非 Python 作业缺少容器运行流程**：补上 JavaScript、TypeScript、C++ 的测试规范、参考实现运行核查、隔离编译/运行及逐项测试计分。旧作业没有私有测试时保留静态审查，需重新布置才有运行成绩。
7. **异常 AI 分数污染画像**：拒绝非有限、布尔及越界分数；编程作业的同时提交只记录一份最终成绩。
8. **费曼进阶丢失编程语言及失败后卡住**：进阶保留原语言、知识点并增加一级难度；费曼通过先保存，生成中断可用“继续生成进阶”恢复。已生成题目及 DOCX 成果复用，避免重复调用。评审提示补充原题条件和已提交题目的参考解析。
9. **视频时间戳错位**：使用真实选帧时间并保存时间清单，不按文件序号乘以固定间隔猜测；短视频保留首帧。新导入的音视频将完整转录与原文件哈希绑定，媒体改变后要求重新导入；旧导入没有绑定时明确提示限制。
10. **MCP 读取概括预览**：非媒体资料重新读取完整原文件，视频读取完整导入转录与采样画面；返回来源清单及下一页位置。原文件丢失或未成功导入时明确报错。
11. **格式解析遗漏**：增加新版 Anki `collection.anki21b` 解压和媒体索引、提取卡片内嵌图片，保留原始字段顺序及标签；补读 XMind/FreeMind/OPML 节点备注、相关标签和链接；支持带 BOM 的 Notebook。
12. **代码乱码与语音临时文件残留**：网页及 MCP 代码提交使用统一编码识别，避免静默替换中文；音频发送完成后删除合成临时文件。中文识别提示采用各学科的中性表述。
13. **夜读主题的折叠标题不清楚**：实际查看截图后修正复习队列、后台记忆和费曼区的标题颜色，采用当前主题的正文颜色。

## 编程运行环境

需要运行成绩时先安装/启动 Docker Desktop，选择 Linux containers，并准备相应镜像。镜像不存在时界面会显示对应命令；批改不会将拉取失败记成学生成绩：

```powershell
docker pull python:3.12-alpine
docker pull node:22-alpine
docker pull mcr.microsoft.com/devcontainers/typescript-node:22-bookworm
docker pull gcc:14-bookworm
```

仅需准备使用语言的镜像。TypeScript 使用严格编译后的 CommonJS 接口；JavaScript 使用 Node 内置测试；C++ 为 C++17 函数/类作业。MATLAB/Wolfram 未接原生运行器；其他语言、浏览器工程、项目依赖与任意多文件作业不属于当前容器接口。

实现依据：[Docker 的运行退出状态](https://docs.docker.com/engine/containers/run/)、[Node 测试运行器](https://nodejs.org/download/release/v22.17.0/docs/api/test.html)、[微软 TypeScript 镜像](https://github.com/devcontainers/images/blob/main/src/typescript-node/README.md)、[Anki 包格式定义](https://github.com/ankitects/anki/blob/main/proto/anki/import_export.proto)、[FFmpeg 选帧和时间信息](https://ffmpeg.org/ffmpeg-filters.html)。这里只参考接口与格式，没有复制这些项目的实现代码。

## 用户验收方式

1. 在系统托盘完全退出旧 StudyForge，双击根目录 **`验收最新版.vbs`**；确认窗口标题含“源码验收版”。
2. 导入一份真实学习资料，先通读，再提出讲解要求；选择模型、学习模式、格式和概括性，生成后对照原文检查。
3. 不勾选同步出题，检查讲解没有额外作业；提交七项理解问卷中的卡点并继续追问。
4. 试用麦克风输入、拖放、分类、成果重命名/删除和暂停恢复；不同主题快速切换后重开确认保存。
5. 有 Docker 时试做 JavaScript/TypeScript/C++ 作业；没有 Docker 时应明确显示静态审查且没有最终成绩。严格费曼进阶保留原语言；生成故障后用“继续生成进阶”恢复。
6. 从“设置与联动 → 工具与联动”配置 Codex/DSH，重启相应客户端，在该客户端调用 StudyForge 工具；先读取资料，再回传成果。
