# StudyForge 0.0.1

StudyForge 是一个运行在 Windows 上的本地 AI 学习工作台。你可以把教材、文档、图片或视频放进项目，和 AI 一起阅读、讨论、整理知识，也可以生成讲解文档、练习和学习卡片。

资料、聊天记录和生成的成果保存在电脑本机。使用在线 AI 服务时，相关提问和资料内容会发送给你选择的服务；需要自行准备可用的账号或 API 密钥。

## 有什么功能

| 功能 | 可以做什么 |
| --- | --- |
| 项目与对话 | 按课程或主题管理资料，在同一项目下建立多个独立对话，保存聊天历史。 |
| 资料导入 | 导入 PDF、Word、PowerPoint、图片、音视频、TXT、Markdown、网页链接及常见代码文件等。 |
| 按范围阅读 | 选择 PDF 页码或一段原文进行解析，按需通读、查看阅读笔记和来源位置。 |
| AI 学习导师 | 围绕选中的资料提问，选择学习模式，追问概念、推理步骤、方法和知识之间的联系。 |
| 讲解与成果 | 生成讲解文档，导出 Word、PDF、Markdown、HTML 等文件，也可制作思维导图、Anki 卡片和代码包。 |
| 练习与作业 | 生成题单和编程作业，提交作答、查看批改与错因补讲，按需复习或再练。 |
| 全局书库 | 保存 PDF 教材，按章节安排阅读，让不同项目引用已整理的内容。 |
| 学习画像与路线 | 查看学习记录、自评和困难，修正不准确的判断，安排想了解或重点学习的主题。 |
| 任务与外观 | 查看任务进度，暂停、继续或取消任务；调整主题、背景、字体和阅读界面。 |
| 手机访问 | 通过浏览器连接电脑，继续聊天、上传资料、查看任务和下载成果。 |

## 安装与启动

1. 打开 [下载页面](https://github.com/keke271828/StudyForge/releases/latest)，下载 Windows 安装器（`.exe`）。
2. 双击安装器，按提示安装，再从桌面或开始菜单打开 StudyForge。
3. 如果没有看到窗口，检查 Windows 右下角托盘，点击 StudyForge 图标恢复窗口。

安装后可以在软件内打开操作指南，按提示完成第一次使用。

## 第一次使用

### 1. 连接一个 AI 服务

打开 **设置与联动 → 模型与语音**，选择自己已有调用权限的一种服务即可。

- **DeepSeek**：填写 API 密钥，保存设置，再点击“检测 DeepSeek 连接”。
- **本机 Codex**：先在电脑上安装并登录 Codex CLI，再到“运行与更新 → 运行环境”确认是否可用。
- **Gemini 或其他服务**：在 AI 服务管理中点击“添加 AI 服务”，按类型填写 API 地址、模型名称和密钥，再检测连接。支持 OpenAI 兼容接口、Gemini API，也有通过官方 Gemini CLI 登录 Google 账号的入口。

回到学习工作台，在“AI 服务”中选择刚配置的服务和可用模型。先发送一句简单的问题，确认能正常得到回复。

### 2. 创建项目和对话

点击左侧 **“＋ 新建学习项目”**，按课程或主题命名，例如“数学分析”。进入项目后，可以为不同话题新建对话。

资料按项目管理，每个对话分别保存聊天记录和所选资料。继续学习时，打开原来的项目和对话即可。

### 3. 放入资料，选择阅读范围

1. 点击输入区的 **“＋ 文件”**，或把文件拖入资料区；网页链接使用“网址”入口。
2. PDF 可以点击 **“范围”**，选择要读的页码；其他文档也可选择一段原文或全文解析。
3. 解析完成后，勾选本次需要使用的资料，再向导师提问。想先整理笔记时，可以点击 **“通读资料”**。

上传文件只是保存资料，不会自动解析或通读全文。PDF 页码按文件从第 1 页起计算，可能与书上印刷页码不同；第一次可以先试一页。

### 4. 提问或生成讲解

在聊天框中写清楚想学什么、哪里没懂，再点击 **“发送”**。例如：

> 请只根据我选中的资料解释这个概念，先讲清楚它在解决什么问题，再说明关键推理。适当举一个例子，这次不出题。

需要可下载的讲解文件时，点击 **“生成讲解”**，设置范围和要求，再到 **“成果文档”** 查看进度、阅读或下载。普通聊天不会自动生成文档。

### 5. 练习、提交和复习

在 **“练习与作业”** 中生成或打开题单，完成后提交作答；也可以在工作台使用 **“提交作业”** 入口。提交后查看批改、解析和补讲，需要时再发起复习或同难度练习。

有些补讲会先询问你的思路，按提示填写后继续。编程作业的隔离运行需要相应的 Docker 和语言环境；代码点评与实际运行结果会分别显示。

## 用手机连接电脑

1. 电脑顶部点击 **“连接手机”**，启用连接，使用窗口中显示的地址或二维码。
2. 按提示在手机上安装并信任电脑提供的证书，再打开 HTTPS 页面。
3. 输入配对码，并在电脑上批准该设备。
4. 配对后，在手机浏览器中选择项目和对话，即可上传资料、聊天或下载成果。

初次使用可以先让电脑和手机连接同一 Wi-Fi。跨网络访问可按软件提示配置 Tailscale。手机使用期间，电脑和连接服务需要保持运行。

## 从源码运行（可选）

如果只想使用软件，下载安装器即可。需要运行源码时：

1. 安装 Python 3.12 或更新版本，以及 Node.js 22 或更新版本。
2. 下载或克隆本仓库，在项目根目录运行 `setup_studyforge.cmd` 安装依赖。
3. 安装完成后，运行 `start_studyforge.cmd` 启动。

软件内的操作指南提供更详细的模型配置、资料处理、作业提交和手机连接说明。
