# 书库生成依据与摘录内存优化验收

2026-10-11。当前为源码更新，未重新打包。打开前从托盘彻底退出旧版，再双击根目录 `验收最新版.vbs`；手机刷新连接此源码服务的页面。本轮使用隔离数据库和模拟模型返回，没有改动用户学习记录，没有调用收费外部模型。

## 修复了什么

1. **讲解固定书库阅读版本。** 原来启动时保存了阅读 ID 和校订，生成正文却可能取后来完成的版本。现在完整原页输入使用启动时的 ID、时间戳、范围；新模型的阅读不会混入旧任务。版本被删除、覆盖或范围改变时明确停止，不悄悄切到另一版本。取用导航笔记时再次核对时间戳。
2. **检查完整的选定范围。** 作为“重点讲解对象”的书库节点必须具有起止范围内每一页的原页记录；漏页、额外页或缓存损坏会提示重读。已有页记录没有文字或图像核对内容时保留明确缺口，不能自动认定为空白，也不能冒充已经理解。
3. **两端展示成果依据。** 电脑“成果文档”和手机“成果”的卡片新增“资料依据”，列出本次正文资料、选定 PDF 页和页内边界，以及书库重点节点阅读的模型、推理强度、扫描核对模型、版本、疑点和启动时的用户校订。外部提示只显示待核对项数，完整提示放在可滚动的详情中。旧成果未保存的信息明确标为缺失，不从当前书库补填。
4. **保留展开状态且按需创建界面。** 详情第一次展开时才创建内容；刷新、切换项目后返回，在本次页面运行期间恢复展开状态。最多记住 200 个成果 ID，不保留已经移除的 DOM。用户内容使用纯文本插入，避免把校订中的 HTML 当作界面代码。
5. **减少长笔记摘录的内存。** 不再同时载入所有引用节点的完整笔记；共用一个笔记查询连接，逐份读取、截取后释放。被标疑的 AI 笔记无需加载正文。关键词窗口仅保留当前窗口附近的匹配，不建立整章的全部匹配列表。
6. **减少同书重复校验。** 一次生成中同一个书文件只计算一次校验值，相同原页缓存也只校验一次。下一项任务仍重新核验文件，避免把一次核验变成永久信任。启动时的书库输入错误返回清晰的 HTTP 400 信息。

书库“参考背景”仍按原有长度预算提供带省略标记的原页摘录；“重点讲解对象”提供选定节点的完整记录。卡片中的原页清单用于正文资料溯源，不是整本书已读完、所有辅助上下文均已逐字核验或学生已掌握的证明。

## 修改前后的本地性能对照

保存修改前的真实 `library.py`，以独立进程分别执行旧实现和现实现。样本是一个实际三页 PDF、12 个选定节点及每节点约 60 万字符的合成长导航笔记；不是用户的教材或实际模型理解结果。每项先预热，四轮不带内存追踪的平均耗时，再单独测量 Python 分配峰值，避免把追踪器时间作为速度。

| 操作 | 修改前 | 修改后 | 实际观察 |
|---|---:|---:|---|
| 33 万字符密集关键词中取 450 字符窗口：峰值 | 6,140,767 字节 | 7,993 字节 | 临时分配降低约 99.87% |
| 同一摘录操作：平均时间 | 24.11 ms | 18.09 ms | 约快 25% |
| 12 节点的参考准备：峰值 | 18,668,132 字节 | 5,507,445 字节 | 临时分配降低约 70.50% |
| 12 节点的参考准备：平均时间 | 361.71 ms | 344.25 ms | 约快 4.83%，重点改善内存 |
| 同一本书的完整文件校验次数／生成准备 | 12 | 1 | 本次内复用，下一任务仍重查 |
| 本样本全部文件校验次数／生成准备 | 48 | 4 | 本样本多个节点共用三份原页缓存 |

完整原页准备的平均时间由 498.49 ms 到 462.02 ms；小 PDF 中数据库及其他固定开销占比较大，不据此预测大书耗时。

**内容一致性：** 40 组不同文本、长度上限、查询词与锚点的摘录及位置元数据逐项完全相同；上述样本的完整原页记录、参考上下文与内容哈希也完全相同。保持原内容哈希的结构，避免只有溯源字段新增就使已保存的生成步骤失效。没有以删内容换内存，也没有为了提速增加模型调用。

## 你可以如何验收

1. 从托盘退出旧版，双击 `验收最新版.vbs`，打开全局书库已经完成阅读的节点。
2. 在当前对话引用节点，设为“重点讲解对象”，生成一份讲解。
3. 到本项目“成果文档”展开“资料依据”，核对实际 PDF 范围、阅读模型和阅读版本；手机“成果”也可展开同一条记录。
4. 切到别的项目再回来，详情继续展开，文档不会显示在别的项目中。
5. 原任务启动后换模型重新阅读同一范围，旧任务仍用旧版本；要使用新版本，重新启动生成。原任务所用版本删除或范围改变则应停止并提示重新发起。

阅读模型与生成模型可以不同。信息和原页版本保持一致，并不等于两个模型共享隐藏推理过程，也不等于能保证对任意教材理解无误。
