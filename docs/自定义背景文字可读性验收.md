## 打开验收

先从 Windows 通知区托盘完全退出旧版，然后双击项目根目录 `验收最新版.vbs`。进入“设置与联动 → 外观 → 分区设置”，上传背景并切换保护模式；再检查学习画像、成果文档、资料库和导师对话。已有安装包仍保持打包时版本。
