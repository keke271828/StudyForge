# 导师讲解质量对照与改进验收

2026-10-10。源码已修改，本次未打包。此记录区分软件行为、真实模型回答、人工内容检查和用户手动提供的官网回答。教学方向的源码调整已通过软件回归，内容验收仍有失败样例；测试通过不等于所有教学内容正确。

## 直接打开

1. 从 Windows 通知区的 StudyForge 托盘菜单完全退出旧进程，然后双击根目录 `验收最新版.vbs`，打开当前源码。
2. 用浏览器打开 `build/teaching-review-20261010/讲解质量真实对照.html`。此文件包含全部回答、Markdown/公式排版和字体，切换与下载不联网，不调用模型。默认隐藏方案标签，可以先独立判断再显示名称和人工评价。
3. 当前静态教学规则见 `docs/AI导师提示词.md`，从程序常量直接导出，不是另一套仅供展示的提示词。
4. 新增 `build/teaching-manual-review-20261010/网页与软件讲解对照.html`：只评用户复制的四份网页最终回答，排除思考过程；与实际聊天入口的样例并排展示。页面包含失败样例的具体说明，不是已审定教材。

现有 0.4.1 安装包没有因源码修改自动更新。本次不会中断正在运行的学习任务。

## 本次要解决的问题

用户选定的主要问题是：方法选择的理由没讲透；过于概括，公式与关键中间步骤缺失；套模板，不能沿具体疑问继续深入。“术语缺失”不是本次选择的主要问题。回答的展开方式先通过实测对照决定，不根据篇幅或提示词长度直接评优。

## 实际改动

- **精简共用规则**：导师、讲解、修订与补讲共用 `studyforge/teaching_policy.py`。移除重复规定，以及不相关的回归案例名称和固定证明。具体历史问题留在测试中，避免每份讲解都携带它们。
- **把问题讲透**：要求目标、实际障碍、选择方法的线索、选择的合法性、必要步骤和结论形成连续解释。区分“可以这样取”“这样取方便”和“必须这样取”；教学重建不冒充真实发现史。
- **按任务组织篇幅**：具体聊天追问集中于当前卡点；独立讲解文档先给简短主线，再展开难点。学生明确要求全面详讲、比较替代方法或关联延伸时优先落实，不限制原资料核心公式的解释。
- **保留选项区别**：概览用于定位问题与主线，精学解释方法和关键依据，研究分析条件、证据及核实办法；通俗、直观与专业并重、学术三种表达仍各有目标。学习模式、风格、语言与概括性独立，不因修改规则换模型或增加审查请求。
- **减少固定模板**：讲解结构作为参考，不要求逐项转成标题；只在原话确有帮助时引用，不要求每节先抄几段再重说一遍。原文、推导、背景补充和不确定性仍区分。
- **约束无益扩展**：自拟模型与公式应交代假设，例子不支持额外结论，不为了显得专业额外数学化。不把所有知识解释成物理。原资料必要的推导与专业内容继续展开。
- **移除聊天重复副本**：实际客户端已独立传入任务启动时的完整历史时，讲解请求只去掉软件编译出的完全相同历史前缀。保留新要求和后续任务目标，不删减原文件或原历史。无法确认完整匹配、独立客户端未传历史时保留原文。
- **保持画像查询**：检索学习画像与评估仍使用去重前的完整任务上下文；只有模型请求去掉重复副本。暂停、恢复的持久化快照不改写。
- **修正总结标题干扰**：共同规则按当前语言总结，避免中文讲解也照搬规则里的英文示例标题。
- **修复教学设置切换的内部会话污染**：聊天入口记录本轮实际使用的共用规则、学习模式、讲解风格、语言和任务提醒签名，并把推理强度纳入内部会话校验。设置或规则改变后，DeepSeek 从本对话公开问答恢复，Codex 创建新的临时会话并恢复公开问答；不沿用旧隐藏指令和工具/推理记录。设置不变时继续复用原内部上下文，资料选择、聊天记录和工作目录保留，不增加模型请求。
- **保留补讲和执行快照**：理解问卷的补讲按原文档模式/风格/语言签名，不覆盖较新的对话设置。返回普通对话时重新采用当前设置；已经启动的任务及其分支保留启动时的教学签名。这不等于已证明新对话的所有内容错误来自上下文污染。

没有新增后台代理或审查轮次，也没有用缩短原文、抽掉必要步骤来换取速度。

## 真实模型试验的方法

成功获得 20 份模型回答；另有 2 次自然追问请求因 API 连接失败未取得正文。失败保留在报告中，没有计作有效回答，也没有当成教学不合格。

共同设置：

| 项目 | 设置与范围 |
|---|---|
| 服务与实际返回模型 | DeepSeek API；响应字段为 `deepseek-flash` |
| 推理强度 | `high`，保持客户端原生推理设置 |
| 讲解偏好 | 直观与专业并重、精学、中文、详略第 3 档 |
| 资料 | 合成的极限唯一性片段、相关与因果片段；不是用户完整 PDF 或视频 |
| 工具与画像 | 各组同等关闭工具，无真实学生画像或其他项目聊天干扰 |
| 同时请求 | 至多 2 个；计时从每个请求实际开始到完整返回，不含排队 |
| 展示 | 保存最终可见正文、实际请求、模型名、用量、耗时，不保存私有推理文本、密钥或账号凭据 |
| 次数 | 每组每方案一次，后续调整另存新报告；不是统计显著性实验 |

第一组 9 份比较原有软件规则、简短基线和第一次修订。第二组 6 份比较集中讲透、主线后分层、全面展开。第三组 3 份复查自拟模型的假设；最后 2 份使用当前默认规则。自然追问首次及重试的 2 次连接失败另列。

**官网对照已有手动样本**：浏览器工具最初报本地组件缺失，后续授权重试仍在读取页面前报 `nodeRepl.fetch request failed`，没有从浏览器读到网站。用户后来复制了柯西不等式首答、数学追问、高斯定律、记笔记与成绩因果问题四份最终回答。只评价最终正文，首份附件的思考过程不参与评价或软件请求；复制出的重复公式、换行不作为模型教学错误。用户报告 V4.1 Flash、深度思考开启，最近明确报告未联网搜索；没有网页耗时和内部服务配置。DeepSeek 官方当前将 `deepseek-flash` 标为 V4.1 Flash（[官方模型接口](https://api-docs.deepseek.com/api/list-models/)），但两端上下文、工具、采样与服务配置仍未证明相同。不能把 API 结果改名为网页结果，不能把差异全部归因于教学规则。

## 补充：自然问题、追问与网页对照

本节是后续一轮，前面的20份输出及其计时属于先前阶段，未被覆盖。软件通过实际 `server.chat_stream` 入口、实际 API 测试，采用隔离数据库、空画像和不操作网页/文件的配置；画像查询工具仍可用，完整代理规则仍进入请求。网页结果由用户复制，没有网页用量和耗时。后续教学策略覆盖实验只改共同导师、聊天规则和任务提醒，保留其他真实参数；候选未直接写入生产代码。

### 当前可支持的判断

- 柯西不等式追问，网页解释更好：先说明 `t=1` 给出怎样的弱界，再用 `50.5` 对 `10` 的具体比较说明目标尚未达到。软件原样本的“判别式只有对所有t时才存在”“任何单点都不行”属于错误理由。网页的“不能推出判别式非负”也有笔误，按上下文应为非正，几何除法需非零条件。
- 高斯定律，网页主线与反例较准确；软件某次精简回答也已连贯，但后续复测又把静态均匀电场误称为非静电场，把等量异号电荷中点误称为零场。这表明一份较好回答不能代替重复内容验收。
- 跨学科题“样本大、记笔记与成绩显著相关”，软件主结论正确，补充却过度公式化，并混淆随机鼓励与随机改变实际记笔记行为。网页回答已收到，先分随机波动与系统偏差，再解释可比性，更易跟随；“无法同时观察个体两种反事实”不意味着不能估计平均效应，随机干预效果也不一概等于实际行为效果。
- 简短 API 基线较快、开头直接，但顶点公式存在符号错误。没有证据支持删掉所有教学、来源和题单边界规则。

### 已落源码的调整

共同规则进一步精简，强调回答当前卡点、例子与理由本身准确、方便与必要分清、追问不重讲整章；未要求练习时不附自测问题。直观与专业风格按概念疑问或证明/方法疑问选择表达路径，避免对所有内容强制套证明模板。导师、讲解、修订仍复用共同原则；模式、风格、语言和资料边界继续独立。

这是教学方向调整，并非内容已经全部合格。新增的更短候选只留在隔离实验；已返回的候选仍有不准确扩展，没有采用。没有新增生产聊天自动审查，也没有修改用户的模型、推理强度或权限设置。

### 轻量审查实验被拒绝采用

四次无深度思考的短审查尝试，2次获得可解析报告，1次连接失败，1次返回非法 JSON 转义。审查者确实指出部分错误，但还错误地将 `a=(1,0)、b=(30,10)` 的平方范数写为100（实际1000），并声称原文没有写出事实上已经写出的条件。它可能把正确内容改错，因此其修正建议只供离线核对，没有自动发送给导师或写入成果。

`scripts/teaching_claim_checks.py` 用实际算术独立核对了六个具体论断：偶极子球面局部通量、中点场、审查者的范数计算、两种最优化参数不同、非零均匀场具有零净通量、一般因果差分解中ATE不能直接代替ATT。它只核对这些论断，不能认证整份答案正确，也不是软件里已上线的通用数学裁判。

## 内容检查与选择依据

### 简短提示词确实值得保留

三个初始问题中，简短基线都能给出有用的解释，而且本次耗时较少。旧规则也并非每次表现差：明确指定构造目标的极限问题，旧版能讲清关键条件。这个结果支持减少无益约束，不能证明“所有提示词越短越好”，也不能证明先前长资料的质量差只有一个原因。

### 具体追问优先集中讲透

极限唯一性三种组织方式的实际结果：

| 组织 | 本次耗时 | 可见正文字符 | 人工判断 |
|---|---:|---:|---|
| 集中讲透 | 30.46 秒 | 2,148 | 当前问题所需的构造目标、任意正 ε、开区间等号边界、统一 N 与具体例子齐全；本组优先 |
| 主线后分层 | 43.49 秒 | 3,086 | 层次清楚，但对单一追问有部分重复 |
| 全面展开 | 42.88 秒 | 3,331 | 替代证明和一般联系可帮助拓展，但不必每次都先读 |

这不是要求导师回答必须短。标准是把困难解释完整，同时让与眼前疑问无关的扩展留在后面。

### 独立讲解文档优先分层，扩展仍需检查

第一轮社会科学组织对照中，分层方式能先交代问题，再用具体比较解释共同原因。集中与全面扩展的样例都出现额外模型条件不全的问题。补充假设要求后的复查仍有错误：

- 某样例列出无条件协方差为零，然后推出条件协方差为零，依据不充分。
- 某样例把处理组上的因果效应写成总体平均效应，缺少使它们相等的条件。
- 各种准实验并不共享同一条识别条件，不能以一句统一要求覆盖所有方法。
- 最后一份默认社会科学样例仍把总体销量和个人购买当成同一个变量，观察单位发生切换，存在余留疑点。

这些错误都已在比较页的人工评价里标出，原回答原样保留。**增加“要写全假设”不能保证模型自拟公式正确**。所以本次默认进一步强调只引入推进当前理解的公式与新理论；不能据此宣布模型输出绝对无误。后续官网对照要检验这种扩展是否有帮助，而不是只比较字数。

最后一份数学讲解已能从 `a+ε≤b−ε` 反推出 `ε≤(b−a)/2`，说明取等号与开邻域的关系，再用 `N=max{N1,N2}` 接成严格证明，并解释更小正半径同样可行。它仍有证明与总结的重复，可以继续减少。

## 软件与产物核验

- 260 项相关合并回归通过：教学选项、学习模式、原文件范围、同一导师、历史与画像、讲解审查、习题、批改、编程、暂停与审批续接。
- 最后规则调整后，80 项教学/偏好/模式/上下文回归通过；画像检索保留后，36 项上下文/记忆/共同导师回归通过。它们与 260 项有重叠，不累加成独立测试数。
- 新上下文用例覆盖真实 DeepSeek 请求消息与 Codex `fallback_history`：旧问题、旧回答、末尾追问各出现一次；原资料首部、中部和末尾、新要求、已检索的画像与持久化快照均保留。部分匹配及独立客户端原历史保留。
- 早期测试出现旧提示词字面断言、模拟客户端构造函数缺少 `effort`、以及只在 `prompt` 而未在 `fallback_history` 检查历史的断言，已按实际接口修正。一次 80 毫秒模拟审批超时在合并运行中失败，未经修改生产超时即在后续相关与最终合并运行通过，不据此声称真实账号的所有审批环境已验证。
- 离线比较页核对 20 份文本与原文件完全相同，检查了嵌入脚本语法及 1,633 个公式片段的 KaTeX 解析；没有外部脚本/字体依赖。页面未取得实时浏览器视觉验收。公式能够排版不证明数学正确。
- 本次没有在用户正在使用的应用里关闭任务、换模型、改权限或写入实验对话；实验采用隔离数据目录，凭据不导出。
