# 当前卡点画像检索与教学适配验收

验收整理：2026-10-17。测试与实验记录编号：20261016。源码已修改，本轮未打包。

## 修复的问题

已通过实际导师和文档输入复现：

1. 引用“高斯定律”后只问“这句为什么”，原画像查询没有利用明确选中的原句，相关困难记录未进入输入。
2. 资料或整段历史同时涉及许多知识点时，原先按更新先后选取有限摘要。当前卡点较早的记录可能被其他较新记录挤掉。
3. 文档的数值评估参考也可能先显示当前并非重点的知识点。

修复前记录保存在 build/profile-focus-before-20261016.xml；前三项完整流程检查实际缺少目标记录，其余检查验证新增接口需求。

## 已落实的改动

- 聊天优先按当前学生问题、明确引用原句分层匹配，再补入所选资料中的其他相关记录。
- 文档优先按本次独立要求、冻结对话最后一条学生问题及其原句匹配。完整历史仍独立交给原客户端，没有为定位而删除旧消息或原资料。
- 每个优先层内保持原顺序，分页也按这个稳定顺序处理；数值评估参考优先当前知识点。默认工具查询与画像总览保持原有行为。
- 用户纠正、移出和恢复、自评与实际作答分数的来源区别继续生效。检索线索不保存为新的能力判断，不把引用 AI 回答变成学生观点。
- 摘要仍最多取 8 个相关知识点，既有长度限制保持。匹配使用已有知识点名称与关联词，不保证识别全部同义表达。
- 不新增共同教学提示词、不增加固定模型请求。共享教学规则仍为 2026-10-16-preserve-valid-reasoning。
- 内置指南与静态规则说明已同步，手机缓存壳 v52。

正常的有学习意义的问题仍可进入原候选队列；本轮没有关闭原先允许的学习证据整理。画像摘要跨项目共享，其他项目聊天原文和原始证据引句不因此共享。

## 三组正式真实模型对照

使用合成资料、对话和自报画像；不是评定真实用户的理解程度。每题先建立目标知识记录，再加入较新的其他知识点，复现记录被遗漏或挤出的情况。

DeepSeek 调用名 deepseek-flash，推理 high，两臂使用相同模型、教学规则、资料、问题和模式／风格，只改变相关画像的选择与顺序。捕获实际客户端 HTTP 消息后直接重放，两臂均省略工具；没有再次追加客户端的公共上下文边界。六个发出请求的指纹与预期消息及选项一致。

| 样例 | 原检索：秒／正文字符 | 新检索：秒／正文字符 | 人工观察 |
|---|---:|---:|---|
| 净通量与局部电场 | 33.95／664 | 16.32／1061 | 新版沿自报困难逐面计算立方体通量，更容易跟算；它也更长，末尾仍有重复。 |
| 全称命题取特例 | 18.24／1718 | 26.24／1619 | 两版核心逻辑正确；新版仍重讲已知邻域与阈值，而且更慢。 |
| 浅复制与槽位赋值 | 15.12／839 | 8.71／755 | 两版完整结果正确；新版较短，第二项保留，仍有回顾和总结。 |

这是两份导师输入与一份文档输入的首次回答，各臂一次，共 6 次真实请求，不包含额外审核、Word 排版、扫描识别或视频处理。耗时不能作为普遍提速结论。

极限新版把原文字句转成 LaTeX 并调整标点后仍作为原文引用展示，不能视为逐字引文；这一不足已在原样对照中注明。取特例与证明全称命题的区分正确，但画像已传入仍未阻止重讲，说明教学表达仍需改进。

## 探索轮也予保留

此前另有 3 题／6 次真实请求，相关画像同样进入新版输入。探索轮通过 Agent 客户端再次重放捕获的消息，多追加了一份公共上下文边界；两臂都相同，仍能观察画像差异，但不与正式轮混作重复采样或统计稳定胜率。

探索中高斯例也按画像展开六面通量；极限例仍较长；编程新版 1175 字符，比原版 1129 字符略长，也更慢。全部保留，没有只挑新版有利样例。

两轮合计 12 次真实模型请求、6 次本机受控输入捕获。程序与模型实验分别检验：前者确认检索与信息边界，后者观察具体教学表现。**相关画像不再漏取，不等于所有回答都变得更好。**
