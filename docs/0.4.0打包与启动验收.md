# StudyForge 0.4.0 打包与启动验收

日期：2026-10-09。Windows x64，本次已生成最终安装包。

## 打开与升级

- 推荐安装：`dist/StudyForge-Setup-0.4.0.exe`，327,155,999 字节，约 327 MB。
- 直接运行：完整 `dist/win-unpacked` 文件夹中的 `StudyForge.exe`。请保留相邻文件和 resources，不能只移动单个 EXE。
- 先从右下角托盘完全退出旧版，再打开新版或安装包；无需 CMD。
- 学习数据仍位于当前 Windows 用户的 `%LOCALAPPDATA%\StudyForge`，项目、聊天、画像、成果、启动偏好与手机证书沿用原目录。安装配置保留用户数据。
- 已启用的源码自启动项在首次打开新版时迁移为新 EXE，继续默认隐藏到托盘；Windows 已禁用的旧项不自动重新启用。
- 手机页面由电脑端提供，电脑升级后手机联网刷新页面即可取得新界面。保留原数据目录及同一 Windows 用户时，原证书和配对记录继续使用；电脑和手机仍需保持 Tailscale 连接。

## 打包前优化

1. 启动项设置、系统回读或磁盘保存失败，都恢复之前的实际命令和启用状态；部分登记失败也能回滚。
2. 保存后直接返回刚核对过的系统状态，减少一次同步 PowerShell 查询。
3. 设置页忽略过期回读，避免旧状态覆盖刚保存的选择；首次确认支持状态后才允许保存。
4. 安装版自检按“资料先入库、明确选择后解析”执行，核验上传没有自动创建解析任务。
5. Anki 自检改为合法的聚焦问答 JSON 卡片，并检查桌面自启动、手机作业与问卷、范围解析和公式渲染资源确实在包内。
6. 实际验证源码到打包 EXE 的启动项迁移，验收脚本仅使用专属测试值，正确处理结束后的启动项清理。
