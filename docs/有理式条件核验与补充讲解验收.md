## 已接入的功能

共同 Agent 的按需数学工具增加 `rational_identity`：

1. 以有理数精确运算核对两个有理式在公共定义域上的恒等，不依靠抽样点代替恒等证明。
2. 两边分别保留原分母非零限制。约分、乘零、负整数幂及嵌套除法不抹掉限制。
3. 例如 `(x*x-1)/(x-1)` 与 `x+1` 相等时仍保留 `x-1 != 0`；`0/x` 与 `0` 相等时仍保留 `x != 0`。
4. 未证明定义域条件等价时返回“未比较”，不误称已经证明两边定义域不同。不同限制的写法也可能给出相同范围。
5. 可在只读权限下使用，禁用 Agent 工具时不调用。复用现有原生服务、Codex 工具入口、私有快速核查与完整文档任务；真实云端本轮仅测已配置的 DeepSeek。

工具核对独立交换实变量的有理式，不求分母根，不应用额外变量关系，不核对完整定理、极限、不等式、量纲或真实系统。`verified` 仅表示计算完成，恒等结果另有字段；不能用它给学生判分或认证整篇讲解。

支持四则、括号和直接写出的1至8／-1至-8整数幂，不支持零次幂、函数、属性、下标、LaTeX或代码执行。最多6变量；每式2000字符、160语法节点；中间多项式总次数24、128项；保留至多32个非零条件；还限制计算次数、有理数大小和结果体积。超限明确拒绝，不把截断的结果称为核对完成。

本机计算不调用模型；但模型选择工具后仍需续答。本轮两项实际 Agent 任务分别有2次、3次模型请求。没有给所有任务增加固定审查轮数，没有新增联网、后台子代理或模型任务。

### 原始Word的具体不足

- 表格第3个数据行 `t · 1/t² = 1/t` 被正文误称“第二行”。
- 原资料已经给定 `t>0`，正文又说“我们额外加的限制”，来源表述不准确。
- 无依据断言真实的量不会精确满足倒数关系；数学示意本身没有给出此现实结论。
- 5611字符，展开到导数、对数导数、梯度、多次总结，超出解决眼前问题所需。工具核对成功并未避免这些问题。

报告保留原始输出，不把人工整理冒充模型回答。另给出明确标注为人工整理的短解释，方便比较“先讲清配对关系，再按需展开”的组织方式。
