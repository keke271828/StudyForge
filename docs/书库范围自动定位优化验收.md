# 书库范围自动定位与集中核对优化验收

2026-10-11。当前源码改造，未打包。实测在隔离数据库进行；读取用户提供教材的副本，没有改动原始教材或在用学习数据库。

## 改造前的问题与处理

| 问题 | 当前处理 |
|---|---|
| 模糊标题先反复查邻页，后面目录没有得到检查 | 先覆盖本批预计边界，再处理疑难；每次任务按边界数量预留检查额度，最多 256 页，仍不无条件 OCR 全书 |
| 目录漏掉 n、唯一性漏字，正文标题因此只能人工确认 | 从目录原页的标题行独立高清复核，再与正文标题匹配。没有一致证据时仍是建议，不凭模型自信通过 |
| OCR 最小置信度稍低就反复读完整邻页 | 只重读实际观察到的标题带，独立缓存；同一节点边界被多个范围使用时复用 |
| 找不到下一标题，却把整本书末页作为候选终点 | 有后续节点却无法定位时，不提供可批量确认的范围；不把未知终点当成书末 |
| 同名标题落在其他章节，也可能被误认 | 同时检查原目录所属章节的开头及后续章节边界，越界建议不自动通过 |
| 只修改目录显示名，就失去自动定位能力 | 保留原目录标题用于定位；用户的显示名保留。仅未改名的 OCR 错标题可由目录原图复核后更正 |
| 一项疑点拖住所选全部阅读 | 可靠节点先入阅读队列；未确定节点保持待核对。只读取用户明确选择的范围，保留优先级、串并行和模型快照 |
| 每项都需打开、填写页码、勾选、保存 | 新增集中核对面板，有完整边界建议的条目可一次确认多项；未定位和真正缺失的边界单独区分 |
| 核对原页字体小、返回后丢失勾选 | 增加只读放大原页；返回时仅保留版本未变化的勾选，改变的范围重新核对 |
| 图片换页尚未完成时可点到上一页 | 只有当前页实际加载完成才接受截取点击；旧图片不改写新页边界 |
| 打开已确认范围后又要重复确认 | 保留已确认状态与精确坐标；真正改变范围时才要求重新确认 |
| 定位开头长时间显示 0% | 预计标题检查与边界复核分别更新进度，重试不倒退 |

## 当前操作

1. 在全局书库建立目录，然后选章／节，“自动定位所选范围”。“补齐本书范围”无需全选，直接处理本书尚未确认的范围；只定位，不启动正文通读，也不改变对话引用。
2. 默认只在本机处理页码和标题。可在“定位选项”开启当前模型辅助判断，最多 6 次，仅提供实际提取的标题行，无法编造页面或坐标。模型辅助结果自身不授权未验证的阅读。
3. 阅读按钮仍可直接使用：未确定范围先定位，可靠节点继续阅读，疑点单独保留。任务显示合并重复章／节后的实际阅读范围数量。
4. “集中核对疑点”或任务卡的核对按钮打开剩余条目。核对当前的起始与下一标题原页后，勾选需要确认的建议；可只确认，也可“确认后阅读这些节点”。缺少起点／终点的条目无法直接批量确认。
5. 原页可放大预览；微调时仍可输入起止页或点击图片设边界。原页预览本身没有保存操作，不会修改任何节点。

确认接口在同一数据库事务中检查书籍归属、每项建议的范围版本、完整原页边界以及在途任务。一个版本发生变化就拒绝整批，不会只确认一半。已确认的手动范围不被自动定位覆盖。

每批最多 200 个节点；极长目录仍应分批。全书阅读、扫描公式正确性与数学理解没有因定位成功就变为“已验证”。
