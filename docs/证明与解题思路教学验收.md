# 证明与解题思路教学：实施与验收

日期：2026-10-02 至 2026-10-03。本轮只处理“导师与生成文档都详细讲解证明、解题策略及背后思想”。不打包，安装版仍保持原样。

## 已实施

- 同一学习对话的导师与文档生成共用 `REASONING_TEACHING_RULES`，Codex 与 DeepSeek 两条实际请求路径各合并一次。继续使用当前服务、模型、推理强度和已经保存的学习对话。
- 长资料与旧对话之后附加简短的当前教学提醒，强调重新核对旧回答和落实本次目标；提醒不保存成学生原话，不额外请求模型，不改变模型选择。
- 先交代目标、定义与假设，再解释困难在哪里、什么结构提示方法、关键构造为何有效，给出可以复现的推导，说明适用边界与迁移条件。
- “怎样可以想到”作为教学性的思路重建；人物真实发现经过必须有可靠来源，不编造作者心理活动。
- 发现原证明的错误、条件遗漏或跳步时，保留原文与来源并明确纠正，不把错误模板扩写成结论。
- 同次回答核对关键等式、例子代入、物理量的系数与量纲；发现自己的旧回答有误时直接更正。标题与总结保留影响结论的限定，不能把特定框架中的结论泛化。
- 关键依据不确定且允许联网时，使用既有检索和网页读取工具，核对原论文、教材、大学讲义等；无法读取或仍不确定时标明待核实。来源限制、联网权限继续有效。
- 哲学与社会科学解释概念、论据、反驳与价值立场，不强行写成物理证明；跨学科联系解释真实对应和差异。
- 现有五档“概括性强弱”保留：强概括凝练方法理由与关键推理，弱概括展开动机、推导、完整例子和必要的方法比较。用户最新要求继续优先。
- 默认极速模式不增加独立审查。已经选择其他审查模式时，将证明依据、方法理由和发现史真实性纳入现有检查；修订仍使用共用教学规则。
- 只补写末尾总结时不附加证明展开规则；讲解不附带待答习题，不额外导出 Markdown 或审查文件。
- 识别文章结尾的“小结／全文小结”，直接复用并统一为“系统性总结”，避免另一次更长的总结生成；局部小结、原文引用里的小结及三级以下小标题不会被当成整篇结尾小结。确实需要补写时，只总结当前文档，不带入旧对话中未在文档解释的知识。

完整可读规则见 [AI 导师提示词](AI导师提示词.md)。

## 验收标准

| 场景 | 要检查的实际行为 |
| --- | --- |
| 诺特定理含错草稿 | 区分驻作用量与一定最小；区分固定端点任意变分与对称变换；纠正“固定区间积分为零所以处处为零” |
| 分部积分的动机 | 解释为什么把变分拆成运动方程项与边界项，以及守恒量怎样从这个结构出现 |
| 全导数与自由粒子推进 | 解释 `δL/ε=dB/dt` 时固定时间变换的量为 `Σpᵢξᵢ−B`；自由粒子例子不能把 `m q̇ t` 当成守恒量 |
| 全局与局域规范对称 | 区分第一、第二定理，不把局域规范自由度机械当成一种新的独立电荷守恒律 |
| 柯西—施瓦茨不等式 | 解释为何构造含参数的平方和，怎样想到该构造，单独处理零向量与等号条件，不无端扯到物理 |
| 同一对话导出 | 后续讲解沿用前一轮讨论；只输出所选 DOCX，原文引用和讲解分开，含原生数学公式与末尾总结 |
| 用户约束及成本 | 完整原文与最新要求保留；极速模式没有新增审查调用，已有完整总结不额外请求模型 |

科学内容校核参考：[诺特原论文英译本，§1–2](https://arxiv.org/pdf/physics/0503066)，[Brading 与 Brown：Noether's Theorems and Gauge Symmetries，§2–5](https://arxiv.org/pdf/hep-th/0009058)。验收中的自由粒子推进例子为独立代数校验，不作为诺特的历史发现过程。

## 实际模型验收

使用 `scripts/smoke_proof_teaching.py`：隔离项目、真实 DeepSeek、禁止启动 Codex；执行诺特定理导师对话、同一对话 DOCX 生成和纯数学证明对话。自动检查仅作为初筛，实际推导与教学质量还需阅读输出核对。

首次真实验收记录：`build/proof-teaching-uyn2hzhq/result.json`。三项实际调用与文件检查完成，禁止 Codex 启动；原论文网页实际读取成功。DOCX 有 466 个原生公式对象，引用使用单独样式，末尾总结完整，仅输出所选文档。

**首次自动初筛通过，不代表首次回答无误。人工复核发现：**

- 诺特导师回答追加了未请求的演算任务，且一个标题比正文更绝对。
- 把 `−m q₀` 的物理含义简写成“初始位置”不够准确，应保留质量因子或说成与初始位置成比例。
- 柯西回答的比较表错误地写成 `B(t−C/B)²+(AB−C²)=Bp(t)`；正确的缩放式是 `B²(t−C/B)²+(AB−C²)=Bp(t)`，或者不缩放地写 `p(t)=B(t−C/B)²+A−C²/B`。

据此收紧了共同规则：同次回答核对等式和例子、比例因子与量纲、纠正自己此前的错误、标题限定、网络证据链接，以及未请求练习时不追加计算、证明或编程任务。使用 `scripts/smoke_proof_refinement.py` 继续原隔离对话，检验短回答和概括性最强的实际生成结果。

最终复验记录：`build/proof-teaching-uyn2hzhq/refinement-result.json`；实际文字为同目录下的 `noether-refined.md`、`schwarz-refined.md`、`schwarz-refined-lecture.md`。使用同一个 DeepSeek 学习对话与 `deepseek-flash`；这些文件是开发验收记录，正式生成不会另导出 Markdown。

人工核对最终样例：

- 诺特例子写出有限变化 `ΔL=mεv+mε²/2`，明确一阶系数才是 `mv`；说明 `Q=−m q₀` 为质量乘初始位置的负值，而非位置本身；保留全导数项、在壳条件与从流到荷的边界条件。
- 柯西例子写出正确配方和缩放式，并实际展开系数、代入 `a=(3,4)`、`b=(1,1)` 验证；处理 `B=0` 及统一等号条件。
- 导师更正自己早前“平方和是唯一的非负来源”的过强说法，改为平方和是便于生成目标交叉项的自然构造；说明投影系数怎样出现。
- 文档生成沿用刚刚的数学对话，选择概括性最强档位，只新增所选 DOCX；没有独立审查，末尾保留系统性总结，含 **86 个原生公式对象**。当前原文定位保留，没有布置习题或无端加入物理定理。
- 最后这组短回答耗时约 21.2 秒与 18.4 秒；简要文档约 17.7 秒。初次长文使用最高细节档位且读取论文，耗时明显更长。时间取决于模型、资料长度、工具与服务响应，这几个样例不能作为普遍速度保证。

排查确认：运行时加载当前工作区规则，保存的内部对话没有夹带旧系统消息。真实样例在只更新长系统规则时仍复用旧措辞；加入当前任务末尾的提醒后，以上关键错误得到纠正。网络读取已在首次验收实际完成；最终这组复验没有新增联网查证或网页引用，不宣称外部来源链接的自动引用行为完全可靠。

## 限制

提示词要求与几个验收样例不能保证模型理解任意证明都正确。教学质量仍受当前选择的模型、原资料完整度及网页可访问性影响。本轮不通过额外多轮审查增加固定生成耗时；需要重要结论核查时可使用已有审查设置。
