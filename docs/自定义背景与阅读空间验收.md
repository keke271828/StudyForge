## 打开与使用

先从 Windows 托盘完全退出旧 StudyForge，再双击项目根目录的 `验收最新版.vbs`，确认窗口标题有「源码验收版」。右上角「外观」或「设置与联动 → 外观与操作」进入背景设置。

背景在聊天、资料库、成果文档等工作区共同生效，属于本机外观偏好，不属于某一学习对话的教学参数。

## 设计与实际行为

| 控制 | 实际效果 |
|---|---|
| 纯净、山岚、暮蓝、晨光 | 纯色或本地 CSS 渐变方案，无需下载资源；选择背景不改变明暗主题 |
| 我的图片 | 上传或拖入 PNG、JPEG、WebP 静态图片，最多 20 MB、3200 万像素 |
| 背景透明度 | 0% 完整显示背景，100% 完全隐藏背景；只改变装饰层，不改变正文透明度 |
| 背景模糊度 | 0–24 px，实际应用于窗口背景和预览 |
| 阅读面板不透明度 | 当前为 0–100%，在「界面分区」调整聊天阅读区；其他区域独立控制，正文和公式不随底色变透明 |
| 图片取景 | 分别调整水平、垂直位置；图片覆盖窗口，按窗口比例裁切 |
| 专注模式自动淡化背景 | 默认开启，进入专注时将背景显示强度降至原来的四分之一；关闭时保留当前背景强度 |
| 阅读预览 | 展示正文、不同样式的原文引用和真实 KaTeX 公式，随滑杆立即变化 |
| 删除图片 | 删除软件中的背景副本；正在使用这张图片时切回纯净背景，使用内置方案时保留该方案 |
| 恢复背景默认 | 恢复背景、透明度、模糊度与取景；阅读面板和其他区域由「恢复界面默认」单独恢复，不重置主题、字号、发送快捷键、模型或学习模式 |

标题区域同样提供遮罩，避免高反差图片使标题难以辨认。动效仅为短过渡，没有持续运动的背景；沿用「减少动画」和系统偏好。

滑杆立即预览，短暂合并连续变化后自动保存。上传、删除、恢复默认和普通外观设置共用有序保存队列，每次只写入变化项。快速切换与退出前会刷新待保存的滑杆变化；失败恢复已确认的偏好，并给出提示。设置页刷新也检查版本，较早发出的读取请求不能把刚修改或删除的背景覆盖回来。

## 本机图片

图片经本地解码、校正 EXIF 方向和缩小过大尺寸后，重新保存干净像素，最长边不超过 3840。原文件不修改，EXIF 等原始元数据不复制。背景副本存放在本机数据目录的 `appearance` 子目录。

替换图片成功后清理先前副本，保存失败保留原副本和偏好。只读 URL 使用内容标识，不接受任意文件路径。不导入资料库，不创建学习任务、聊天或画像事件，不向模型发送背景图片。学习 Agent 现有内部文件隔离继续生效。

## 手动验收

1. 选择山岚、暮蓝或晨光，再回到学习工作台。改变的是整个工作区背景，不只是预览卡片。
2. 选择自己的图片，尝试拖动透明度到 0% 和 100%，再调整模糊度。正文不应跟着变透明，公式仍应正常显示。
3. 打开图片取景，移动水平、垂直位置；调整阅读面板不透明度，检查图片和面板的强度可以分别变化。
4. 进入专注模式，比较「自动淡化」开关的两种效果；退出专注后恢复正常背景强度。
5. 退出托盘并重开，检查背景与参数恢复。移动原图片不影响软件中的副本。
6. 在内置方案与「我的图片」之间切换，删除图片，再恢复背景默认。模型、对话资料选择与聊天记录不应变化。
