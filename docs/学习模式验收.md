# 共享学习模式验收

本项只实施学习模式，未打包，未继续知识图谱、复习或托盘等后续项目。已有安装包仍是旧版。

## 打开方法

退出旧版窗口，再双击项目根目录的 **验收最新版.vbs**。它直接启动最新源码，窗口标题带“源码验收版”，不需要维持 CMD 窗口。

学习工作台的模型栏下方新增 **学习模式**，适用于同一导师的聊天和文档：

| 模式 | 学习目标 | 教学取舍 |
| --- | --- | --- |
| 概览 | 读懂原文并建立知识定位 | 串联问题、结构、概念、主要论据与结论；解释必要术语、关键理由与条件，避免默认逐行展开计算。 |
| 精学（默认） | 形成可复现和可迁移的理解 | 解释方法为什么合适、关键构造如何想到、步骤的依据和适用边界，按需要提供完整讲解的例子或反例。 |
| 研究 | 理解证据、假设、争议与可继续追问的方向 | 先讲清原文，再辨析证据和替代解释；有依据时提出相关延伸和核实路径，不能伪称已经查证。 |

三种模式均完整读取原资料，不使用预览摘要代替原文。研究模式不会新增权限；是否联网、读取网页视频和修改文件仍遵循已有权限。网络未授权或无法核实的具体内容必须标注。

模式与概括性相互独立：概览可以详细梳理主线，精学可以凝练地解释方法理由。模式不会替用户更换模型、推理等级、格式或审查轮数，也不会自动勾选出题。讲解仍不附习题；勾选同步出题时沿用独立习题流程。

学生当前明确的要求优先，例如“只用原资料”“两段说明”“详细解释这一步”“不要出题”。模式不是固定文章模板，也不能以研究之名给简单问题堆砌文献。

## 操作与恢复

- 选择模式后，下次发送或生成使用该模式；选择写入本机软件配置，桌面重开即使更换本地端口也可恢复。快速切换按顺序保存最后选择，没有保存选择时默认精学。
- 切换模式保留当前资料、对话和已完成通读，不重复调用 AI 通读；也不清空输入框或改变概括性、模型和同步出题。
- 开始生成时固定模式；暂停、重启或修改当前对话模式都不改变该任务。继续时复用已经完成的模型步骤。
- 成果卡片显示生成模式，元数据与任务保留模式记录；对同一资料可以另行生成不同目标的版本。
- 从成果打开理解问卷时，恢复原讲解的模式和公开对话。补讲接续同一导师，仍会优先回应具体卡点与当前明确要求。
- 老对话没有新增字段也可打开；老任务没有模式记录时按精学处理，不伪称知道旧任务曾选择哪种模式。

## 建议验收

1. 用一份实际资料，选择概览，概括性设为最强，关闭同步出题，要求“先把主线讲清，用必要术语解释”。
2. 保留资料与对话，改为精学，追问其中一个证明、构造或论证“为什么这样做”，确认不是复述步骤。
3. 改为研究，要求说明论据、假设和适用边界；若禁止联网，不应声称读过外部论文或视频。
4. 比较同一资料的成果；核对模式显示、来源和总结。在问卷中选择真实卡点，确认补讲针对卡点且没有擅自布置习题。
5. 开始生成后暂停，切换当前模式再继续；旧任务应保持原模式。

## 自检证据与限制

- 全项目回归 **276 项通过**，其中新增模式专项 **9 项**。
- 验证 DeepSeek 实际请求协议中的三种模式、完整原文与明确要求；Codex/DeepSeek 对话切换及省略参数继承；生成快照和成果记录；补讲模式恢复；暂停后重启继续的模式和已完成步骤复用；修订与缺失总结；非法输入与旧表兼容。
- 真实 Electron 操作检查：三个模式选项、默认精学、重开保存、旧讲解模式恢复、切换保留对话和通读、选项独立、实际发送与生成、成果模式记录，以及原有问卷提交和跳过。没有浏览器错误。
- 检查使用隔离学习数据和模拟云端，不消耗实际模型额度、不修改真实资料。它们验证功能传递和恢复，不能证明真实模型的解释一定正确，或三种模式已经改善长期学习表现。
- 本项没有增加模型调用、审查轮数或自动出题；实际长度、延伸质量和响应速度仍受资料与所选模型影响。
