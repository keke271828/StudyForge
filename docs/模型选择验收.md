# 模型选择验收

状态：本项源码实现与自检完成，等待用户验收。没有重新打包。

## 打开与操作

1. 双击项目根目录的 `验收最新版.vbs`。窗口标题应含“源码验收版”；以前安装的快捷方式仍可能打开旧版。
2. 在学习工作台顶部选择 AI 服务，再选择模型。导师、讲解、通读、习题及编程作业请求使用该选择。
3. Codex 推理强度只列出所选型号返回的档位。自动项交给服务默认；切换到不支持当前档位的型号后改为自动，不自行恢复已失效档位。
4. 点击模型旁的刷新按钮读取相应目录；也可在设置与联动中刷新目录，或手动填写默认模型。
5. 换服务、关闭后重开，检查两种服务的模型选择和 Codex 档位分别保留。保存到本机设置，不依赖当前窗口端口的浏览器存储。

“默认”会解析为当前配置或目录返回的默认型号，并传给导师和生成任务。修复了原对话使用 Pro、后来选择默认 Flash 时，讲解仍沿用原对话 Pro 的情况。切换模型继续软件内同一学习对话；模型之间的能力及回答风格仍可能不同。

## DeepSeek 型号与边界

2026-10-03 核对官方文档：

| 界面名称 | 发送的调用名 | 说明 |
| --- | --- | --- |
| DeepSeek V4.1 Flash | `deepseek-flash` | 当前正式调用名；新配置默认使用它 |
| DeepSeek V4 Pro | `deepseek-v4-pro` | 可独立选择；画面分析仍使用单独配置的视觉模型 |
| V4 Flash 兼容名 → V4.1 Flash | `deepseek-v4-flash` | 旧 V4 Flash 已退役，该兼容名目前转向 V4.1 Flash，不能固定调用旧版本 |

依据：[官方首次调用说明](https://api-docs.deepseek.com/guides/codex)、[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[更新日志](https://api-docs.deepseek.com/updates/)。型号路由可能变化，应以提供商最新说明和实际响应为准。

软件初始化显示上述文档候选，不自动发起模型推理，也不要求 Codex。用户点击刷新后仅请求 `/models` 元数据；未知的新调用名也保留。目录未列出的文档候选、目录网络故障、无效密钥和未配置密钥分别提示，不将“有一个选项”等同于账户调用成功。

刷新失败保留当前选择及同一密钥下最近成功的目录。换密钥不沿用前一个密钥的服务目录。响应不返回密钥，缓存识别仅使用密钥摘要。已有默认模型配置保留，用户可自行改成 Flash 或 Pro。

本项没有扩大 DeepSeek 推理档位控制；界面中的档位明确属于 Codex。DeepSeek 仍采用现有请求设置及服务默认。目录刷新没有生成 token；实际对话、生成及连接测试会调用所选服务。

## Codex 目录

按 [Codex App Server 官方接口](https://learn.chatgpt.com/docs/app-server) 逐页读取 `model/list`，使用返回的调用名、默认型号和支持档位。不会通过预置型号冒充账户支持，也不把隐藏型号显示成正常可选项。

2026-10-03 对本机安装的 CLI 进行了两次只读核验，均返回八个型号：GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol、GPT-6 Luna、GPT-5.6 Sol、GPT-5.6 Terra、GPT-5.6 Luna、GPT-5.5。本次未复现历史上“只剩两个 Luna”；实际修复的是分页遗漏、Windows npm 脚本与原生程序路径一致性，以及目录故障时不丢弃最近成功的完整列表。

实时目录、上次目录、本机备用目录会分别显示。配置、登录文件变更及隔离数据环境不复用旧目录缓存。目录可以反映 CLI 客户端配置和账号状态，不能保证每个型号实际推理成功；本次没有对真实账户发起付费模型生成。
