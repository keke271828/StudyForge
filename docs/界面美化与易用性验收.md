# 界面美化与易用性验收

本项完成源码实现和隔离验收，没有重新打包。用户已指示进入历史需求全面审计与修 bug；最新结果见《全面审计与修复验收》。

## 打开与操作

1. 从托盘完全退出旧版，双击项目根目录的 `验收最新版.vbs`，确认标题带「源码验收版」。
2. 左侧集中显示六个工作区：学习工作台、资料库、成果文档、练习与作业、学习画像、设置与联动。项目列表与新建项目在导航下方。
3. 点击右上角「外观」，或进入「设置与联动 → 外观与操作」。这里的选项立即生效并自动保存，完全退出重开后保留。
4. 可选暖纸／青绿／夜读三个主题、标准／大字阅读字号、舒适／紧凑界面密度、跟随系统／减少动画、两种聊天发送方式。
5. 右上角「专注模式」收起项目和资料侧栏，保留工作台控件和当前草稿；再点击或按 Esc 恢复。有原生弹窗时 Esc 先关闭弹窗；展开的「更多设置」也可用 Esc 收起。
6. 设置分为外观与操作、生成偏好、模型与语音、工具与联动、运行与更新。外观自动保存；生成、模型和工具仍用原有「保存全部设置」；软件更新有自己的保存按钮。

外观设置使用本机设置文件，跨启动端口保留；不依靠当前网页端口的 localStorage，不更改模型、讲解要求或生成参数。

## 常用操作与布局

- 格式、概括性强弱、同步出题和生成按钮保持在聊天输入框底部，可直接操作。审查、语言、风格和特别指定的习题格式放在「更多设置」。
- Codex 的模型与推理控件保持在聊天上方。DeepSeek 模式收起不支持的 Codex 推理控件，切回 Codex 后恢复；没有伪造 DeepSeek 的推理参数。
- 资料快选与分类一键选用保留，文件和网址仍可直接导入。切换主题、专注模式不重建聊天或资料节点，不清空输入和选择。
- 原文引用与导师讲解保留不同字体、颜色和引用块；Markdown 与 KaTeX 数学公式继续正常渲染。
- 矮窗口收紧标题、说明和输入区域，保证聊天和发送／生成按钮可用；高级选项弹出方向向上，减少被底边挡住的情况。
- 配色、卡片、控件、空状态、设置分组、焦点提示和启动页统一。图标使用本地 SVG 和系统字体，不新增在线字体或图片请求。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + K | 回到学习工作台并聚焦输入框 |
| Ctrl + Shift + F | 切换专注模式 |
| Ctrl + 1—6 | 切换左侧六个工作区 |
| 设置分类中左右方向键、Home、End | 切换设置分类并移动焦点 |
| Esc | 优先关闭已有弹窗／高级选项，否则退出专注模式 |
| Enter／Shift + Enter | 默认发送／换行 |
| Ctrl + Enter／Enter | 选择第二种发送方式后的发送／换行 |

输入法处于组词阶段时不把 Enter 当作发送，兼容 `isComposing` 和 229 键码判断。实际中文输入法和个人键盘习惯仍请按上述步骤验收。

## 动画与反馈

页面和弹窗使用短暂淡入、轻微位移，控件及进度条使用过渡，通读进行中有状态指示。没有全屏装饰动画，没有为动画增加模型调用。

默认跟随系统 `prefers-reduced-motion`；「减少动画」立即关闭页面、控件和进度过渡。启动页也尊重系统偏好。应用退出前等待已发起的外观保存，保存失败恢复上次设置并明确提示。
