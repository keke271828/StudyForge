# 聊天框直接引用书库章节：使用与验收

2026-10-10。接续[书库本地语义检索验收](书库本地语义检索验收.md)。本轮增加电脑与手机聊天框的 `@` 章节选择器，以及保存到当前对话的引用标签。当前为源码交付，0.4.1 安装包没有更新；验收使用独立测试数据库和文件，未改写正式学习资料。

## 一、直接打开

1. 从 Windows 右下角托盘完全退出旧版 StudyForge。仅关闭窗口会保留旧服务。
2. 双击根目录的[验收最新版.vbs](../验收最新版.vbs)，无需保留 CMD 窗口。
3. 打开学习项目中的一个对话。电脑输入区点“@ 书库”，手机输入区点“@”；已打开的手机页面请刷新并连接当前源码版服务。本轮更新了手机网页缓存版本。
4. 软件内 F1／“使用指南”的全局书库章节已加入对应操作步骤。

## 二、具体操作

### 找到并选中章节

在行首、空格或左括号后输入 `@` 和书名、章或节的标题，例如：

```text
请参考 @数域
```

也可点击 `@` 按钮后输入标题，筛选一本书。候选列出书名、完整目录路径、PDF 范围和阅读状态；同名节点用书籍和真实节点 ID 区分，不把名称字符串当作授权。

- 已整理节点可以直接引用；每个对话最多手动引用 12 个节点。
- 尚未阅读或范围待确认的节点会定位到书库。由用户确认页码与页内范围、主动安排阅读，完成后再引用；选候选本身不启动阅读。
- 方向键选择，Enter 确认，Esc 关闭。候选打开时 Enter 不发送聊天；中文输入法正在选字时保持选字。邮箱及三反引号代码块中的 `@` 不触发选择器。
- 选择已读节点后，输入框中的 `@` 搜索片段移除，正文草稿保留，节点成为可操作标签。

### 区分两种用途

| 用途 | 效果 |
| --- | --- |
| 参考背景 | 辅助当前问题或其他主资料；导师按问题回查相关原页，保留出处。 |
| 重点讲解对象 | 将该节点作为生成对象；没有项目附件时也可生成讲解，生成仍读取整个已确认范围。 |

默认是参考背景。可在选择器或输入框下方标签中改用途；点标签定位原书，点叉号移除。若当前对话曾关闭书库引用，主动选择已读节点会启用手动引用；自动与手动模式仍可在书库参考中调整。

标签随当前对话持久保存，刷新、切走再回来恢复。新建或切入其他对话不会继承这些标签。书和已授权阅读记录仍全局共享，项目聊天记录保持隔离。

### 快速选择与正文搜索

选择器只查书名、目录路径、范围与阅读状态，不进行 OCR、云端模型调用或语义推理；不会因搜索章节而解析全文。输入采用短延迟合并请求，最多返回 12 条候选，更多结果提示补充书名或标题。

想搜索正文中的概念、同义表达或原文片段，可用全局书库的搜索与智能检索。手动选择章节后，实际导师输入仍通过既有原文回查与范围校验，不拿选择器显示的标题代替正文。

## 三、可靠性与界面改进

- 同一对话的引用保存依次合并；不同对话使用各自的保存队列。发送或生成前只等待本次对话的引用保存。
- 新增引用使用数据库事务合并，两个独立请求不会互相覆盖；已有节点去重并可更新用途。
- 旧的查询或保存响应不能覆盖后来选择的引用；切项目或对话时关闭选择器，响应按原归属核对。
- 修复再次从书架添加已引用章节时，将“重点讲解对象”降回“参考背景”的问题。
- 保存引用时防止重复移除或修改；失败显示具体信息并重新同步已保存状态。
- 选择器使用不透明文字底板和弹出顶层，在背景图、手机深色模式下保持可读；支持减少动画设置。
- 输入框标签同时显示节点和书名。在 430 像素以下手机布局，将项目资料状态放到独立短行，保留上传、拍照、退出专注、选项与发送按钮。按钮明确写“项目资料”，避免与书库标签混淆。

## 五、当前边界

这轮完成聊天框直接选择书库节点。它不自动阅读尚未授权的章节，也不把书籍阅读记入学生掌握评分。目录拖动重建层级、十本完整扫描教材的长期负载和复杂证明准确率仍有后续工作；全局书库目前支持 PDF。后续已实现后台时段／每日 token 软预算，见 [书库后台阅读安排验收](书库后台阅读安排验收.md)。

实现主要位于 `studyforge/library.py`、`library_routes.py`、`mobile_access.py`，以及两端共用的 `web/library_mentions.js`、`library_mentions.css` 与 `library.js`。原文校验、生成对象完整读取和各项目聊天隔离继续沿用已有流程。
