# StudyForge 0.4.5

Windows x64 本地 AI 学习工作台。

本版包含以下改进：

- 切换项目、对话或刷新界面后，恢复原通读任务的进度、暂停和重试入口，避免重复启动阅读。
- 支持部分失败任务沿用原资料、模型与要求接续重试，并复用已完成步骤。
- 后台出题和批改成果跟随来源项目、对话，减少打断当前学习。
- 缩小前端任务状态缓存，排除讲解全文和完整聊天副本，并限制旧结束任务的常驻数量。
- 改善常见失败提示和手机连接判断，重写新手操作说明及使用指南。

安装方法：从 Windows 托盘退出旧版后，运行 `StudyForge-Setup-0.4.5.exe` 并安装到原位置。学习数据仍保存在本机用户数据目录。

手机页面由电脑提供，电脑更新后刷新手机网页即可。AI 服务需要自行配置账号或密钥；本版本未接入正式自动更新发布源。

下载时选 `.exe` 安装器；`Source code` 和源码 zip 用于开发，不是安装器。附带 SHA-256 文件可核对下载完整性。

本次发布不代表对所有模型回答、真实大型资料处理速度或整机内存峰值作出保证。
