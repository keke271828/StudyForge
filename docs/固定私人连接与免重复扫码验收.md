# 固定私人连接与免重复扫码

2026-10-09 源码更新，未打包。先从 Windows 通知区托盘完全退出旧版，再双击根目录「验收最新版.vbs」。页面刷新不会更新旧版桌面的主进程与后台接口。

## 一次设置

1. 电脑安装 Tailscale 并登录。此次已通过 WinGet 的官方 Tailscale 包安装电脑客户端，核对安装包哈希成功；电脑的客户端和系统服务已经运行、登录。用户已安装连接安卓客户端；核对到 KEKE-Phone 在线且属于同一账号。
2. 手机安装 Tailscale，登录电脑使用的同一个账号，并开启连接。官方 Android 下载入口：<https://tailscale.com/download/android>。没有 Google Play 时，在 <https://pkgs.tailscale.com/stable/> 顶部 Android 区域下载通用 APK。APK 的后续更新需自行安装。
3. 手机首次打开 Tailscale，点击 Get Started，接受系统 VPN 配置提示；非 Google 账号用 Sign in with other 选择对应登录方式。账号和密码由用户在官方登录页面输入，StudyForge 不接收密码。
4. 打开新版 StudyForge，顶部「连接手机」→「重新检测」→「启用固定私人连接」。这个按钮实际启用 Tailscale 地址、下次软件启动自动连接以及长期记住设备，随后优先显示固定私人地址。
5. 使用面板显示的固定地址完成一次 StudyForge 配对，并在电脑确认。此前已安装同一电脑、同一数据目录导出的 CA，无需因换网重新安装。原来用局域网 IP 配对的浏览器凭据不能跨地址迁移，因此首次改用固定入口需再配对一次。
6. 手机输入区「⋯」→「添加手机主屏幕入口」。支持安装提示的浏览器可直接安装；否则在浏览器菜单选择「添加到主屏幕」或「安装应用」。保存不含配对码的固定入口。

以面板里的实时地址为准，不沿用旧 Wi-Fi 地址。固定私人地址来自本机 Tailscale 客户端的 Self 信息，不允许随意填一个 100.x 地址冒充本机。

## 平时如何使用

- 手机与电脑可以在不同 Wi-Fi，手机也可以使用移动网络；两端 Tailscale 需处于连接状态并属于同一账户。
- 点击同一手机主屏幕图标或书签即可。关闭浏览器、关闭电脑窗口、重启软件不撤销已配对设备；电脑窗口隐藏到托盘后继续提供服务。
- 电脑必须开机、未睡眠，StudyForge 后台必须运行。手机连接不能替代电脑计算，也不能在电脑关机时执行模型请求。
- 默认记住设备 365 天，每次使用会自动续期。也可在连接面板选择 90 或 30 天并「保存连接偏好」，无需中断正在进行的回复。调整记忆期限会在设备下一次请求时生效。
- 清除浏览器数据、更换浏览器、撤销设备或凭据长期不用而过期时，需要重新配对。Tailscale 账号本身的设备登录有效期仍由该服务管理；可在其设备管理页调整自己电脑的到期设置。
- 两端使用固定入口时，换 Wi-Fi 不改工作台地址。若 Tailscale 晚于软件启动才连接，后台自动识别并接入地址；不停止已有手机回复。服务器叶证书接近到期时会自动续签，不更换手机已信任的 CA。

## 软件里具体新增了什么

- 独立的「固定入口，随时接着学」设置区：安装/连接状态、固定地址、官方安装入口、重新检测和一键启用。
- 局域网与 Tailscale 可同时使用；固定入口优先显示，仍可手动选择 Wi-Fi 地址。
- 配对设备自动续期、30/90/365 天偏好、已连接设备的保留日期与撤销入口。
- 连接偏好在编辑期间不被后台轮询覆盖。
- 桌面和后台的连接协议版本检查：旧后台下隐藏错误地址和二维码、禁用新版连接操作，提供「保存并退出旧版」，避免新界面仍调用旧后台。手机连接管理的本机请求超时调整为 20 秒，不再用原来的 3 秒误中断启用、退出和客户端状态读取。
- 连接自检识别 Tailscale，不把正确的私人网卡误报成应该避开的 VPN，也不按手机 Wi-Fi 网段判断跨网络是否可达。
- 只有启用固定连接、确认本机 Tailscale 地址后才接受对应私人网络请求；手机的资料范围、审批和密钥隔离继续生效。没有启用公开的公网隧道。
