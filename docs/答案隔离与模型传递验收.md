## 本项修复

- 出题、习题批改、费曼评估、作答文件提取及编程出题/批改使用私有上下文。服务、模型和推理强度沿用当前选择，参考答案不进入导师的公开对话或内部对话缓存。
- 配套习题不复用文档导师的运行环境；无对话编号的生成任务也使用独立出题环境。Codex 出题继续使用独立临时会话。
- 私有上下文不能通过工具修改文件、生成图片或导出文档；参考解由应用存入私有解答字段，完整提交后按既有流程公开解析。编程测试仍由应用的判题流程执行。

- 五个学习评估入口现在传递学习对话工具栏所选模型。Codex 推理强度先验证，DeepSeek 不查询 Codex 模型目录，也不接受 Codex 专属的推理强度字段。

## 手动验收

1. 在学习对话选服务和模型，导入一份资料并勾选同步出题，生成讲解。
2. 在提交之前查看题组和配套文档，确认没有解析；继续与导师讨论讲解。
3. 在“习题与作业”提交全部作答，确认批改与解析正常；需要费曼讲解时继续完成该流程。
4. 选择编程语言并布置作业，提交对应文件。出题与批改使用当时工具栏的服务、模型和强度。
5. 使用 DeepSeek 时可以关闭 Codex；题组出题、批改与讲解不依赖 Codex 启动。

题目自身可能暗含提示；这些修复隔离参考答案和内部协议，无法保证任何模型绝不从原资料自行推导答案。
