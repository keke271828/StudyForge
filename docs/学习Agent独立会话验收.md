# 学习 Agent 独立会话与共享工具验收

日期：2026-10-02。范围为用户本轮列表的第一项，以及追加的“独立工作区、软件对话不进入 Agent 外部历史”。仅修改源码，未打包；旧安装包不包含本次改动。下一项需用户审批后开始。

## 实际接入方式

- Codex 使用真实 App Server，按项目建立本机工作目录，按学习对话建立临时会话。导师与讲解运行期间共用该会话；临时会话不加入 Codex 历史列表。
- 软件自己的问答和讲解继续保存到本机。服务重启后恢复已保存的消息，在新的临时会话继续学习；这不等于保留服务重启前未保存的中间推理。
- DeepSeek 使用独立工具执行循环，共用软件保存的学习对话，无需运行 Codex 或 DSH。这里没有嵌入 DSH Desktop 的窗口或私有实现。
- 两种服务共用来源读取、文件权限、联网、视觉、视频、图片生成和导出工具；保留各自模型能力的实际差异。工具层并非某个 Agent 客户端全部功能的复制品。

官方接口说明：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。本机协议结构与实际服务均已核对临时会话字段，未复制或改写用户 Codex 登录文件。

## 本轮修复

1. 文档插图和视频抽帧可通过原文件位置或提取图片路径交给视觉模型；保留原文件、位置和视频时间。BMP、TIFF 也直接使用视觉读取。
2. 同名但不同路径、不同版本的原资料使用不同图片缓存，防止读取错图。原文件变化或读取目录撤销时，旧图权限失效。
3. 后续学习对话恢复先前读取的图片关联。生成图片可在当前项目继续查看；不会自动获得其他项目的文件权限。
4. 插图列表支持分页，原文和插图各自返回下一次读取的位置；已完成的原资料读取复用缓存，核对视频画面不重复转录全片。
5. 优先检索知乎，再检索 B 站、课程与大学站点，最后扩大范围；过滤无关结果，搜索摘要只提供线索。习题题源也通过同一套工具检索并读取正文，关闭联网时停止检索。
6. “是否允许 AI 读取网页视频”同时约束网页下载、缓存视频、视频抽帧和后续读取。下载中撤销后不开始转录；视觉读取结束时再次检查权限。
7. AI 生成图片实际验证 PNG 后保存并展示。讲解中引用的图片可嵌入 Word、PDF、PPTX；正式讲解不额外添加 PNG 成果，图片缺失时明确报错。
8. 工具规则要求尊重学生的篇幅、实际执行后报告结果，减少重复技术清单与无关提醒。DeepSeek 服务错误区分无效密钥、余额不足、模型或接口错误、请求过频，并保留请求编号；连接失败和超时不会显示为空白错误。
9. 文本写入覆盖已有解析器支持的源代码扩展名，以及 Jupyter Notebook；C#、SQL、PowerShell 与笔记本的写入、精确修改、备份和重新读取均已验证，不执行未请求的代码。

## 外部条件与范围

- 文件修改目前覆盖授权目录中的文本与代码，办公文档支持读取和重新导出。没有实现任意二进制文件编辑或无限制执行电脑命令。
- AI 绘图需要另外配置兼容的图片生成服务。尚无绘图密钥，本轮未进行实际付费绘图；服务调用、PNG 保存及文档内嵌采用模拟响应验证。
- 视频使用字幕／转录及采样画面，不是逐帧观看；具体 B 站或知乎内容仍可能需要用户登录或浏览器导入，不能绕过平台访问限制。
- 其他导出格式暂未承诺内嵌生成图片；本轮明确验证 DOCX、PDF、PPTX。
- 历史隔离针对本次更新后创建的学习会话，既有外部历史没有删除。

测试使用隔离目录，不修改用户现有资料、画像或外部对话。源代码版本仍为 0.3.4；安装包保持原样。
