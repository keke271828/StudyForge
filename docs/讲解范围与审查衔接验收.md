# 讲解范围、审查衔接与实际内容复核

2026-10-14，源码更新，未重新打包。本轮优先处理教学质量与当前要求能否贯穿成品流程。

## 改了什么

生成讲解原本会收到冻结聊天、本次输入、学习目标、详略档位和分章位置；审查入口没有显式收到同一份本次要求、详略与章节范围。DeepSeek 等客户端会继承部分对话，不能据此说审查完全没有上下文，但新输入框要求不一定属于已有历史。

现在撰写、核查和必要的修订使用同一任务的要求、详略及当前章节范围：

- 按当前问题检查应该讲到什么，参考资料中范围外的内容不自动算遗漏。
- 学生要求简短，也须保留必要条件、关键理由，核对已写出的结论和例子。
- 串行与并行章节各自获得章节范围，不要求某章补齐整本资料。
- 只有实际审查客户端继承了相同历史，才去掉重复的整段聊天文本；脱离历史的审查仍接收完整要求。
- 成果的审查元数据保存要求指纹、详略档位、章节范围指纹和历史复用状态，不再重复保存一份聊天正文。
- 任务开始后新增聊天不改写这项任务的要求；暂停继续仍使用原快照。

真实数学回答还暴露了“把充分条件说成必要条件”的问题，现有审查增加对此类表述的核对：`只有／只在／才／必须` 要有必要性依据，不能把常用构造说成唯一可用条件。这不是专为某个数学题硬编码答案。

没有修改导师模型或默认推理强度；没有新增固定审查轮次：极速 0；快速 1；平衡 1，发现问题再修订 1 次；严谨 3，必要时修订 1 次并复核 3 次。联网、题单和其他已有生成步骤另计。

## 实际模型结果

固定配置 `deepseek-flash / high`，关闭外部工具，使用不含真实学生数据的短合成原资料。程序与数据分别保留：

- `build/teaching-scope-20261013-baseline`：六项初次讲解，四项成功，两项连接失败。
- `build/teaching-scope-20261014-retry`：只补测上述两项，均成功；没有覆盖原失败记录。
- `build/explanation-audit-scope-20261014-1`：四项范围审查，一项成功，三项连接失败。
- `build/explanation-audit-scope-20261014-retry`：只补测三项，均成功。
- `build/actual-teaching-audit-20261014-1`：实际数学原稿核查，连接失败。
- `build/actual-teaching-audit-20261014-2`：同一原稿快速审查成功，约 85.77 秒。

共 17 次样例调用，11 次取得结果、6 次未取得结果。不是底层网络重连或计费次数统计；对照页面复用了数学原稿，因此显示 12 个条目，不是 12 个独立成功样本。

### 人工判断

1. **数学追问：**两种提示均能回应量词次序、`N(n)=n+1` 的空真问题，并完成 `1/n` 的统一门槛演算。两种提示也均把有限门槛的充分性说得过强，不能宣布任一份全文合格。
2. **实际快速审查：**正常一个核查请求找到上述过强表述，局部修改为“常见充分情形”，没有重写全文或追加独立复核。人工检查确认这一处正文已改善。审查证据自身又把无限多个相同门槛的指标族称成无限集合，仍不严谨；原报告保留，不能把自检记录当作无误证明。
3. **哲学模式：**精学通过完整例子解释评价原则；研究增加法律、习俗、道德含义的边界、替代解释与核实方法。概览仍偏长，模式仍有重叠；简短提示基线也有可读性优势。没有因此继续堆长共用提示词。
4. **范围对照：**同一正确短讲解，提供范围与不提供范围的两组都通过，没有复现缺少范围必然误判的情况。两组都运行当前审查程序，是输入范围的消融检查，不是历史版本复演。

这不是随机多次抽样，也不包括完整视频、扫描教材、网页端实测或学生学习成效。速度受网络、服务和缓存影响，未证实总生成时间减少 30%；85 秒的实际快速核查本身仍偏慢。哲学样例中的模型历史补充未联网核实，不作已核实出处。

## 怎么打开验收

1. 若旧 StudyForge 在托盘运行，先从托盘退出。
2. 双击根目录的 `验收最新版.vbs`，进入当前源码版本，不需要重新安装。
3. 在学习工作台写明确要求，如“只解释这一构造为什么成立，定义我已懂，不要重讲全章，不要出题”；选择详略档位，使用快速或平衡审查生成 DOCX。
4. 讲解和修订都应保持这次问题的范围；必要条件仍要说清。新开的独立聊天不应改变已经启动的任务。
5. 阅读 `build/teaching-scope-review-20261014/讲解与审查实际对照.html`，可先隐藏标签判断，再展开人工评价和原始输入；也可下载每份原始回答。

原有安装包没有这些新源码改动。隔离试验不改写用户真实资料、聊天和画像；本轮不代表最初全部需求已重新验收完成。
