# 按需练习与复习验收

这是逐项改进的第六项，已修改源码并自检，未重新打包。后续讲解质量、多格式成果、模型目录、托盘和更新等项目尚未在本项完成。

## 打开与验收

退出旧窗口，双击项目根目录 **验收最新版.vbs**，确认窗口标题带“源码验收版”，进入 **练习与作业 / 习题与编程作业**。使用原有本机资料与设置；新增表保存提示、低分策略、复习计划和任务关联，不重写已有试卷或聊天。

1. 打开一套尚未提交的普通习题。题干支持 Markdown 与数学公式；每题下方的 **需要思考提示？** 可选择卡点，依次查看三层思考方向。提示不读取私有答案，使用的类别和层数会保存。
2. 展开 **作答条件与低分处理**，说明是否参考过笔记或解析，选择 **先诊断，自主选择修复**。已有题组默认保留原有费曼进阶方式，混合复习和新修复题默认采用自主修复；选择在完整提交时保存。
3. 完成全部题目并提交。自主修复模式低于80分时，显示逐题依据、暂定卡点和下一步建议，不自动提高难度；费曼讲解可选。原因缺少可核对的作答引句时显示“待定位”，不把低分直接解释为缺少前置知识。
4. 点击 **带回导师定位卡点**，题干、批改反馈、作答引句和暂定诊断加入当前导师输入框，保留原有要求与对话。需要你主动发送，不会悄悄再调用模型。
5. 需要练习时点击 **请求同难度修复练习**：重新读取可用原资料，要求不同情境、相同薄弱知识、保持原难度，经原有出题审查后发布。单独输出无答案 DOCX；重复点击打开已经生成的修复题，不重复出题。完成这套题后可继续请求下一套。
6. 想检验保持情况时，展开 **可选：加入延迟复习**，选择题目与1—90天间隔。只加入选中题目，不调用模型、不生成新题。
7. 打开 **复习队列**，跨项目选择1—6题，点击 **开始所选复习**。题目进入当前项目的新复习套题，提交前隐藏本次解析；完整提交后显示评分和解析。可只看到期题、继续进行中的复习、分页或移出队列。
8. 提前开始复习时会如实标记。完成后按选定间隔安排下一次；调整计划只改到期时间，不将安排计划误记成一次作答。移出不删除原题或成绩，也不会被已经开始的复习重新加入。
9. 到 **学习画像** 核对提示支持、笔记自报、复习次数和开题间隔。依然能查看原依据、纠正和移出；这些条件不被包装成客观掌握概率。

不勾选同步出题时，讲解或问卷不会自动创建练习与复习计划。只有主动完成习题并加入后才有复习队列。本项提示和混合复习用于普通习题，容器编程作业保留已有流程。

## 低分与通过线

| 方式 | 79分 | 80分 | 费曼讲解过关后 |
| --- | --- | --- | --- |
| 原有费曼进阶 | 进入原有费曼环节 | 达到本次通过线 | 按原流程生成更难题组 |
| 自主修复 | 定位原因，自主选择补讲、费曼或同难度练习 | 达到本次通过线；有支持时单独标记 | 不自动出题或加难度 |

80分是当前流程的通过线，不表示长期掌握。提示支持和笔记使用也保留在逐题画像证据中；后续自动难度选择对带新作答条件的知识点优先参考“未用软件提示且自报未看笔记”的成绩，条件未说明时不凭支持后的高分自动提升难度。原始评分不被改写。

## 证据与费用边界

- 三层提示是按六类卡点编写的固定方向提示，不是已经理解每道题后给出的具体解题提示。不会读私有参考解，也没有额外模型请求；详细解析仍须完整提交后查看。
- 诊断复用原有两次批改请求；分数差超过10分时按原流程再复核一次。检查引句确实来自对应作答，但不能据此证明模型对错误原因的解释正确；界面明确标为暂定，证据不足时先询问。
- 批改开始后暂停新增提示，避免遗漏作答条件；重复提交被同套题的短期占用记录挡住。正常错误或取消会释放，异常终止后的记录最多15分钟失效，不据状态标签提前显示解析。
- 复习队列直接复用已批改题目及私有参考解，整理、开始和移出不调用模型；提交仍调用当前所选模型批改。请求新修复题仍有生成、解题审查及可能的资料视觉读取用量。
- 已发布的原题解析仍可查看。本次复习隐藏解析是界面支持，不是禁止学生查阅旧答案或外部帮助的考试防作弊机制。
- 间隔从上次完成作答到本次打开复习计算，不测量期间是否再次阅读、是否拖到几天后才答。修改计划不会重置这个起点；完成复习才更新起点。
- “至少24小时且自报未看笔记 / 未用软件提示”的次数只是记录筛选，不证明独立完成、长期保持或迁移。1、3、7、14天是可选间隔，尚无个体化记忆模型或最优间隔保证。
- 同难度新题是保持难度参数并请求变换情境，不能自动保证模型生成的题目在语义上绝不重复，也不能保证实际难度完全相等。真实教学和判分质量还需要用户用自己的多学科资料验收。
- 打开的题目、草稿和选项能保留在列表刷新及切换页面中；当前未提交草稿保存在运行中的界面，不承诺重启后恢复，避免将临时草稿误当正式作答。
