# 对话放大与全屏

更新日期：2026-10-04。已纳入 0.3.5 桌面发行版本。

## 打开与操作

安装方式：从 Windows 右下角托盘完全退出旧 StudyForge，再运行 `dist/StudyForge-Setup-0.3.5.exe`。安装后从桌面 StudyForge 快捷方式打开。源码验收仍可双击项目根目录的 `验收最新版.vbs`，窗口标题带“源码验收版”。学习工作台的对话标题右侧提供“放大对话”和“全屏”。

| 操作 | 实际效果 | 返回方式 |
| --- | --- | --- |
| 放大对话 | 对话占满当前窗口，收起项目侧栏、顶部项目栏和资料快选；先收起上方导师工具，为正文增加高度 | “还原布局”、Esc 或 Ctrl+Shift+E |
| 全屏 | 放大对话，并在桌面版调用原生窗口全屏，隐藏窗口边框和标题栏；网页入口使用浏览器全屏 API | “退出全屏”、F11 或 Esc |
| 展开导师工具 | 在放大或全屏中临时展开模型、学习模式、资料通读及阅读入口 | 再点击“收起导师工具” |

- Ctrl+Shift+E 切换放大，双击对话标题空白处也可切换。
- F11 切换全屏。从普通布局进入全屏，退出后回到普通布局；从放大布局进入，退出后保留放大，再按 Esc 还原。
- 长按快捷键不会反复切换模式。
- Esc 先由作业、阅读等弹窗处理；未打开弹窗、菜单或编辑器时，才退出全屏或放大。退出这些显示模式不修改既有专注偏好。
- Ctrl+P 会恢复侧栏并聚焦项目/对话搜索；切换到其他工作区也自动恢复导航并退出对话全屏。
- 当前模式是临时阅读状态，不保存成模型设置，也不在下次打开时强制全屏。

## 内容与任务保持

放大、还原和全屏使用同一个对话面板与消息节点，不重新选择对话，不重新读取资料，不发送模型请求。聊天历史、未发送文本、输入选区和原有阅读位置保留；在聊天底部时继续贴近底部，在中段阅读时尽量保持原可见段落的位置。

资料引用、模型与学习模式使用原来的值。收起导师工具只改变显示；通过“展开导师工具”继续使用原控件。输入、提交作业和成果生成仍可操作，模型任务没有接入显示模式的忙碌锁。

界面背景、分区透明度、字体和动画沿用既有设置。窄窗口下输入区可以单独滚动，避免长输入或生成选项把正文和退出入口挤出窗口。

## 原生状态与失败恢复

桌面全屏通过限定为本机主窗口的 IPC 调用 `BrowserWindow.setFullScreen`；外部网页、子帧和其他窗口不能控制它，参数只接受布尔值。

监听进入/退出全屏、窗口尺寸和显示事件，同时在全屏期间低频核对实际窗口状态。操作系统退出或个别原生事件未送达时，界面仍会恢复对应状态，避免留下错误的“退出全屏”按钮。该核对是本机 IPC，不消耗模型额度。

切换失败时还原进入前的布局，恢复可用按钮并显示错误。切换尚在进行时要求退出，会在当前切换结束后继续退出，不留下无法返回的模式。
