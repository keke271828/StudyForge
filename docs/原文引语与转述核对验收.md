# 原文引语与转述核对验收

2026-10-17。本轮继续改善学习内容的可核对性：明确区分逐字引文、空白差异、改写和来源缺口。源码完成，尚未重新打包。

## 实际问题

旧来源统计会去掉全部空白再比较，界面却称其为“逐字匹配”。这会混淆 `ab` 与 `a b`，也可能掩盖公式、代码或词义差异。导师聊天没有相同的最终来源检查。

回放上一轮保存的 DeepSeek 真实极限回答，发现模型将原文件中的纯文本公式、字句与标点改成 LaTeX，仍标成“原资料那句话”。这是引文身份问题；未逐字匹配本身不说明数学错误。本轮保留完整原回答，没有另调模型改写它。

## 已实现

- 新记录将引句片段逐字匹配、仅忽略空白匹配、文字未匹配、无唯一来源定位分开。旧记录没有新字段时说明未区分空白差异，不再据此宣称逐字一致。
- 核对当前已选来源中的 `[来源名｜位置]`，以及可识别的文件名加行号等尾注。找不到或同名定位不唯一时保留疑点，不自动读取未选文件或其他项目。
- 导师声称是原文且没有逐字匹配时，在回答开头添加“软件引文核对”。原模型正文完整保留；导师自己的无来源示意不会仅因使用引用块就被一概提示。
- 提示与聊天共同保存、重开恢复并进入下一轮公开上下文。DeepSeek 能原位更新的私有协议保留；不可修改的旧远端会话从公开记录恢复，不删公开聊天。
- 文档及 Anki 卡片沿用同一来源状态，Word 导出保留提示与系统总结位置。没有新增固定模型请求、评分或画像能力判断。
- 支持带省略号的有序引用片段核对，但明确不保证省略恰当、公式等价、条件完整或教学正确。详细引用回执最多列50项，超过部分保留总数与提示。
- 软件内零基础指南和手机缓存壳v53同步。

## 验证结果

最终三组检查分别154、86、28项，按测试标识去重后 **244项全部通过**。涵盖定位范围、空白与符号差异、省略顺序、未选来源、超过回执上限、中文／英文／双语、损坏旧缓存恢复、DeepSeek与Codex聊天续接、其他既有交付行为。

其中 **三份受控完整DOCX任务**使用实际客户端、文件写出与重读，分别验证逐字、空白、LaTeX改写状态和系统总结。模型响应来自受控传输，不能冒称三次真实云端生成。

**四项实际界面检查**通过：Electron成果卡、电脑聊天公式与刷新重开、配对HTTPS手机恢复和继续提问、请求次数与界面错误检查。两次受控模型响应，零次外部模型请求。手机为390px浏览器宽度，不代替真实安卓手机全部流程。

## 仍有边界

只识别目前支持的引用块和来源标记，不保证所有写法都被识别。未匹配可能只是正确改写或格式变化，不能直接判为编造或数学错误。片段按序逐字相同也可能遗漏关键条件，仍需内容审查。

本轮改善的是来源身份和反馈的可靠性，不宣称解决模型重复讲解、全部推理质量、整段视频耗时或全应用内存。已安装EXE仍为原内容，本轮未打包。
