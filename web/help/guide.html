第一次使用：走通一遍

先不上传文件。用一句简单的问题确认 AI 能正常回复。

  1. 连接一个 AI。点下方“打开 AI 设置”，按连接 AI中的一种方式填写并保存。已经配置过就跳过。
  2. 创建项目，进入对话。电脑左侧点“＋ 新建学习项目”，输入“我的学习”，点“创建”；进入该项目中的一个对话。手机在“项目与对话”中创建。
  3. 选服务，发一句话。回工作台，在“AI 服务”中选刚配置的服务。输入“请用中文解释什么是函数”，点“发送”。手机可在“学习选项”里选服务。

成功后你会看到：问题留在聊天区，导师在下面回复。离开页面再回来，进入同一项目、同一对话即可继续。

接下来，学自己的材料看上传资料；要可下载的文件看生成讲解。仅聊天时不必点击“生成讲解”。

打开后没有窗口，或者没有回复？

没窗口时看 Windows 右下角托盘，点 StudyForge 图标恢复。没回复时先看错误提示，再到 AI 设置检测连接。软件能打开，不代表模型服务已连通；详见报错处理。

先分清这几个动作

上传以后，为什么导师还没开始读？

放入资料＝保存文件

文件加入当前项目，不会自动读完整本书。“待解析”表示尚未提取内容。

解析＝提取要读的内容

例如从 PDF 第 3 页提取文字和公式。先指定范围，再开始。

通读＝让 AI 整理笔记

适合先熟悉资料再深入讨论。它是可选步骤，不是每次提问的前置要求。

勾选 / 引用资料：表示“本次对话请参考它”。保存文件不等于已选用；“清空选择”只取消引用，不删除文件。新对话默认不选资料。

发送：在聊天区得到回复。生成讲解：制作可下载的成果文件。两者参考当前对话的资料和要求，但发送消息不会自动导出 Word。

只需先连接一种服务

连接 AI，选择模型

电脑打开“设置与联动 → 模型与语音”。先用你已取得调用权限的服务，完成下面对应的一种配置。

我用 DeepSeek
  1. 在“DeepSeek API 密钥”填写服务商给你的密钥。它是调用凭据，不是账号密码，也不是聊天网址。
  2. 模型先保留默认值，或点“刷新 DeepSeek 模型目录”选可用模型。
  3. 点“保存全部设置”，再点“检测 DeepSeek 连接”。
  4. 检测通过后回工作台，“AI 服务”选 DeepSeek，发一句简单问题验证。

不必同时打开 Codex。服务商的 API 额度与网页聊天额度可能不同，以实际账号为准。

我用本机 Codex

先确保电脑的 Codex 运行环境已安装并登录，在“设置与联动 → 运行与更新 → 运行环境”查看是否可用。工作台选 Codex，再选账号可用的模型；留空沿用本机默认。仅打开本软件不会自动完成 Codex 登录。

我用 Gemini 或其他第三方模型
  1. 打开 AI 服务管理，点“添加 AI 服务”。
  2. 按类型填写名称、API 接口地址、模型调用名和密钥。普通聊天网站地址不是 API 接口地址。
  3. 保存服务并检测连接，再到工作台“AI 服务”中选择。

Gemini API 使用密钥；“Gemini · Google 账号”通过本机官方 Gemini CLI 登录，需按入口完成安装与授权。Gemini 客户端能聊天，不表示 CLI 或 API 已授权。失败时保留原提示。

配置成功的标志：工作台能选到服务，而且一句简单问题能得到回复。看到模型名称不等于连接成功。

聊天时在哪里切换？

电脑在工作台上方选“AI 服务”“模型”“推理强度”；手机打开“学习选项”。导师与文档生成沿用当前对话选择。已启动任务继续使用启动时设置。

推理强度和 API 连接方式怎样选？

首次先用默认模型、自动推理。复杂证明或复核再提高强度；高强度通常更慢，只对支持它的模型有效。连接超时时，按网络情况尝试“沿用环境配置”或“直接连接”后重新检测。需要代理的服务应保留可用代理；直连不关闭证书校验。

一个主题建项目，一个话题建对话

项目、对话与历史记录

例如建“数学分析”项目放教材，再分别建“极限”“连续性”两个对话。同项目共享文件，但各对话分别选资料、保存聊天和讲解要求。

  • 新建项目：电脑左侧“＋ 新建学习项目”；手机打开“项目与对话”。
  • 新建对话：先选项目，再用“项目与对话”旁的“＋”。新对话不自动读取上个对话。
  • 找回聊天：展开原项目，点原对话；较早记录用“加载更早的消息”。
  • 改名、删除、固定、排序：电脑在条目上右键或用条目菜单；手机使用列表中的操作入口。

关闭重开后：资料和聊天仍保存在电脑本机。回原对话继续，不用为了找历史新建同名项目。

删除了怎么办？哪些内容共享？

项目先进入回收站，可恢复；“彻底删除”不可恢复。成果按项目保存，标明来源对话。全局书库和学习画像可跨项目参考，但不会开放其他项目的聊天全文。

第一次建议只试 1 页

放入资料，只读需要的部分

  1. 上传。电脑点输入框“＋ 文件”或拖到“资料快选”；网址点“🔗 网址”。手机点输入栏“＋”或“资料 → 上传手机文件”。
  2. 选择内容。PDF 旁点“范围”（资料库叫“选择解析范围”），选“指定 PDF 页码”，首次填 1，点“按此范围解析”。
  3. 勾选后提问。解析完成后勾选这份范围资料，向导师提问；想先整理阅读笔记再点“通读资料”。

成功后你会看到：资料不再是“待解析”，当前对话的已选资料出现本次范围。原文件仍保留。

PDF 页码从文件第 1 页起数，可能不是书上印刷页码。3-5,8 表示第 3、4、5、8 页，一次最多 60 页。只读一段时不要先解析整本书。

只读某一页的一段文字
  1. 在“范围”窗口填预览页码，点“只查看这一页”。
  2. 选中原文框中的一段，点“只使用我选中的文字”；手机可长按选文。
  3. 核对原文和来源位置，再点“按此范围解析”。

扫描页预览没有文字时，可按该页解析后核对识别结果。其他文档可选“只读选中文字”，粘贴原文并填写位置；要整份内容时才选“全文解析”。

网址、图片和视频怎么处理？

它们上传后也先保存。网址点“解析网址”，图片点“解析图片”，无需选部分解析。公开网页失败时可试电脑端“浏览器读取”，完成登录或验证，正文显示后再读取。

视频依据可获得的字幕、语音转录和抽取画面，不把推荐、评论当正文；有时需临时下载。耗时取决于长度、硬件、画面识别和模型服务。访问被拒绝时先处理访问条件，或提供有权使用的本地视频、字幕；重复生成不能解决网址不可访问。

支持哪些格式？如何分类？

支持 PDF、DOCX、PPTX、图片、音视频、TXT / Markdown、XMind / FreeMind / OPML、Anki APKG、常见代码、Jupyter、MATLAB 和 Mathematica 等可解析脚本。特殊、加密或损坏文件可能需要转换。

在“资料库”填“新分类名称”并创建，把文件移入分类；工作台可一键选用分类。只读范围时，不要同时勾选已全文解析的整本书。

把卡住的那一步说出来

和导师交流，定制讲解

勾选资料，再写要求并点“发送”。想先熟悉资料可点“通读资料”，完成后点“阅读笔记”；查看笔记不会往聊天里重复插入笔记。

复制后改成自己的要求
请只使用我选中的资料，先说清楚它要解决什么问题，再一步步解释关键推理，尤其是为什么想到这一步。适当给一个具体例子，不要省略关键条件。这次只讲解，不出题。

还不懂时说“我看懂计算，但不知道为什么引入这个量”，比“再详细一点”更容易得到针对性解释。当前聊天中的要求也供后续生成讲解参考。

通读时，可以切换对话或关闭窗口吗？

可以切换对话或项目。回到原对话后，会显示原任务的进度；刷新界面也不需要重新通读。已暂停的任务会保持暂停，点“继续通读”才会继续。任务失败时，先看原因；可恢复的临时错误会提供“重试未完成的通读”。

窗口隐藏到托盘时仍可处理任务。选择托盘中的“退出”或关机，会停止处理。换了所选资料、模型或推理强度后，不会把旧任务当成这次选择的阅读进度；旧任务仍可在“成果文档”中查看。

知识结构里的联系看不懂，怎样追问？

通读完成后打开“知识结构”，选一个知识点。每条联系下方有“请导师讲清这条联系”：论证关系会追问为什么这样推，类比会追问共同点和不适用的地方。点击后会回到原对话，把问题和原文位置补入草稿，保留你已经写的内容；核对或修改后，点击“发送”才请导师回答。它不会自动发消息或布置习题。

再次选择同一条联系不会重复插入同一问题。随问题附带的图谱数据是 AI 整理的参考，不代表你的理解或掌握程度；导师仍需回查原文。

长资料后面的内容，导师也能找到吗？

较长资料仍先完成一次通读。之后提问时，软件从本次选中的原文件内容中寻找相关段落，并附上相邻的定义、条件或证明；不再固定只给导师原文开头。你可以写具体概念，或选中导师原句追问。

本次提供的是有来源位置的原文片段，不等于导师再次核对了整本书；笔记只帮助导航。没有找到明确段落、或完整段落太长时，请补充页码或选段，导师不能靠笔记猜原文。手机续聊也可沿用本对话保存且与文件一致的通读记录，不必重复通读。生成讲解文档仍使用完整所选范围。

怎样针对一句话或一个公式追问？
  1. 在导师回答下打开“针对原句追问”。
  2. 默认“阅读 · 公式排版”可正常看公式；选中文字，点“使用选中原句”。
  3. 回输入框补上疑问，再发送。仅引用不会调用 AI。

要精确选择公式源码时切“Markdown 原文”。长回答可翻前后段。引用的是导师原回答，不自动等于教材事实。

满意的回答如何留下？

用回答旁的保存入口，或提出整理要求后生成讲解文件。完成成果自动出现在本项目资料快选，可手动勾选继续问，不必下载再上传。

不知道怎么选，先用这些

选择讲解方式

首次可用：精学 + 通俗清晰 + 中文 + 快速审查。只想大致了解选“概览”。电脑展开“讲解与生成选项”改风格和语言；手机打开“学习选项”。

选项影响什么
概览 / 精学 / 研究概览抓问题与主干；精学展开动机和关键步骤；研究更重条件、边界和证据。
通俗清晰解释术语，减小步骤，配必要例子或恰当比喻，保留关键条件。
直观与专业并重先建立直觉，再给准确表述与推导，说明直觉怎样对应公式。
学术专业更重定义、条件、符号和论证，默认基础更高。
概括性强弱往“主干凝练”更简短；往“细节丰富”增加步骤、例子和细节。
讲解检查方式如何选？

“极速”生成时自检，无额外审查调用；“快速”加一次综合核查；“平衡”发现问题后修订；“严谨”做三项审查和必要复核，通常更慢。它控制文档核查，不等于缩短聊天，也不保证零错误。

工作台修改当前对话；设置里的默认值主要用于新对话。已启动任务不因改选项而重做。更具体的要求直接在聊天中说。

把讨论整理成文件

生成、下载和管理成果

  1. 确定内容。选好资料，特殊要求先在当前聊天发送，例如“重点解释证明动机”。没提要求则用当前设置。
  2. 选成果。电脑在输入框下选“生成内容”“讲解格式”；手机点“生成”。只讲解时不要勾选“同步生成举一反三习题”。
  3. 开始制作。点“生成讲解”（只出题时按钮随选择变化）。在“成果文档”看当前项目任务进度。
  4. 完成后下载。点成果下载入口；成品也会加入本项目资料快选，可勾选后继续问。

你会得到：所选格式的讲解文件。同步出题时另有一份习题，默认 DOCX，与讲解格式独立。

任务太久：暂停、继续、取消有什么区别？

任务卡“暂停”保留进度，之后点“继续”；有些步骤需等待当前请求结束才暂停。取消是停止本次任务，可能要重新发起；删除记录不等于暂停。不要连续点多次生成，以免排重复任务。

独立任务可有限并行，共用同时处理上限。“同时生成多个部分”开启后，独立章节可以同时写；若原文标明“原文续接”或开头明确接续前文证明，后半部分仍要等前一部分完成及按所选强度核查后再写，避免衔接不上。文件名里出现“接上文”不代表两份资料有关。关闭“同时生成多个部分”时，章节会按顺序完成。讲解与配套习题按相应设置执行；并行不保证每项更快，内存紧张时减少同时运行数。

任务失败后，能接着上次重试吗？

讲解、习题生成、通读、知识整理或另存格式遇到可恢复的临时错误时，任务卡会显示“重试未完成步骤”。点击后核对原资料版本，保留同一个任务和已完成步骤；资料、模型、阅读范围和要求沿用这项任务开始时的选择。要换模型或改变要求，请新建生成任务。

如果没有这个按钮，任务卡会说明原因。内容检查未通过、原资料已改变、删除记录，或未完成的操作可能已经修改文件时，不能直接重复执行。作业评分和错因补讲请在作业历史使用“重试批改”，保留原提交记录。

在哪里改名、删除、排序？

打开“成果文档”先选项目文件夹。文件卡可下载、重命名、删除，列表可按时间、名称、格式排序；任务历史可展开查看或删除。先确认删除的是文件还是任务记录。

其他格式需要什么软件？

PDF、PPTX、思维导图、Anki、代码 / Jupyter、MATLAB、Mathematica 等需相应软件打开。代码和模型要核对运行条件；标为未实际运行的不等于已在目标软件验证。公式显示正常也不代表推导正确。

先作答，再看解析和补讲

出题、交作业与错题补讲

只出题：工作台“生成内容”选“只生成习题”。讲解配练习：勾选“同步生成举一反三习题”。新题单完整提交前隐藏答案。

交作业的完整流程

  1. 打开题单。电脑工作台点“✓ 提交作业”，选本项目题单；手机点“作业”。
  2. 逐题作答。直接填写，或上传已完成的文件，再点提取 / 识别到答题框。核对题号、文字和公式；上传文件本身不算提交。
  3. 确认提交。不会的题注明卡点。勾选完成确认，再点“提交作业 · 立即输出解析”。
  4. 分别看两份文件。先提供“原题与答案解析”；导师另行评分、分析错因，生成“批改与错题讲解”。

批改出现问卷时：导师尚不能确定错因，批改文档等待你填写真实思路后继续；参考解析仍可先看。

低于80分以后，要做什么？

提交前展开“作答条件与低分处理”，可选择：先找出不懂的地方并补学，或先用自己的话讲解（费曼学习法），通过后再做进阶题。前一种方式允许先做同难度练习。两种方式都以80分为通过线；自评不会改写作业分数。

怎样要提示、追问批改或复习？

作答时可展开通用思考提示，它不提供参考答案；实际请求过的提示会记录，但不直接扣分。批改后可按错因再练，或主动加入复习队列。原对话直接问“某题单第2题为什么这样改”，不用重新上传反馈。

评分还需确认时复核原作答，仍是同一次作答，保留原帮助条件。题目或评分标准版本改变时，不把两次分数直接当同题进步。详细批改失败或取消时，先看原作业记录能否“继续原批改”。

编程作业怎么用？

在“练习与作业”先选语言，再点“根据选中资料布置编程作业”，按题意提交代码。Docker 和语言环境可用才运行隔离测试；只看代码得出的反馈不能视为实际运行通过。

题单改过、批改中断，或想继续追问题目？

题单已有提交记录时，可在习题页点“按题回看，再向导师追问”，选具体题目后回原对话继续问，不必复制整份批改。错因提问和诊断说明支持公式排版；你的作答引句保留原样供核对。切换项目或对话后，尚未完成的旧追问读取不会写入新草稿。

题单后来被修改时，旧作答仍按提交时保存的原题和参考解析回看，并显示“当前题单已变更”。旧问卷、重试批改与再练入口会停用，避免把旧成绩配到新题上；已交付的文档仍可下载。若原题版本未完整保存，软件会说明无法按题核对，不会用新题补猜。

如果在批改、容器判题、补讲或文档排版期间改动了题目或参考解，本阶段结果会停止交付，并提示核对版本。已经完整提交的作答与此前正确保存的评分保留；不会靠反复请求模型修复版本冲突。请先核对旧记录，需要按新题练习时另建题单。

异常中断后，可从作业历史点“重试批改”继续原任务。软件会核对这次作答、原题版本和已保存成绩，能对应时复用评分，只补做尚未完成的讲解，不会因恢复再次计分。若记录缺失或无法对应，会说明原因，不会拿“最近一次成绩”代替。“重新检查原作答”则是你主动要求再判断评分，与继续未完成任务不同。

只写“答案是4”“我选B”或一个最终公式，通常不足以判断为什么错。导师会先询问你当时怎样得到结果，不会仅凭结果断定是粗心或概念不懂。你填写的原因会标为你自己的说明；批改里的多行作答引句始终保持引用样式，与导师自己的讲解区分。

不必反复整篇重新生成

听不懂，或怀疑导师讲错了

读完讲解可填理解反馈：不懂术语、缺前置知识、不懂构造动机、不知道何时用方法、不能独立论证、计算或实现出错；“其他补充”写具体问题。问卷可选。

最好补充“第几节 / 哪句话，我理解到哪里，哪一步接不上”。在“卡在哪一节或哪句话”里选章节，再点“查看本节原句”，可正常阅读公式并选中具体片段；选不准公式或表格时切到“查看排版原文（Markdown）”。选完仍需填写疑问并提交，才请导师回应。

不是我不懂，而是讲解可能有错

用内容核对入口或在原对话指出原句、条件、页码、反例。需要解释就补充教学；需要纠错先核对事实。无法确认的地方保留疑点，核查次数不等于结论一定正确。

帮助导师了解你，你也可以纠正它

学习画像：查看与纠正

“学习画像”记下你的知识疑问、理解、学习困难、作答、自评和教学偏好，帮助其他对话中的导师了解你的学习情况。闲聊、软件操作和任务进度不应作为知识水平判断。

  1. 打开“学习画像”，搜知识点，查看判断来源和时间。
  2. 自评尽量沿用已有知识点名称，填掌握度与主观难度。
  3. 不准确就更正，或将无关记忆移出画像。

自评有什么用：供导师调整讲解与题目，可按你选择的权重参与综合参考分；不会改写实际作业分数和80分通过线。

画像会永远记我“不懂”吗？后台整理是什么？

同时看近期作答与历史困难。读过不等于掌握，一次高分不证明独立、长期掌握，提示和笔记等条件分开看。共享的是学习记录与判断依据，不是所有项目聊天全文。

“后台学习记忆”可关闭自动整理、调间隔和开销限制。它向产生记录时所选模型发送少量学习片段，不是在本机永久训练一个模型。

把想了解和想学透的主题分开安排

广泛了解与重点精学

“学习路线 → ＋ 新建学习目标”，填主题、领域和“学到什么程度”。例如“能解释高斯定律的条件，独立判断何时不能直接用它求场强”。

  • 广泛了解：知道问题、核心观点与范围，再决定是否深入。
  • 重点精学：理解方法理由，独立论证或做题，检验迁移。
  • 独立探究：提出问题，比较资料、证据和边界。

可从知识结构加入目标，也可暂缓。理解检查按需发起，保存目标不自动出题；重点多时先集中少量主题。

适合整本 PDF，不必先读全文

全局书库：按章节积累参考资料

项目资料库服务当前项目；全局书库的书和阅读结果可给多个项目参考，不会把所有书一次塞入聊天，也不共享其他对话记录。

  1. 放书。打开“全局书库”，点“＋ 放入 PDF 教材”，仅保存文件。
  2. 建目录。选书后按“自动找目录”识别章节；有误再展开手动指定目录页。
  3. 选章节并核对范围。勾选章、节，也可点“全选本书目录”。软件先自动找页码；找不准时才请你查看原页确认，不必逐章手填。
  4. 安排阅读。想现在开始，选“优先开始”；想让聊天先用 AI，选“空闲时再读”。再选阅读顺序和详细程度，点击开始。
  5. 用于聊天。回工作台引用章节，或让自动检索找到相关已读章节作为参考，必要时回查原页。

“AI已整理”表示：所选章节已有阅读笔记。可以点“查看阅读结果”对照原页；笔记可能出错，也不代表你已经学会。

怎样让阅读更快，或少占用聊天资源？

“优先开始”会直接排队，你仍可继续聊天；“空闲时再读”会先让聊天和文档任务使用 AI。前后衔接的教材适合依次阅读，独立章节可同时读。卡顿时先选“空闲时再读”和“按目录依次阅读”。任务卡可暂停、继续，离开页面不会停止任务，但软件需要保持运行。

书库用哪个模型？能调吗？

展开“阅读模型”，默认跟随点击阅读时工作台的服务、模型、推理强度，但不带入聊天上下文。选“为书库单独选择”并保存后即可另选模型；扫描页核对需支持图片的模型。已启动任务沿用原选择。

自动参考、未读章节和智能检索

工作台可开关书库自动参考，也可手动指定章节。未读章节只提示线索，由你决定是否读取，不会当作已读正文引用。检索结果可滚动，切回原对话恢复已找到记录。

“智能检索”可以按关键词查找，也可以帮助理解你提问的意思。后一种方式首次需要下载一个本地模型，只查已整理的范围；关闭后仍能按关键词查找。找到相似内容不代表条件相同，重要结论要回原页核对。

重要结论回原文核对

检查这份成果依据了什么

成果附近的“核查记录”或来源入口可查看资料范围、模型、审查、疑点与修订。来源位置帮助回到文件页码、节点、视频时间，不把导师一句话当成原文证据。

“未核查”“待确认”或“历史记录缺少依据”仍需核对。核查记录保留在软件内，不要求每次另下载一份审查文件。

教学核查记录能证明正确吗？为什么有多个版本？

核查记录不是正确性认证；它保留检查依据和疑点，不写入学习画像，不自动把旧疑点算成新错误。补讲、纠错和原讲解分别保留版本与来源。先确认当前读的是哪份，不把旧版审查当新版已通过，也不把别份题单评分当当前题证据。

需要实际工具时再开启

文件权限、联网与语音

聊天框附近可选文件权限。普通提问与引用资料不需要授予整台电脑完全访问。

  • 只读：在授权范围读取，不修改文件。
  • 需要审批：需要批准的操作先显示请求，任务等待你允许或拒绝，再继续。
  • 完全访问：在授权范围内按工具规则修改，确认可接受后再选。
联网、网页视频和生成图片

工具设置中启用“允许联网查询与读取网页”；自主读取网页视频还需“是否允许 AI 读取网页视频”。图片生成需另有可用的绘图服务配置；勾选能力不代替密钥或网站访问权限。

语音输入没有文字

点“语音”开始并允许麦克风，结束后等本地识别。到模型与语音设置查语言、设备、转录模型；首次下载、长录音或 CPU 识别可能慢。

在 VS Code Codex / DSH 中使用

电脑设置的外部工作台区域有“配置 VS Code Codex”“配置 DSH Desktop”。完成后重启对应客户端，再复制示例指令。在工具列表看到 StudyForge MCP 即可，不一定有单独按钮；需使用同一 Windows 用户的数据环境。

手机遥控，任务仍由电脑运行

安卓手机连接与使用

  1. 电脑开启连接。顶部点“连接手机”，启用连接，再用本次显示的网址或二维码。
  2. 手机打开页面。按窗口提示安装并信任电脑提供的 CA 证书，再开 HTTPS 地址。证书解决信任问题，不解决网络不通。
  3. 首次配对。手机使用配对码，在电脑批准设备；之后在同一浏览器保留站点数据，通常不用反复配对。
  4. 使用。选项目和对话，“资料”上传文件，“生成”制作文档，“成果”下载。专注模式保留主要聊天和输入区。

离开页面后：电脑上已启动任务继续，手机重新打开查结果。电脑必须保持运行且连接服务开启。

不同 Wi-Fi 或移动网络能用吗？

可用已配置的 Tailscale：电脑和手机登录同一私人网络并保持连接，电脑启用跨网络连接。收藏显示的私人地址，别复用旧 IP。Tailscale 在线不代表 StudyForge 服务已开启。

每次要扫码吗？电脑更新后手机也要装吗？

保留浏览器站点数据和电脑原数据目录，已批准设备在有效期内可继续用；换浏览器、清站点数据、撤销设备后要配对。手机界面由电脑提供，电脑更新后刷新手机页面即可；旧界面可关闭后重新打开。

分清隐藏窗口和完全退出

后台运行、开机启动与更新

按关闭窗口设置，右上角 × 可隐藏到 Windows 托盘，任务继续。要停止软件，在托盘右键退出，或到“设置与联动 → 运行与更新”点“完全退出”。

在哪里设置开机启动、通知、安装？

“运行与更新”可设置开机启动、隐藏启动和 Windows 通知。系统禁用通知时需在 Windows 设置允许。

在“软件更新”点“立即检查”，软件会查询官方 GitHub 的正式版本，无需自己填写更新地址。源码版也能检查和下载安装包。可保存“自动检测更新”及检查间隔；只有勾选“发现新版本后自动下载”，才会自动下载较新的安装包。

发现新版后可以先看发布说明，再点“下载安装包”。下载进度会显示在页面中，可以取消、失败后重试；不会影响聊天或生成任务。下载完成后点“打开安装包所在文件夹”，先从托盘完全退出 StudyForge，再手动运行安装器。不要删除学习数据目录。

当前 GitHub 下载会核对文件大小与完整性，但不会自动执行安装包。自动重启安装仍需发布者签名及安装前备份，目前没有启用。网络不通时，可点“打开官方发布页”用浏览器下载。高级更新地址应留空，除非发布者明确提供了其他更新目录。

请保留学习数据目录及资料原件。直接运行版需保留整个文件夹，不能只把一个 EXE 拿出来运行。

先把阅读空间调舒服

阅读区、外观与快捷键

工作台可收起导师工具、资料栏和生成选项，放大对话或全屏；拖动阅读区与输入区之间的分隔线可以改变大小。手机可用专注模式。

“设置与联动 → 外观”可换主题、背景、字号，分别调阅读区、侧栏、输入区等透明度与模糊。背景太花时，先提高“文字背后的底色”的不透明度。

  • F1：打开指南；Esc：关闭帮助。
  • F2：电脑侧栏选中条目后改名；右键有更多操作。
  • 换行：按输入框显示的快捷键操作；Enter 发送时，Shift+Enter 换行。
按现象找处理办法

遇到问题怎么办

失败提示或任务卡上有“查看处理办法与错误详情”时，点开先看中文原因和下一步操作。需要反馈问题，再展开“错误原文”复制；可识别的常见密钥会隐藏。打开说明不会重试任务。手机端若只是模型账号报错，无需重新配对电脑；只有连接失效时才按提示配对。

没回复 / 空内容 / 网络超时

确认工作台选了已配置的服务，到 AI 设置检测连接，核对密钥、模型调用名、额度和网络。先发不带资料的短问题；短问题也失败时先修连接，不要重读整本书。

429 / Too Many Requests / 重试次数已用完

服务限制了请求。减少同时运行的任务，按提示等待再试；反复立即点重试通常无效。不同服务的额度独立，保留错误时间与服务名称便于排查。

上传了却不能用 / 导师说没资料

看是否“待解析”：先解析需要的范围，再在当前对话勾选结果。检查是不是换了项目或新对话。PDF 用文件页码；图片和网址各有解析按钮。

网页 / B站提示403、412或读取失败

浏览器确认有权访问且完成验证，再试电脑端“浏览器读取”；仍不行就提供本地文件、字幕或截图。保存链接不代表正文可读，改播放时间参数通常无效。

生成慢 / 界面卡 / 内存高

看任务卡正排队、解析、转录、生成还是审查。先用一页或短片段对照；减少同时处理的任务，让聊天和生成先用 AI。只需讲解就取消同步出题，审查先选快速。扫描图片转文字、音频转文字、模型回复和检查都耗时，不只取决于输出字数。

生成失败 / JSON或公式报错

复制任务完整错误、服务模型、资料范围、格式和审查档位。先确认资料解析成功，再重试失败任务；重复失败别连续新建同样任务。100%但标失败不表示交付成功。

手机一直加载 / 连接超时

电脑确认连接服务开启，用当前显示地址；电脑不要睡眠。跨网络查两端 Tailscale 是否在线。CA 证书不能修复错误IP、防火墙或网络隔离。

聊天或成果消失 / 帮助打不开

回原项目、原对话；成果页先选原项目，旧消息加载更早；检查项目回收站。帮助用左侧入口或F1；手机配对页和学习选项也有入口，不需要 AI 在线。
