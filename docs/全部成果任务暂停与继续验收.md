## 支持范围与入口

| 任务 | 常用控制位置 | 继续时复用的内容 |
|---|---|---|
| 讲解、配套习题、只习题、修订讲解 | 成果文档中的任务卡片 | 已保存的模型步骤、题单、原对话与生成参数 |
| 资料通读 | 学习工作台通读栏；成果任务卡片 | 已完成部分的阅读结果 |
| 知识结构整理 | 知识结构窗口；成果任务卡片 | 已完成部分的结构结果 |
| 编程作业生成 | 习题页面任务卡片；成果任务卡片 | 题目草稿、独立解题和审查、参考实现测试、已创建题单 |
| 普通习题批改 | 习题页面任务卡片；成果任务卡片 | 已完成的逐轮批改与已提交评分 |
| 编程判题 | 习题页面任务卡片；成果任务卡片 | 已完成的容器测试、代码审查和评分 |
| 费曼评审、修复练习与进阶出题 | 习题页面任务卡片；成果任务卡片 | 已保存的费曼成绩、题单、父子题单关系与导出结果 |

界面显示「正在暂停」时，当前已发出的模型请求、容器测试或导出仍会先完成并保存，随后变成「已暂停」。继续后不会重复已保存步骤。完整退出会中断未完成步骤；重开保留暂停状态，必须主动继续，尚未完成或尚未持久化的请求可能需要重发。隐藏至托盘仍继续后台工作。

这里控制上述学习后台任务，文件上传、导入解析和普通导师流式回复继续使用原流程。旧版本缺少必要参数的任务不能凭空续做，会明确提示重新发起。习题和编程的原同步 API 保持兼容；软件页面采用新增的后台任务接口。

## 数据与评分保护

- 每项任务固定项目、来源对话、模型、推理选项、原资料和题目/评分依据；切换页面或项目不改写任务归属。
- 继续前验证已经读取的原资料。原文件被替换、修改或删除，或题目/评分依据发生变动时，拒绝混用旧结果，要求重新发起。
- 批改成绩与模型步骤分别保存。已评分后暂停，继续只处理未完成导出；已通过费曼评审后暂停，继续只生成或导出进阶题。
- 同题单进行中或暂停的任务阻止重复评分；MCP 编程提交也受同样保护。批改期间不新增方向提示，避免改变已提交作答的提示记录。
- 实际进程重启会留下未释放的批改锁。新锁关联具体任务，恢复时只清理已经中断/结束任务自己的旧锁，不清理其他调用方的锁。
- 全部未完成任务保持可见；「最近30项」只限制已结束历史。完成、取消的任务不提供暂停按钮。
- 删除任务仍取消后续发布，已完成成果保留。删除对话会取消属于该对话的新增学习任务。

## 建议人工验收

1. 加入一份较长资料，在通读期间点「暂停通读」。等待显示「已暂停」，再点「继续通读」，检查从剩余部分续做。
2. 整理知识结构并暂停，关闭再打开知识结构窗口，检查「继续整理」仍对应同一任务。
3. 在习题页布置编程作业。页面立即返回任务卡片，在出题中暂停；在成果文档里也能找到并继续同一任务。
4. 完整提交习题后暂停批改；重开软件，检查尚未完成时没有提前显示答案，继续后评分只出现一次，解析文档可打开。
5. 费曼评分通过后暂停进阶出题，继续时无需重新提交费曼讲解；只生成一份新题单。
6. 在暂停期间切换项目，检查任务与成果仍归属于原项目。要真正停止应用请从托盘完全退出，仅关闭窗口仍在后台运行。
