# 回收站彻底删除与自评综合分验收

2026-10-07，源码更新；未重新打包。使用原本机数据目录，数据库新增项目工作目录和任务文件产出的归属记录。

## 打开方式

1. 在 Windows 右下角托盘右键选择「退出 StudyForge」，完全退出已有进程。
2. 双击工程根目录 `验收最新版.vbs`，窗口标题带「源码验收版」。无需打开或保持 CMD。
3. 使用旧安装包会打开打包时的功能；本次改动在源码入口验收。

## 项目回收站

1. 项目侧边栏右键选择「移入回收站」。这一步仍可恢复，关联生成任务停止。
2. 点击侧边栏「项目与对话」标题右侧的回收站图标，每项都有「恢复」「彻底删除」。
3. 点击「彻底删除」会展示对话、消息、资料、成果、任务、学习证据数量，以及软件独占文件的数量与大小。
4. 输入完整项目名称，点击「永久删除项目」。取消或名称不一致不会执行删除。

清理项目记录及其依赖：对话与草稿、AI会话状态、通读、知识结构、成果及其快选引用、任务历史和步骤、习题、答卷、批改、提示和复习记录、审批、通知，以及来自该项目的画像证据。剩余项目的知识点评分重新计算，不从旧汇总恢复已删除证据。跨项目独立记录的自评保留。

只清理应用数据目录中归属于该项目的文件、成果副本、视频记录与画面、解析缓存、已登记的Agent工作目录、任务产生的临时文件和尚未登记为成果的中断导出。电脑上的外部原文件保留；其他项目仍引用的文件、视频画面与缓存保留。跨项目数据库关联无法安全解除时拒绝删除，不通过级联清理其他项目。

文件先移至应用内部恢复目录，数据库操作失败或移动失败则回滚；退出或断电中断可在重新打开回收站时恢复未提交的文件。已经提交的删除若有文件占用，回收站显示待清理数量，重新打开时重试，恢复记录不会因此重新出现。本地解析/导出线程若仍在收尾，永久删除暂时拒绝；线程实际结束及登记文件后再删除。后台画像在提交前检查项目与原事件，不能写回已删除项目。

此功能是应用记录与归属文件的删除，不是磁盘安全擦除；既有整库备份不在项目清理范围内。

## 自评的作用与综合分

旧版本自评已供导师参考，但主分只汇总作答/费曼表现。本次增加显示及实际接入：

| 字段 | 含义 |
| --- | --- |
| 作答参考分 | 当前有效做题、运行判题与费曼记录的汇总，不被自评改写 |
| 自评掌握度 | 最近一次有效数字自评，不因重复提交累计权重 |
| 主观难度 | 学生觉得有多难，用于调整讲解步骤与节奏，不作为扣分项 |
| 综合学习参考分 | 两项均有时按配置加权，供导师、讲解和习题调整详略、难度 |

默认公式：**综合分 = 作答参考分 × 80% + 自评 × 20%**。在「学习画像 → 知识点评估」调整自评权重0–50%，点击「应用权重」。选择0%可让有作答记录的综合分完全依据作答参考。该权重是可调的教学约定，未经能力测量校准。

验收示例：作答参考60、自评100，综合68；将自评权重改为40%，综合76，作答参考仍60。界面显示计算式，导师的画像工具、对话上下文和新生成任务使用相同字段。配置保存到本机，重启保持；已有成品文档不会被自动重写。

只有自评时显示「自评参考 · 未测验」，已有一项分数不把缺失项按0计算。自评与作答相差至少20分时提示核对理解或短测，不凭分差断言错因。先从自评知识点输入框选择已有名称可避免将同一知识点填写成两个名称；尚未自动合并同义知识点。文字问卷或聊天判断不凭空生成数字成绩。

重要边界：**实际答卷79分仍要求原规则的补救/费曼环节，80分按实际答卷过关**，综合分不能代替它。移出或恢复自评证据会重算综合分，保留原成绩。
