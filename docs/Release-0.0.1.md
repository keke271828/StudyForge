StudyForge 是 Windows x64 本地 AI 学习工作台，用来管理教材与资料、和 AI 讨论、整理阅读笔记与知识结构、生成讲解文件和练习，并记录学习过程。

## 功能

- 按项目管理资料和独立对话，支持 PDF、文档、图片、音视频、网页和代码等输入。
- 按页码或选段阅读，通读资料，查看笔记、知识联系和来源位置。
- 配置自己的 AI 服务，选择学习模式，进行提问和针对性追问。
- 生成讲解、练习、卡片和其他成果，完整提交作业后查看批改与补讲。
- 使用全局书库、学习画像和学习路线，按需暂停、继续和管理任务。
- 手机浏览器连接电脑，上传资料、继续讨论、查看任务和下载成果。

## 下载与开始使用

1. Windows 用户下载 `StudyForge-Setup-0.0.1.exe`，运行安装器后打开软件。
2. 在“设置与联动 → 模型与语音”配置自己可用的 AI 服务，检测连接。
3. 创建项目和对话，先发一句简单的问题；再上传一小份资料，选择范围并解析、勾选后提问。
4. 需要文件时使用“生成讲解”，在“成果文档”查看和下载。软件内按 F1 可打开操作指南。

`StudyForge-source-0.0.1.zip` 供运行和修改源码使用。两个 `.sha256.txt` 文件用于核对下载完整性。安装器未做商业代码签名，Windows 可能显示未知发布者；请先确认文件来源。

资料和成果保存在电脑本机；调用在线 AI 时，相关内容会发送给所选服务。AI 账号、密钥和额度需要自行准备。手机访问时电脑必须保持运行。当前没有启用自动安装，请使用本页安装包。

详细介绍与操作见 [README](https://github.com/keke271828/StudyForge#readme)，问题可在 [Issues](https://github.com/keke271828/StudyForge/issues) 反馈。具体的反馈将帮助这个项目走得越来越远，在此谢谢各位。

## Features

- Organize projects, materials, and separate conversations; import PDFs, documents, images, audio, video, web pages, and code.
- Read selected pages or passages, run reading tasks, and inspect notes, concept connections, and source locations.
- Connect your own AI service, choose a learning mode, and ask focused follow-up questions.
- Generate explanations, exercises, flashcards, and other outputs; submit complete assignments for feedback and follow-up explanations.
- Use the shared library, learning profile, and learning plans; pause, continue, and manage tasks as needed.
- Connect a phone browser to your computer to upload materials, chat, check tasks, and download outputs.

## Download and get started

1. On Windows, download `StudyForge-Setup-0.0.1.exe`, run the installer, and open the app.
2. Open 设置与联动 → 模型与语音 (Settings and integrations → Models and voice), configure a service you can use, and test it.
3. Create a project and conversation. Try a short question first, then add a small file, select its range, parse it, and select the result before asking about it.
4. Use 生成讲解 (Generate explanation) for downloadable documents and find results in 成果文档 (Outputs). Press F1 for the in-app guide.

`StudyForge-source-0.0.1.zip` is for running or modifying the source. The two `.sha256.txt` files let you check download integrity. The installer has no commercial code-signing certificate, so Windows may show an unknown-publisher warning. Check the file's source before running it.

Materials and outputs are stored on your computer. Relevant content is sent to your chosen service when using online AI. Supply your own account, keys, and service quota. Your computer must remain running for phone access. Automatic installation is not enabled; use the installer on this page.
