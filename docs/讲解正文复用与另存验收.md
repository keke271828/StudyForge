# 讲解正文复用与另存验收

2026-10-11，源码更新。本轮聚焦复用已经完成的讲解，减少换格式和排版失败后的重复等待；不将此功能等同于首次生成速度或教学准确率已经改善。

## 用户操作

1. 在原项目的“成果文档”里点讲解卡片的“另存讲解格式”。
2. 选择 DOCX、PDF、PPTX、FreeMind `.mm`、Markdown 或文本；仅按明确选择生成一个新成果，不自动附带 Markdown 或审查文件。
3. 新任务显示本机排版进度，可暂停、继续或取消。原成果保留，新文件加入原项目、标注原对话、进入资料快选；手机可直接选择和下载。
4. 完整正文已保存、仅导出失败的讲解任务有“正文已保存 · 换格式导出”入口。补救不会把原失败任务改成全部成功，不会重新出题。

另存不调用模型，不重新理解原文件。适合保留满意的讲解，仅更换阅读或下载格式；如需修正知识内容，请另发修订要求。

## 正文与发布边界

- 讲解通过当前选择的审查、总结整理及来源版本核对后，才存入本机私有正文表。极速模式仍是生成时自检，不能据此宣称独立审查通过。
- 原正文按生成任务保存并校验 SHA-256，不允许同一个任务悄悄替换成另一版正文。改变原文件不会改变旧讲解的另存依据。
- 元数据轮询只读取可用格式，不读入整篇正文。重复请求与进行中的同一格式请求去重。
- 原项目与对话归属保留；跨项目请求拒绝。习题、私有答案和批改文档不通过这个入口转换。
- 临时文件写完后原子替换；失败或取消清理未注册输出。实际本机排版并发上限为 1，减少多格式同时排版造成的峰值。
- 暂停与重启复用已写好的文件；删除任务历史保留已完成成果的转换能力。彻底删除项目同时删除所属正文记录，不影响其他项目。
- 排版补救后的讲解只向原对话发布一次，并保留同一份理解反馈问卷；已删除对话不会重新出现。删除原成果后另存的新文件可继续用于原问卷。

## 验收与限制

实际桌面和配对 HTTPS 手机流程报告：`build/document-exports-ui-20261011-1/ui-report.json`。检查取消窗口不启动任务、实际 PDF 与 Word 补救、自动加入快选、320px 手机布局、PPTX 下载字节、重新加载与项目隔离；整个转换过程新增模型请求为 0。截图已检查，PDF 使用 Poppler 渲染后检查中文、公式、引用框及来源标注。

回归用例：`tests/test_document_exports.py` 共 19 项通过；142 项相关回归和 20 项调度回归通过，后补本功能与理解反馈 33 项重叠回归通过。同时检查原文件生成、暂停恢复、教学交接、理解反馈、手机访问、项目删除、桌面通知、公式导出和调度。用例按独立临时目录运行，实际学习数据库未改动。

六类文件通过实际生成和对应结构读取；PDF 已视觉核验。未将其扩大成所有版本的 Word、PowerPoint、FreeMind 客户端均已实际打开的结论。幻灯片和思维导图的组织仍由已有导出器决定，转换不会使错误的讲解自动变正确。

新功能对更新后的任务开始保存正文。旧成功讲解可从原对话的完整生成消息恢复，旧失败任务缺少完整消息时不能补造正文。重新制作 Anki 卡片、可运行代码、Notebook 或数学模型涉及内容重组，不属于零模型排版转换。
